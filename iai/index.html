第1讲 人工智能与智能体

这一讲建立整门课的语言：先说清楚“谁在什么环境里，为了什么目标作出什么行动”，再讨论算法。搜索、逻辑、概率与学习最终都服务于这个闭环。

1.1 从电影中的智能到可研究的问题课件 1–20 页

课件先用电影、机器人、语音助手、推荐系统、自动驾驶和棋类程序展示不同形态的 AI。电影中的形象常把语言、情感、身体控制和自主目标混在一起；科研与工程必须拆成能描述、能实现、能评价的任务。例如“会开车”要拆成感知车道、预测交通参与者、规划路线、控制车辆等问题。

课件中 AlphaGo、DeepStack、Libratus 与 ChatGPT 的页面是课程背景，不是同一种算法的连续版本。公开棋盘上的博弈、隐藏手牌下的策略和语言生成，面对的信息与评价目标不同。不要从某项任务成功直接推断系统在所有任务上都具有人类能力。

易错历史案例中的“当时最强”“人类无法战胜”“围棋程序太弱”等描述带有年代背景。讲义保留原图供核对，理论解释不把这些时代性说法当作今天的排行榜。

人工智能的历史页可读成研究方法的变化：早期重推理与问题求解，后来强调领域知识，再到从数据学习。它们没有互相完全取代；一个现代系统仍然可能同时使用规则、搜索与学习。

1.2 四种人工智能定义课件 15–16 页

课件用两条轴分类：目标是像人，还是符合规范性的理性标准；研究对象是内部思考过程，还是外部行动。

视角核心问题怎样判断进展
像人一样思考人实际上怎样记忆、推理和决策与心理实验、认知过程相比较
像人一样行动系统行为能否达到人类表现对话、操作、感知等行为测试
理性思考结论是否遵守正确推理规则逻辑形式与推导正确性
理性行动给定信息后怎样行动能得到更好结果目标、效用及预期表现

“理性”不是“知道所有真相”。你带伞后没有下雨，不等于带伞一定不合理；决策应根据当时可用信息及收益损失判断。类似地，下棋程序作出预期最好的选择后仍可能输给对手。

重点理性行动强调“在已知信息和资源约束下，最大化预期表现”。它不要求系统内部必须模仿人脑，也不要求每次都获得最好的事后结果。

1.3 智能体与环境的闭环课件 21–25 页

智能体通过传感器获得感知，通过执行器影响环境。感知是某个时刻得到的信息，感知序列包含到目前为止的历史。智能体函数在概念上把感知序列映射为动作，智能体程序是具体实现。

吸尘器世界有 A、B 两个位置，每处可干净或脏。感知可写成 [位置,清洁状态]，动作是 Left、Right、Suck、NoOp。若机器人只知道当前格子脏不脏，就不能把“当前没有灰尘”理解成“所有地方都干净”。这说明局部感知与完整世界状态的区别。

例题两位置吸尘器若位置有2种、每处清洁状态各2种，物理状态共有 2×2×2=8 种。一个“当前位置是A且A干净”的感知仍可能对应两个世界：B干净或B脏。

课件的动作表展示：相同的当前感知在不同历史下可以对应不同动作。例如已经检查过两处都干净时可以停止；只见到当前一处干净时，还需要去另一处检查。历史是否保留，决定了智能体能表达怎样的策略。

1.4 先写 PEAS 再选算法课件 26–27 页

PEAS 是任务规格的四部分：Performance measure 评价标准，Environment 环境，Actuators 执行器，Sensors 传感器。它不是算法步骤，而是设计前应明确的任务边界。

任务P 评价标准E 环境A 执行器S 传感器
出租车智能体安全、合法、准时、成本道路、车辆、乘客、天气转向、油门、制动、显示摄像头、定位、速度等
吸尘器清洁程度、耗电、时间房间、障碍物、灰尘移动、吸尘位置、灰尘、碰撞

设计评价时要避免“指标替代目标”。如果吸尘器按吸到灰尘的次数计分，它可能反复制造灰尘；若黑白棋只按当前棋子多寡评价，可能贪吃子而丢角。指标应尽量反映真正想实现的结果。

1.5 环境类型决定问题难在哪里课件 28–28 页

完全可观测表示当前感知足够获取决策所需状态；部分可观测表示信息缺失，需要内部状态、信念或概率。单智能体与多智能体的区别，在于环境中是否还存在有自己目标并影响结果的行动者。

确定性表示给定状态和动作，下一状态由规则确定；随机性表示结果服从分布。对手下一步不知道，并不意味着黑白棋翻子的规则是随机的：它是确定性、多智能体环境。

情节式任务的各次决策基本独立，例如独立分类多张照片；序贯任务中当前动作影响未来，例如导航与下棋。静态环境在决策期间不变；动态环境会继续变化。离散/连续则要分别看状态、动作和时间。

难点这些分类不是互相替代的标签。一个任务可同时是部分可观测、随机、动态、连续和多智能体。应逐个维度分析；模型是否已知又是另外一个维度。

1.6 五种智能体结构课件 29–34 页

简单反射智能体使用条件—动作规则，例如“见到脏就吸”。优点是直接、响应快，缺点是不能区分当前感知相同而历史不同的情形。

带状态反射智能体维护内部状态，结合“世界怎样变化”和“我的动作造成什么变化”更新它。内部状态是对外界的模型，不保证与真实世界完全相同。

基于目标的智能体会问“执行某动作后能否到达目标”。它需要预测动作后果，因此自然引出搜索与规划。基于效用的智能体继续区分不同成功结果：同样抵达目的地，时间、费用和风险可以不同。

学习智能体包含执行部分、学习部分、评价者和问题生成器。执行部分负责当前行为；评价者给反馈；学习部分改进机制；问题生成器推动尝试有信息价值的新行动。学习不只是“多运行几遍”，而是经验实际改变了参数、知识或策略。

重点后续章节可视作这套结构的展开：搜索预测后果，逻辑表达知识，概率处理不确定性，学习根据经验改善估计。手写规则或评价函数本身不等于通过数据学习。

第2讲 无信息搜索

这一讲把“想到一个办法”改写成“在状态空间里系统地找路径”。关键不是背算法名字，而是说明状态是什么、节点保存什么、frontier 按什么顺序取出节点，以及这种顺序带来什么保证。

2.1 用五个要素描述搜索问题课件 1–10 页

搜索问题包括初始状态、合法动作、转移模型、目标测试和路径代价。路线问题中，状态是城市；动作是沿邻接道路移动；转移给出抵达城市；目标是到达 Bucharest；代价是沿途路程和。把现实地图转成城市图，已经进行了抽象：车辆微观位置、驾驶操作等暂时被忽略。

八数码问题的状态是九个位置上的排列，动作是让空格与相邻数字交换。目标是指定排列，常令每次移动代价为1。并非每个排列都可从固定起点到达，因此“枚举所有排列”与“搜索可达状态”不是同一件事。

吸尘器的8个状态能画成状态空间图：节点是物理配置，有向边代表动作的结果。一个动作可能保持状态不变；实际搜索要处理这种自环，不然可以永远重复执行没有效果的动作。

重点状态应保留预测未来与检验目标所必需的信息，舍弃无关细节。把不充分的信息当状态，会让同一个“状态+动作”产生互相矛盾的后果。

2.2 状态与搜索节点不是一回事课件 11–20 页

状态描述世界，节点描述某次搜索如何来到这个状态。节点通常包含 state、parent、action、path_cost、depth。从父指针沿路回溯，才能恢复完整方案。

例题S→A→G 与 S→B→A→G 两条路径里出现的 A 是同一城市状态，却对应不同搜索节点。它们有不同父节点、深度和累计代价。如果只存城市名，无法解释“这次从哪里来”。

课件区分栈与队列，Lecture 3 又补充递归栈与堆。算法意义上的 frontier 容器，不应和操作系统/语言的调用栈混为一谈。DFS 可以用显式栈实现，也可以用递归；BFS 的 FIFO 队列则按先进先出管理待探索节点。

大O表示规模增加时的增长阶，通常不说明常数快慢。NP-hard 表示困难性下界的归约关系，不等于“所有实例都慢”；也不等于“目前没写出快程序”。搜索树指数增长已经能使较小分支数变得不可承受。

2.3 通用树搜索与图搜索课件 21–29 页

通用树搜索只需要改变 frontier 的取出规则，就能形成多个策略：

frontier ← [初始节点]
循环：
    若 frontier 为空，返回失败
    n ← 按策略取出一个节点
    若 n.state 满足目标，返回从父指针恢复的路径
    展开 n，把后继节点加入 frontier

树搜索可能为同一状态创建大量重复节点。图搜索增加 explored/closed 及 frontier 状态记录，避免无意义重复。在状态空间有限但路径可以无限绕圈时，这项处理尤为重要。

难点图搜索不能总是“第一次见过的状态以后永远忽略”。如果后来用更小代价抵达同一状态，UCS 或 A* 需要更新已有记录，必要时重新打开节点。是否可永久关闭，取决于算法与启发条件。

课件的图分离性质可理解为：frontier 位于已探索区域与未探索区域之间；若仍有可达目标路径，该路径离开 explored 的位置上应有待处理节点。这个观察也是后面最优性证明的基础。

通用树搜索与图搜索的完整骨架

依据 Lecture 2 · PDF第21、23、28页整理

算法与流程 · 可直接复制
TREE-SEARCH(problem, policy):
    frontier ← container([INITIAL-NODE(problem)])
    while frontier is not empty:
        node ← POP(frontier, policy)
        if GOAL(node.state): return SOLUTION(node)
        for action in ACTIONS(node.state):
            INSERT(frontier, CHILD-NODE(problem, node, action))
    return failure

GRAPH-SEARCH(problem, policy):
    frontier ← container([INITIAL-NODE(problem)])
    explored ← empty set
    while frontier is not empty:
        node ← POP(frontier, policy)
        if GOAL(node.state): return SOLUTION(node)
        add node.state to explored
        for action in ACTIONS(node.state):
            child ← CHILD-NODE(problem, node, action)
            if child.state is in neither explored nor frontier:
                INSERT(frontier, child)
    return failure

这是课件通用骨架，不能把最后的去重规则直接当作所有代价搜索的完整实现。UCS 要替换 frontier 中更贵的路径；不一致启发式下的 A* 还可能需要重新打开已扩展状态。

2.4 用四个维度评价搜索策略课件 30–31 页

完备性问“有解时是否一定找到”，最优性问“找到的是否最低代价解”，时间和空间分别问需要多少计算与存储。记 b 为分支数，d 为最浅解深度，m 为最大搜索深度；这些量不是同一个概念。

无信息搜索只用问题定义中已有的信息，不额外估计“哪个状态更接近目标”。UCS 知道已走代价，仍属于无信息搜索，因为它没有预测剩余距离。

2.5 广度优先搜索 BFS课件 32–35 页

BFS 用 FIFO 队列，每次取深度最小的节点。根之后是全部深度1节点，再是深度2节点，所以有限分支且存在有限深度解时能找到最浅解。

若每一步代价相同，最浅等于最便宜，因此最优。若路程不同，“一条边”可能比“两条边”更贵，BFS 不再保证最低成本。课件的标准实现通常在取出节点时检查目标，可能在发现深度d目标前生成下一层一部分，因此给出 O(b^(d+1))；生成时检查的某些实现可写 O(b^d)。两者都表达指数时间与指数内存的核心困难。

例题S→G 代价10，S→A 代价1，A→G 代价1。BFS 喜欢一条边的 S→G，代价10；最便宜路径其实为2。判断最优必须先看优化的是边数还是总代价。

BFS：FIFO 队列与生成时目标测试

BREADTH-FIRST-SEARCH(problem):

    if GOAL(root.state): return SOLUTION(root)

2.6 深度优先搜索 DFS课件 36–45 页

DFS 用 LIFO 栈，沿一个分支尽量深入，走不通再回溯。它通常比 BFS 省内存，但“省内存”不表示一般更快：左边分支若很深而目标在右边浅层，DFS 会浪费大量计算。

在无限深度或未处理环路时，DFS 可能永远不回来，所以一般不完备；有限状态图配合正确去重可以保证终止。它按深度而非代价走，因此通常不最优。标准树搜索时间 O(b^m)，空间 O(bm)：每层要保留未探索的兄弟选择。仅数递归深度的 O(m) 没算这些存储。

易错BFS 与 DFS 的“快慢”依赖目标分布、树结构和内存限制，不能将课件中的直观比较读成对所有实例的绝对排名。

2.7 一致代价搜索 UCS课件 46–52 页

UCS 用按累计路径代价 g(n) 排序的优先队列，先扩展便宜路径。在常见非负边权设定下，状态按正确顺序出队；当目标以当前最小代价从队列取出，才能确认没有仍在 frontier 的便宜方案会胜过它。

若新路径到达 s 的代价小于已有 best_cost[s]：
    更新 best_cost[s] 与父指针
    将改进后的节点加入优先队列
取出旧的过期条目时跳过

对前面的代价10与代价2例子，UCS 在目标10出队前会先展开 A 的1，再用2更新目标，因此返回2。若所有边代价相同，UCS 的扩展层次与 BFS 对应。

无限状态情况下，为保证不会无限探索一串越来越小的正代价，常要求存在正的最小步长 ε。时间与空间可用 O(b^(1+⌊C*/ε⌋)) 描述，其中 C* 为最优解代价。负边会破坏常见 UCS/Dijkstra 式关闭逻辑，不能直接沿用上述保证。

UNIFORM-COST-SEARCH(problem):

    frontier ← MIN-PRIORITY-QUEUE([(0, root)])

2.8 深度限制与迭代加深课件 53–57 页

深度限制搜索 DLS 在深度 l 停止 DFS。这里要区分三种结果：找到解、整个可搜空间确实失败、仅因深度上限截断。若把截断误当成无解，迭代加深就无法判断是否值得继续。

IDS 从限制0开始反复运行 DLS，每次上限加1。它会重复浅层，但浅层节点少，最深层数量多且只搜一次。对 b>1 的树，总工作量为 (d+1)b⁰+db¹+…+b^d，仍为 O(b^d)，空间为 O(bd)。等步长时具有 BFS 的最浅解优势，又避免保存整个宽阔边界。

例题b=10、d=3 时最后一层有1000个节点，根只有1个。多重复根几遍远少于存储和遍历最后一层的代价。因此“重复过”不等于“复杂度差一个指数”。

RECURSIVE-DLS(node, problem, remaining):
    if GOAL(node.state): return SOLUTION(node)
    if remaining = 0: return cutoff
    cutoff_occurred ← false

                               problem, remaining - 1)
        if result = cutoff: cutoff_occurred ← true
        else if result ≠ failure: return result
    if cutoff_occurred: return cutoff
    return failure

3.1 递归栈与显式frontier课件 1–5 页

课件先回顾通用树搜索，再说明内存中的栈区与堆区。递归 DFS 把返回位置与局部变量放在调用栈上；显式写法可以把 frontier 节点放在堆上的容器。两者都能表达深度优先的访问顺序，区别在实现和资源限制。

3.2 g h f 分别表示什么课件 6–7 页

g(n) 是从初始状态到 n 已经花费的真实代价；h(n) 是从 n 到某目标的预测剩余代价；f(n) 是算法用于排序的评分。启发函数不需要给出完整方案，但应该能利用领域结构区分更值得优先探索的状态。

路线问题中的直线距离 hSLD 是一个例子：道路不能比两城直线更短，因此可作为路程下界。若目标是时间而不是路程，直接使用公里数就混用了单位，应先换算或重新设计估计。

3.3 贪心最佳优先搜索课件 8–13 页

贪心搜索用 f(n)=h(n)。它只关心看起来离目标近不近，忽略之前绕了多远。罗马尼亚例子中它会从 Arad 到 Sibiu，再到 Fagaras，最后到 Bucharest，总路程140+99+211=450。

另一条路径 Arad→Sibiu→Rimnicu Vilcea→Pitesti→Bucharest 是140+80+97+101=418，反而更便宜。贪心不是因为不会算g而错，而是排序目标本身没有使用g。

无限空间或有环时它可能不完备；有限状态空间配合正确去重可以保证找到可达目标。它不保证最低总代价，最坏时间与空间仍可能指数增长；优秀启发式可以改善典型表现，但不会自动改变最坏情况。

算法与流程 · 可直接复制
A-STAR(problem, h):
    root ← INITIAL-NODE(problem)
    best[root.state] ← 0
    frontier ← MIN-PRIORITY-QUEUE([(h(root.state), root)])
    while frontier is not empty:
        (_, node) ← POP-MIN(frontier)
        if node.path_cost ≠ best[node.state]: continue
        if GOAL(node.state): return SOLUTION(node)
        for action in ACTIONS(node.state):
            child ← CHILD-NODE(problem, node, action)
            if child.path_cost < best.get(child.state, +∞):
                best[child.state] ← child.path_cost
                PUSH(frontier, (child.path_cost + h(child.state), child))
    return failure

本版本允许更小 g 的节点重新进入队列。课件罗马尼亚例中，首次生成 Bucharest 时 g=450；继续扩展后会出现 g=418。只有最低 f 的目标出队，结合相应启发条件才能确认最优。

3.5 可采纳性与一致性课件 21–27 页

可采纳启发式不高估真实最优剩余代价 h*(n)：h(n)≤h*(n)，通常还要求目标处h=0、h非负。一致性要求每条边满足 h(n)≤c(n,a,n′)+h(n′)，像估计距离的三角不等式。

将一致性两边加 g(n)，并用 g(n′)=g(n)+c，得到 f(n)≤f(n′)。因此沿一条正确更新代价的路径，f不下降。目标h=0时，一致性还蕴含可采纳性：沿通向最优目标的每条边反复应用不等式，h(n)不会超过整条真实路程。

难点树搜索中，可采纳性在常见条件下支持A*最优；图搜索若永久关闭已扩展状态，通常需要一致性保证。若启发式只可采纳但不一致，应允许发现更低g时重新打开状态。不能删掉实现条件，只说“A*有h就最优”。

把最优性证明中的不等式写全

依据 Lecture 3 · PDF第21–27页整理

f(n) = g(n) + h(n) ≤ g(n) + h*(n) = C*
f(Gbad) = g(Gbad) > C*
h(n) ≤ c(n,a,n′) + h(n′)
⇒ f(n′) = g(n) + c(n,a,n′) + h(n′) ≥ f(n)

设 C* 是最优解代价，n 位于某条最优路径的尚未扩展边界上，Gbad 是次优目标。可采纳性给出第一行；h(Gbad)=0 给出第二行，因此算法不会在还有这类 n 时先弹出次优目标。一致性进一步使每条路径上的 f 非递减，支持不重新打开节点的图搜索版本。

按课件思路证明最优性

设最优目标代价为 C*，算法却要先取出一个更差目标 G，代价 C>C*。沿某条最优路径，在目标尚未取出前，frontier 上应有一个对应节点 n。由可采纳性，f(n)=g(n)+h(n)≤C*；而 G 的 f(G)=g(G)=C。因此 n 应比 G 先出队，与“G先被取出”矛盾。

这段证明依赖：最优路径的合适候选没有被错误丢弃，目标在合适时机检验，队列的g和优先级正确更新。证明不是对任意叫作A*的伪代码都成立。

3.6 八数码的两个启发式课件 28–29 页

h1 是不在目标位置的数字块数量，空格不计；h2 是各数字到目标格子的曼哈顿距离之和。每次移动最多让一个块沿水平或垂直方向靠近一格，所以至少要走这么多格。

例题若数字块分别还差1、2、0、1格，总曼哈顿距离为4；若其中只有3个块错位，h1=3，h2=4。这不是在预测“恰好4步能解”，而是说不足4步一定不够。

若两个启发式都可采纳，且处处 h2≥h1，则称h2支配h1，提供更紧的下界。典型情况下它减少必需扩展；相同f边界的平局处理会影响确切节点数。计算h2若比h1昂贵很多，墙钟时间仍需实际比较。

3.7 从松弛问题得到启发函数课件 30–31 页

放松约束得到的最优解不会比原问题更难或更贵，因此可成为下界。八数码若允许块穿过其他块移动，得到曼哈顿距离；若进一步允许任意块直接跳到正确位置，就得到错位块数。

旅行商问题要求访问每个城市并回到起点，最小生成树只需连接全部城市而不满足回路与度数条件。删除这些限制后的最小代价不超过巡回路代价，可用于构造下界。必须保证比较的是相同边权模型，且松弛方案确实涵盖原方案。

重点多个可采纳启发式取最大值仍可采纳，通常比单个更强；直接相加可能重复计算同一份代价而高估，除非能证明它们分摊了互不重叠的成本。

4.2 MiniMax递推课件 7–9 页

所有节点的值统一从MAX视角解释。终局返回真实效用；MAX选择最大的孩子值；MIN选择最小的孩子值：

V(s) = U(s)                         若终局
V(s) = max_a V(RESULT(s,a))          若轮到MAX
V(s) = min_a V(RESULT(s,a))          若轮到MIN

课件的三组叶子为 [3,12,8]、[2,4,6]、[14,5,2]。对手会分别留下3、2、2，根因而选择第一组，保证3。这里不是假设对手配合，也不是计算三个叶子的平均值。

重点MAX/MIN随执棋方改变，分数的利益方不改变。若叶子总按“轮到谁”评价而根仍机械取大，就可能帮助对手。使用Negamax时可以换视角，但必须同时正确取负号与变换窗口。

4.3 性质与多玩家扩展课件 10–11 页

有限完整树上的MiniMax完备，并针对最优对手给出最优策略。时间O(b^m)，深度优先保存后继的空间O(bm)。围棋、国际象棋等完整游戏树太大，理论正确不等于能实时算完。

若对手偶尔犯错，MiniMax至少保留对最优回应的防御保证，但未必最擅长利用对手的特定弱点。它优化最坏合理回应下的值，不是针对一个已知随机弱对手的期望收益。

多玩家时，终局可用收益向量 (uA,uB,uC) 表示。某玩家行动时选择自身分量最大的孩子，再回传整个向量，常称Max-n思路。由于三方利益不再简单相反，双人零和的标量min/max与剪枝性质不能无条件照搬。

4.4 AlphaBeta怎样知道某些分支不必算课件 12–17 页

alpha是MAX通过已有相关选择能够保证的下界；beta是MIN通过已有相关选择能够限制的上界。边界来自当前路径上的祖先，并非仅描述当前局部孩子。

第一组MIN子树 [3,12,8] 完整搜索后值为3，根已有至少3的方案。第二组MIN看到第一个叶子2，就知道自己最多给MAX一个2。MAX不会舍弃3选至多2，因此 [4,6] 不必再看。

第三组先看到14时不能立刻剪，因为“至多14”仍有可能胜过3；看到5仍不能；看到2后值落到不值得根选择的范围。剪枝必须有足够有效信息，不能只看到“大数字”或“不喜欢的动作”就截断。

MAX(s, α, β):
    v ← −∞
    对每个孩子：
        v ← max(v, MIN(child, α, β))
        α ← max(α, v)
        若 α ≥ β：停止
    返回v

    v ← +∞
    对每个孩子：

        β ← min(β, v)
    return v

α 是 MAX 已有的下界，β 是 MIN 已有的上界，不是两个玩家分别能保证的最终真值。课件叶序中读完 A₁ 得 α=3；A₂ 只读到2便可剪掉4、6，最后仍需读取 A₃ 的14、5、2。总共读取7个叶子。

4.5 动作顺序与理想复杂度课件 18–19 页

先检查对当前行动方有希望的孩子，常能更早收紧边界。理想动作排序时，AlphaBeta约需O(b^(m/2))，相当于同预算内有机会搜索更深；最坏排序下仍接近O(b^m)。它改变的是计算量，不改变相同树和叶子评分下的根值。

同分动作可能因遍历顺序不同而选择不同坐标，不一定是错误。验证时应先检查根值，再确认返回动作确实达到该值；不能只比较坐标字符串。

4.6 资源有限时的启发式MiniMax课件 20–22 页

实际程序用CUTOFF-TEST决定何时截断，用EVAL估计非终局价值。深度d只限制看几次行动，并非把非终局真的变成规则上的结束。终局仍应返回真实胜负效用。

线性评估写成 EVAL(s)=Σ wi fi(s)。国际象棋可以用子力，黑白棋可以用棋子差、行动力差、角点、稳定子。前期棋子多不一定好，因为暴露的棋子会被翻回；角点无法被夹住，通常更安全。评价计算本身也占时间，复杂到使搜索深度大幅下降可能得不偿失。

重点好的评估需保持终局胜负顺序、计算足够快、非终局分数与未来胜率相关。深度受限搜索只能保证当前截断树的最优，不保证真实游戏最优。

确定性MiniMax只关心叶子顺序，严格递增变换保持选择，例如所有正分同时平方而不改变顺序。非严格变换可能制造新平局；严格递减变换会倒转偏好。期望节点则不同，非线性变换可能改变平均值的排序。

4.7 随机游戏的期望极大极小课件 23–26 页

带骰子的游戏要加入CHANCE节点。MAX取大、MIN取小，CHANCE按概率加权：V(s)=Σr P(r|s)V(RESULT(s,r))。例如两个结果值2与10，各概率1/2，随机节点值为6，而不是2或10。

随机分支让树迅速膨胀。双骰有36个有序结果或21个无序点数组合，后者概率并不相等；把21种全部赋同样概率会算错。未来越远，每个特定结果分支概率越小，深搜的实际价值与计算成本要平衡。

例题动作A一定得4，动作B以一半概率得0、一半概率得10。按原效用B期望5优于A；若取平方根，A变2，B期望约1.581，偏好反转。这说明随机游戏的效用不能随便做非线性变换。

4.8 不完全信息游戏课件 27–27 页

桥牌等任务中，手牌未完全公开。可考虑与已知证据一致的可能发牌，估计不同方案的效果，但不能把“每种隐藏世界里都知道答案后分别选最佳”当成现实可执行策略。真实策略只能根据可观测信息行动。

蒙特卡洛抽样发牌可以近似评估，但隐藏信息推断、策略一致性和对手行为建模都有额外困难。它们不能靠把普通MiniMax树随便多复制几份解决。

5.1 从随机数到未知奖励课件 1–5 页

伪随机数由确定性算法和种子生成，相同算法、相同种子通常可复现序列。固定种子有助于对比实验，但不同实现或版本的随机过程仍需保存实际输入。程序中的随机rollout也不表示环境规则本身变成随机。

K个老虎机臂各有未知奖励分布，均值为 μa。每轮选一个臂并观察奖励，目标是在总共T轮中取得高累计奖励。最大期望臂记为a*，期望遗憾可写为 R(T)=Tμ*−E[Σt rt]，也等于各差臂的均值差乘期望尝试次数之和。

这是一个“边采样边做决定”的任务。只要求最后推荐最好的臂，和要求整个过程中累计奖励高，是相关但不同的目标；不能把只用于识别的采样预算与累计收益无条件混同。

5.2 只探索或只利用都不够课件 6–11 页

只探索把预算均匀分给K个臂，可以估计每个均值，却把很多轮浪费在已知较差的臂上。只利用先每臂试一次，随后永远选当前最好，可能被一次偶然高奖励骗住，再也不纠正。

例如真实成功率为0.7与0.6，两臂各试一次完全可能得到0与1。把“观测最佳”等同“真实最佳”就是纯利用的风险。探索有短期机会成本，但有信息价值。

重点探索不是盲目冒险，而是为了减少未来决策的不确定性；利用是使用已有知识争取当前收益。两者都服务于同一个长期目标。

5.3 ε贪心与softmax课件 12–13 页

ε-greedy以1−ε选择当前估值最大的动作，以ε从全部动作随机选。若随机选择也包含最佳动作，那么最佳动作实际概率为1−ε+ε/K；其他每个动作概率为ε/K。

Softmax按 P(a)=exp(Q(a)/τ)/Σb exp(Q(b)/τ) 采样。τ大时更接近均匀，τ小时偏向高Q。与ε-greedy不同，softmax探索时也会区分“略差”与“非常差”。为避免指数溢出，可以先减去所有Q中的最大值，不改变归一化结果。

例题Q=[2,1]、τ=1 时，第一动作概率为e²/(e²+e)=e/(e+1)≈0.731。τ减小会让概率更集中。改变Q的数值尺度也会改变探索强度，所以温度和奖励单位有关。

5.4 UCB为什么给不确定动作加分课件 14–14 页

课件采用 Q(a)+√(2 ln n / na)；Q是样本平均，n是总次数，na是该动作次数。第二项给样本少的动作额外机会；随着na增大，置信奖励下降。na=0时通常优先尝试，不能直接除0。

直觉来自浓度不等式：在独立、有界奖励等条件下，样本均值偏离真实均值的概率随样本数增多而下降。UCB遵循“对不确定的选项保持乐观”，用上置信界而非均值选择。这个式子的经典结论依赖相应Bandit假设，不能直接保证任意非平稳对抗问题都有同样表现。

5.5 用rollout评估路径选择课件 15–20 页

课件再次使用罗马尼亚路线：把当前可选道路看成臂，从每个动作后随机走若干次，观察完整路径成本，再更新估值。估计“未来可能多贵”不再只靠手写直线距离，而可从模拟得到。

路线是最小化成本问题。如果UCB用于最大化奖励，应把回报定义成负成本，或在相应形式中使用下置信界。不能把正路程直接当奖励后继续“越大越好”。

当只在根分配模拟预算不能充分利用结构时，可把同样思想递归用于后继，从一个节点逐渐长成树。沿所经过路径更新统计，让多次模拟共享经验。

5.6 MCTS的四步循环课件 21–24 页

选择：在已有树中按规则选孩子，直到可扩展位置。扩展：加入一个或少量新节点。模拟：从新节点按rollout策略走到终局或指定截断点。回传：把模拟结果更新到沿途节点的访问数与累计收益。

每条边或节点通常保存访问次数N与累计收益W，均值Q=W/N。UCT是在树上使用UCB式选择的一类方法；MCTS是更广的框架，两者不应完全当成同义词。

回传不等于每层都做MiniMax取极值：纯MCTS更新的是统计估计。双人博弈中，应明确Q从根玩家、当前玩家还是某固定颜色视角定义，再一致处理对手层；否则对手可能错误地帮助根方。

            append node to path

            node ← EXPAND-ONE-UNTRIED-ACTION(node)
            append node to path
        result ← ROLLOUT-TO-TERMINAL(node)
        for v in path:
            v.visits ← v.visits + 1
            v.total_reward ← v.total_reward + REWARD-FOR(v, result)
    return root child with the largest visit count

UCT(parent, child) = Q(child) + c × √(ln N(parent) / N(child))

这是把课件的 Java TreeNode 程序整理成语言无关的四步流程。rollout 不把经过的所有状态都加入树；回传时每个节点的奖励视角必须一致。双人零和游戏可按节点所代表玩家换号，不能让对手也始终最大化根玩家奖励。

5.7 rollout质量与AlphaGo联系课件 25–27 页

随机rollout省去某些手工叶子评分，但有限样本有方差，模拟策略也有偏好。局部模式、邻近落子、已有价值函数可改进rollout；用有偏模型降低方差可能更适合有限预算。

课件的“无限尝试后最优”应在适当有限博弈、充分访问及采样条件下理解，不能把任意MCTS变体的有限预算结果当成必然最优。相比AlphaBeta，MCTS逐步把预算集中到部分树，适合大分支问题；两者没有脱离实现与任务的普遍胜负关系。

原始AlphaGo结合策略网络给先验、价值网络评估与树搜索，详细结构在第13讲展开。学习模块改进估计，搜索在决策时前瞻；不是“用了神经网络就不需要搜索”。

5.8 非确定性行动与AND OR搜索课件 28–31 页

不可靠吸尘器的Suck在脏格上可能只清当前，也可能顺带清邻格；在干净格上还可能弄脏。动作的转移不再是单一RESULT，而是多个RESULTS。

OR节点是智能体挑一个动作；AND节点是该动作所有可能结果都要有后续计划。解是一棵条件计划树：OR处保留一个可行选择，AND处覆盖全部可能结果。如果所有结果概率未知且要求保证成功，不能随意只取平均。

深度优先AND-OR搜索对路径上的重复状态可判定当前分支循环并返回失败。这不表示那个状态全局无解，只表示此条无环证明路径不能继续重复。允许反复尝试的循环计划需要更强的分析，不能用同一条简单规则全部排除。

AND–OR 搜索返回条件计划

依据 Lecture 5 · PDF第30–31页整理

算法与流程 · 可直接复制
OR-SEARCH(state, path):
    if GOAL(state): return empty_plan
    if state in path: return failure
    for action in ACTIONS(state):
        plan ← AND-SEARCH(RESULTS(state,action), path ∪ {state})
        if plan ≠ failure: return [action, plan]
    return failure

AND-SEARCH(states, path):
    branches ← empty map
    for state in states:
        plan ← OR-SEARCH(state, path)
        if plan = failure: return failure
        branches[state] ← plan
    return conditional_plan(branches)

OR 节点只需找到一个可行行动；AND 节点必须覆盖该行动的每一种可能后果。返回值因而是一棵带条件分支的计划树。这一版本寻找无环条件计划，遇到环失败不等于所有允许重试的循环策略都不存在。

5.9 没有观察时在信念集合中搜索课件 32–32 页

没有传感器时，智能体不知道自己处在哪个物理状态，只知道可能集合B。动作后集合更新为 B′=⋃s∈B RESULTS(s,a)。一个动作序列若要保证成功，就得让最后集合中的每个状态都满足目标。

课件的增量方法先找能解决某个可能状态的方案，再检查其他状态，不够就扩展或修改。优势是有些失败可用很小的反例子集发现。与AND-OR的区别在于：如果没有新观察来区分结果，就不能为不同隐藏状态分别选不同动作。

难点belief state可以只是可能状态集合；引入概率后才是信念分布。未知、随机、对抗三种来源应分别建模，不能全部套成MIN节点。

6.1 用变量 取值域 约束描述问题课件 1–6 页

CSP由变量X1…Xn、各自取值域Di和约束C构成。目标是给每个变量赋值并满足所有约束。地图染色中，变量是地区，域是红绿蓝，邻接地区必须异色。

约束图中节点代表变量，边代表二元约束，位置只是示意，不必与地理地图一致。同一个问题可用不同编码，编码会改变搜索和传播效率。

若用一般搜索表示，可把已赋值变量集合当状态，每次给一个未赋值变量赋值。赋值顺序常不影响最终方案，因此固定“一次一个变量”能去掉许多只因顺序不同而重复的路径。

6.2 回溯搜索与三种排序课件 7–13 页

回溯每次选择一个变量，尝试某值，检查与已有赋值是否冲突，冲突就换值，所有值都失败再退回上一变量。它比“所有变量都填完再检查”能更早发现失败。

BACKTRACK(assignment)：
    若所有变量已赋值，返回assignment
    选择未赋值变量X
    按某顺序尝试域中的v：
        若X=v与已有赋值一致：
            暂时赋值，并做推理/域删减
            若没有冲突，递归搜索
            若成功，返回解
            撤销赋值及本层域删减
    返回失败

MRV选剩余合法值最少的变量，“最可能失败的先查”。度启发式在平局时选约束最多其他未赋值变量的变量，“影响大的先查”。LCV则为选定变量先试对其他变量删值最少的值，“尽量给别人留余地”。

易错MRV与LCV方向看似相反，原因是对象不同：变量选择先处理紧迫问题，取值选择尽量不制造新问题。一次回溯后还必须恢复被删域，不能让某失败分支污染兄弟分支。

CSP 回溯：失败时恢复赋值与取值域

依据 Lecture 6 · PDF第7–13页整理

算法与流程 · 可直接复制
BACKTRACK(assignment, csp):
    if every variable is assigned: return assignment
    X ← SELECT-UNASSIGNED-VARIABLE(assignment, csp)
    for value in ORDER-DOMAIN-VALUES(X, assignment, csp):

6.3 前向检查与约束传播课件 14–19 页

前向检查在X赋值后，删除其未赋值邻居中不兼容的值。若某邻居域空，立即回溯。但它不会自动检查两个都未赋值的变量之间是否已没有兼容选择。

弧一致性要求：对有向弧Xi→Xj，Xi域中的每个值都能在Xj域里找到满足二元约束的支持值。没有支持的值应删除。若Xi的域变小，还可能使其他邻居失去支持，因此需要队列传播。

例题X、Y、Z的域均为{1,2,3}，约束X<Y、Y<Z。先修正X<Y删X=3、Y=1；再由Y<Z删Y=3并限制Z；继续回查可得到X=1、Y=2、Z=3。删一个域中的值，会改变另一条弧是否有支持。

AC-3反复取一条弧，REVISE删无支持值；若某域空则失败；若有删减，把指向该变量的相关弧重新入队。简单实现常见上界O(ed³)，e为弧规模、d为最大域大小，具体实现可改进。

难点弧一致不保证全局可满足。例如三个两两相邻的地区都只有红蓝两色，每条异色约束单独看有支持，但三角形不可能两色染色。

AC-3 与 REVISE

依据 Lecture 6 · PDF第16–19页整理

算法与流程 · 可直接复制
AC-3(csp):
    queue ← all directed constraint arcs (Xi, Xj)
    while queue is not empty:
        (Xi, Xj) ← POP(queue)
        if REVISE(Xi, Xj):
            if DOMAIN[Xi] is empty: return failure
            for Xk in NEIGHBORS[Xi] except Xj:
                INSERT(queue, (Xk, Xi))
    return success

REVISE(Xi, Xj):
    removed ← false
    for x in a copy of DOMAIN[Xi]:
        if no y in DOMAIN[Xj] satisfies CONSTRAINT(Xi=x, Xj=y):
            delete x from DOMAIN[Xi]
            removed ← true
    return removed

删除的是 Xi 中在 Xj 找不到支持的值。Xi 的域变小，会影响指向 Xi 的入弧，因此回队的是 (Xk,Xi)。success 仅表示没有发现空域、已经弧一致，不保证一般 CSP 已有全局解。

6.4 问题结构为何能降低复杂度课件 20–23 页

独立连通分量可分别求解，再组合答案。树形二元约束图没有环，选根并按父在前排列；从叶向根删掉父域中对孩子无支持的值，再从根向叶给每个孩子选与父一致的值，可在O(nd²)内完成。

树上之所以可以一遍赋值，是因为孩子之间没有额外回边；一般图的环会让先前局部相容的选择后来冲突。几乎是树的图可通过给少量环割集变量赋值或进行树分解利用结构，但代价随被条件化变量数量或树宽增长。

6.5 最小冲突法与皇后课件 24–26 页

局部CSP方法先给所有变量赋值，即使有冲突也保留完整候选。每轮挑一个冲突变量，改成使冲突数最少的值。N皇后可令每列一个变量，值为行号，约束是不同皇后不同行也不在同一对角线。

课件的大规模皇后结果说明某些结构化实例非常适合最小冲突，不意味着任意CSP都能常数时间求解。随机约束问题在某些约束密度附近容易出现“临界难区”，实例分布与结构会影响表现。

6.6 不同约束与高阶约束编码课件 27–33 页

变量可以离散、整数或连续；域可有限或无限；约束可以是一元、二元或涉及多个变量。硬约束必须满足，软约束则表达偏好或罚分。实际排程、资源分配和设计可能同时包含两者。

高阶关系可引入辅助变量，其取值域是允许的元组，再用二元相容约束连接原变量。例如辅助T=(x,y,z)只取满足x+y=z的组合，原变量必须等于对应分量。这保留逻辑关系，但辅助域可能很大，转换不是免费的。

SEND+MORE=MONEY的字母代表不同数字，首位S和M不能为0。除AllDifferent外，可引入进位c1…c4，例如D+E=Y+10c1，N+R+c1=E+10c2。一个解是9567+1085=10652。列约束使传播比直接枚举8个数字赋值更有效。

6.7 一般解空间与爬山法课件 34–42 页

路径搜索关心“怎样到那里”；一般解空间搜索常只关心最终配置。状态是一个完整候选解，邻域定义一步怎样改动，目标函数评价好坏。若目标可微，可沿梯度方向改善；若只能评估方案，也能使用邻域比较。

爬山法每次移到更好的邻居。局部最优附近所有一步邻居都差，但远处可能有更优点；平台让方向难区分，山脊使轴向小步难以沿正确斜方向前进。允许横移、随机重启或改邻域可缓和问题，但不带来任意有限预算的全局保证。

随机搜索不利用局部坡度，可能更容易跳到远处区域，但也可能浪费已获得的结构信息。课件通过二者对照引出结合局部改进与随机探索的方法。

6.8 模拟退火课件 43–47 页

最大化问题中，较好邻居总接受；若变化Δ=f(new)−f(old)<0，以exp(Δ/T)概率接受。高温T大时更愿意接受差解，低温时更像保守爬山。最小化记号常写exp(−Δcost/T)，不能把两种Δ定义混用。

例题收益下降2，T=4时接受概率e^(−0.5)≈0.607；T=0.5时为e^(−4)≈0.018。同一坏步在早期可能用于跳出局部盆地，后期很少接受。

理论上的全局收敛需要可达性与足够慢的降温等条件；工程中有限步数的降温通常是折中。不能仅凭“用了随机数”断言已经越过所有局部最优。

模拟退火：最大化与最小化的符号对应

依据 Lecture 6 · PDF第44–47页整理

算法与流程 · 可直接复制
SIMULATED-ANNEALING(initial, schedule):       // 最大化 Value，与课件一致
    current ← initial
    for t ← 1, 2, ...:
        T ← schedule(t)
        if T = 0: return current

6.9 局部束搜索与遗传算法课件 48–53 页

局部束搜索同时保存k个候选，联合产生后继，再挑k个保留，候选之间会共享选择压力。它不等于k个独立随机重启；若全部集中到同一盆地，还需保持多样性。

遗传算法把候选编码成个体，经历初始化、适应度评估、选择、交叉和变异。选择偏向好个体，交叉重组片段，变异产生新变化。若编码让交叉后大量违反约束，便需要修复或不同算子；“生物学比喻”本身不保证优化效果。

6.10 工程实例与收敛条件课件 54–59 页

“容易评价一个方案”不等于“容易反向求出最好方案”。零阶优化只依赖函数值，不需要梯度；若搜索有正概率沿有限路径到达最优区域，并满足合适的持续探索条件，才有相应渐近论证。课件中的个别工程提升数字只属于其所引示例，不作为所有进化算法的通用比例。

6.11 没有免费午餐定理课件 60–66 页

设有限搜索域X、有限输出集合Y，对所有目标函数f:X→Y作均匀对称平均，并考虑相应非重复查询设定。已经查询m个不同位置后，每一种与观测一致的未知剩余映射都有相同计数：|Y|^(|X|−m)。若没有任何结构偏好，下一个未知位置没有先天更值得查。

因此在这些条件下，不同算法对所有函数的平均表现相同。一个算法擅长某类结构化函数，必须在别处付出相应代价。现实任务远非均匀随机函数，所以利用平滑性、局部性、约束结构或棋盘知识仍然非常有效。

重点No Free Lunch反对“脱离问题结构的万能最优算法”，不是反对算法改进，也不说明所有方法在实际数据上同样好。

7.1 知识库智能体与Wumpus世界课件 1–16 页

知识库KB保存用形式语言表达的句子。TELL把新事实加入KB，ASK查询哪些结论可由KB推出。知识智能体先把感知加入知识库，再推断动作，最后记录自己做了什么。

Wumpus世界是带陷阱、怪物、金子的格子环境。breeze暗示相邻有坑，stench暗示相邻有怪物，glitter提示金子。智能体只看到局部线索，必须组合历史知识判断哪里安全。相邻通常指上下左右，不含对角，推理时不能悄悄改变邻接规则。

例如令P12表示(1,2)有坑，P21表示(2,1)有坑，B11表示(1,1)有微风。规则可写B11↔(P12∨P21)。若观察¬B11，可推出¬P12且¬P21。若观察B11，却不能单独确定是哪一格有坑。

重点没有推出“有坑”，不等于已经推出“无坑”。未知应保留为未知，不能用程序变量默认False替代逻辑结论。

课件连续探索页展示知识如何逐次收紧：每一次安全移动都会带来新感知；新句子与旧规则合起来排除更多世界。遇到“所有可能移动都有未排除风险”时，确定逻辑的保证可能不足，需要后来概率决策的方法。

7.2 语法 语义 模型与蕴含课件 17–26 页

语法定义怎样的符号串是合法句子；语义定义句子在某个世界解释中何时为真。模型是一种使句子为真的解释，不是机器学习里训练出的模型参数。

KB⊨α表示每个满足KB的模型也满足α，即Models(KB)包含于Models(α)。判断蕴含是在所有与知识相容的世界中检查，不能只挑一个让自己满意的例子。

KB⊢α表示一个指定推理程序或证明系统可以从KB推导α。可靠性要求“能推导就被蕴含”；完备性要求“被蕴含就能推导”。一个推理器很快但不可靠，会得出假保证；可靠但不完备，则可能漏掉真实可推结论。

难点蕴含是语义关系，推导是操作过程。正确性与终止性也不同；某程序若永远运行，不能只因“从未输出错结论”就说它足以解决全部查询。

7.3 命题连接词与真值表课件 27–33 页

命题符号代表真或假的原子事实。¬表示否定，∧合取，∨析取，→蕴含，↔双条件。这里的∨通常是“至少一个真”，不是生活语言中排他的“二选一”。

PQP∧QP∨QP→QP↔Q
真真真真真真
真假假真假假
假真假真真假
假假假假真真

P→Q等价于¬P∨Q，只在P真而Q假时为假。P假时蕴含为真，不是在断言现实因果；它只是当前形式语言的真值定义。

有n个命题变量共有2^n个赋值模型。真值表枚举逐一检查：若某赋值满足KB却不满足α，便找到反例；全部没有反例则蕴含成立。方法直观、可靠且完备，但指数枚举会成为瓶颈。

7.4 等价 有效与可满足课件 34–36 页

逻辑等价表示两句在所有模型中同真同假。常用关系包括双重否定、交换律、分配律、德摩根律，以及P→Q≡¬P∨Q、P↔Q≡(P→Q)∧(Q→P)。

有效句在每个模型都真；可满足句至少有一个模型为真；不可满足句没有真模型。P∨¬P有效，P∧¬P不可满足，单独P可满足但不有效。

证明KB⊨α可转为证明KB∧¬α不可满足。其原因是：若后者可满足，那个模型恰好就是KB真而α假的反例。

例题KB={P→Q,P}。加入¬Q后，由P→Q的等价形式¬P∨Q可先推出Q，再与¬Q冲突，因此KB⊨Q。若KB={P→Q,Q}，不能反推P；P假Q真就是反例。

7.5 前向链与确定子句课件 37–48 页

确定子句可写成P1∧…∧Pk→Q，前提是原子合取，结论为一个正原子；事实是没有前提的特殊情况。Horn子句一般指至多一个正文字，确定子句恰有一个，两者范围有细微差别。

前向链从已知事实出发，把满足全部前提的规则触发，加入新事实。高效实现为每条规则记录尚未满足的前提数，某事实首次被推得时更新相关规则，不必每轮从头反复扫描。

agenda ← 初始事实
每条规则count ← 前提数量
重复取事实p：
    若p是查询，成功
    若p尚未处理：
        标记已处理
        对包含p为前提的规则，count减1
        count为0时，把其结论加入agenda

例如事实A、B，规则A∧B→C、C→D，依次得到C与D。正确性来自每次触发都满足假言推理；对有限命题确定子句，达到不动点后，若仍缺目标，就不存在该子句体系中尚未触发的有限证明。每个事实只需处理有限次，能得到线性级于知识库表示规模的实现。

PL-FC-ENTAILS(KB, query):
    count[c] ← number of premises in each definite clause c
    inferred[p] ← false for every symbol p
    agenda ← known positive facts in KB

7.6 后向链与目标导向课件 49–60 页

后向链从查询D开始，寻找结论为D的规则，再把规则前提当子目标。例如要D，需要C；要C，需要A和B；事实中已有A和B，于是完成证明。

它不必推出大量与当前查询无关的事实，适合问答式调用；但需要防止循环子目标，也可能反复证明相同子问题。前向链适合不断加入事实、许多目标共享后果的情况。这里的可靠完备性要在适当规则类别和搜索控制条件下讨论。

7.7 归结与合取范式课件 61–65 页

文字是原子或其否定，子句是文字的析取，CNF是多个子句的合取。归结从A∨P与B∨¬P推出A∨B，消去一对互补文字。反证时把KB∧¬查询变为CNF，反复归结，若得到空子句就矛盾。

CNF转换先消去↔与→，用德摩根律把否定推到原子，再用分配律把∨分配过∧。例如P→(Q∧R)变为(¬P∨Q)∧(¬P∨R)。大型公式的直接分配可能膨胀，实际SAT编码常使用辅助变量保持可满足性，属于实现层的进一步技术。

子句1：¬P ∨ Q
子句2：P
归结得到：Q
查询否定：¬Q
再次归结：空子句 □
难点归结一般是反证完备的，即不可满足的子句集可通过适当归结找到矛盾；不是每个策略都能高效找到，也不是任取一个析取文字就可随意删掉。

7.8 SAT DPLL与局部搜索课件 66–72 页

SAT问一个命题公式是否存在满足赋值。DPLL是系统性的回溯：检查子句状态，做单子句传播和纯文字简化，必要时选变量分支。单子句只剩一个可真文字时必须满足它；纯文字只以一种极性出现时，可以选择使它为真的值。

例题F=(A∨B)∧(¬A∨C)∧¬C。单子句¬C迫使C假；第二子句迫使A假；第一子句再迫使B真，于是得到满足赋值。这里不是三次猜测，而是传播迫使的选择。

WalkSAT从完整随机赋值开始，找未满足子句，再随机或贪心翻转其中变量，以减少未满足数。它可迅速找到某些大公式的满足解；但有限步失败不能证明不可满足。DPLL的穷尽式搜索与WalkSAT的随机局部改进，保证性质不同。

随机3-SAT常在特定子句/变量比例附近难解，课件用景观说明实例分布的重要性。临界现象不是对每个具体公式的复杂度预测，更不是证明一般SAT简单。

DPLL(clauses, symbols, model):
    if all clauses are true under model: return true
    if some clause is false under model: return false
    if a pure unassigned symbol P with value v exists:
        return DPLL(clauses, symbols - {P}, model ∪ {P=v})

8.1 一阶逻辑的基本构件课件 1–11 页

常量命名对象，如John；变量指代未指定对象，如x；函数把对象映射到对象，如Father(x)；谓词对对象或关系给真假判断，如Student(x)、Loves(x,y)。项由常量、变量和函数应用构成，原子句由谓词应用或相等关系构成。

模型需要一个对象域，并解释常量指哪个对象、函数怎样映射、谓词在哪些对象元组上成立。相同句子在不同域或关系解释中可以真假不同。函数Father(x)的值是对象，不是“父亲关系成立”的布尔值。

重点语法正确不等于语义正确。即使Loves(John,Car1)形式合法，它表示什么仍取决于知识域和谓词解释。

8.2 全称与存在量词课件 12–18 页

“每个学生都勤奋”写∀x(Student(x)→Diligent(x))。“有一个勤奋学生”写∃x(Student(x)∧Diligent(x))。全称限制对象类别常用蕴含，存在声明对象需同时满足属性常用合取。

若把前者写成∀x(Student(x)∧Diligent(x))，就说世界里所有对象都是学生；若把后者写成∃x(Student(x)→Diligent(x))，一个非学生就可能使它成立，不能保证勤奋学生存在。

量词顺序重要。∀x∃y Loves(x,y)是“每个人至少爱某人”，不同x可配不同y；∃y∀x Loves(x,y)是“有同一个人被所有人爱”。同类量词可交换，不同类一般不能。

否定量词遵循¬∀xP≡∃x¬P，¬∃xP≡∀x¬P。相等x=y表示两个项指同一对象，不仅是字符串相同；通常需与同一性替换规则配合理解。

难点变量的绑定范围必须清楚。把两个独立规则中都叫x的变量直接当成同一个对象，是作用域错误；合并推理前常需变量标准化分离。

8.3 用情况描述变化与框架问题课件 19–27 页

Wumpus知识库可用Situation表示某个动作历史，Result(a,s)表示在s执行a后的情况。动态谓词如Holding(Gold,s)明确依赖情况，不把“现在拿着”与“过去拿着”混成同一个命题。

效果公理说明动作改变什么，例如在金子处执行Grab后拿到金子。框架公理说明什么不变，例如抓金子不应让箭消失。若每个动作都为所有无关属性写不变公理，表示和推理都会很冗长。

后继状态公理对每个属性统一写：“下一时刻P成立，当且仅当某动作使P成立，或P原来成立且当前动作没有使它失效”。例如：

Holding(Gold,Result(a,s)) ↔
  ((a=Grab ∧ AtGold(s)) ∨ (Holding(Gold,s) ∧ a≠Release))

资格问题关心动作成功可能需要无穷细节条件，如金子是否被粘住；连带效应问题关心动作引发的间接后果，如移动物体带走附着灰尘。后继状态公理主要处理表示层面的框架问题，不会自动解决全部现实建模。

规划可问“是否存在动作序列p，使执行后Holding成立”。PlanResult递归执行序列。通用定理证明能表达这种查询，但专门规划器通常更善于利用行动结构。

8.4 实例化与命题化的边界课件 28–34 页

全称实例化从∀xP(x)得到P(t)，t是合适的项。存在实例化给见证引入新的名字，不能擅自用一个已有对象冒充：从“有人聪明”不能直接推出John聪明。

没有函数符号且常量有限时，可枚举许多落地实例并转成命题推理。但带函数后会有Father(John)、Father(Father(John))等无限项，命题化可能永无止境。

一般一阶逻辑蕴含半可判定：被蕴含的结论存在有限证明，适当完备过程可最终找到；不被蕴含时可能一直寻找。不能期待一个对所有一阶知识库都能可靠、完备且总终止的通用算法。

8.5 合一与广义假言推理课件 35–37 页

替换θ把变量映射成项；合一寻找使两个表达式替换后相同的θ。最一般合一子不做不必要的额外限制，其他合一可由它继续实例化得到。

表达式一表达式二可用替换或结果
Knows(John,x)Knows(John,Jane)x=Jane
Knows(John,x)Knows(y,OJ)y=John，x=OJ
Knows(John,x)Knows(y,Mother(y))y=John，x=Mother(John)
Knows(John,x)Knows(x,OJ)若John与OJ不同则失败：x需同时等于二者

先把独立句子的变量改成互不相同的名字，可避免最后一类“名字碰巧重复”造成错误约束。经典有限项合一通常还需出现检查，防止x被替换成包含自身的f(x)，否则不再是有限项替换。

广义假言推理把可统一的前提与规则连接。例如King(x)∧Greedy(x)→Evil(x)，已知King(John)及Greedy(y)，用合适实例推出Evil(John)。可靠性来自全称实例化后应用普通假言推理。

算法与流程 · 可直接复制
UNIFY(x, y, θ):
    if θ = failure: return failure
    x ← APPLY(θ,x); y ← APPLY(θ,y)
    if x = y: return θ

    if y is a variable: return BIND(y,x,θ) unless y occurs inside x
    if x,y have the same outer symbol and arity:
        for each corresponding argument pair (xi,yi):
            θ ← UNIFY(xi,yi,θ)
        return θ
    return failure

θ = {y/John, x/Mother(John)}

这是对课件定义与例子的算法化展开；加入 occurs check，排除 x=f(x) 这种有限项无法满足的循环替换。不同规则每次使用前要 standardize apart，给变量换新名字。

8.6 一阶前向链与犯罪知识库课件 38–43 页

课件的West例子包含American(West)、Missile(M1)、Owns(Nono,M1)、Enemy(Nono,America)，以及“导弹是武器”“敌国是敌对方”“West向Nono出售其拥有的导弹”“美国人向敌对方出售武器构成犯罪”等规则。

8.7 后向链与Prolog课件 44–55 页

后向链从查询找规则，规则前提成为子目标，通过合一传递变量替换。朴素深度优先可能陷入循环，也可能反复求相同子目标；循环检测、缓存或tabling可改善，但需遵守适用语义。

Prolog用事实和形如结论 :- 前提的规则表达知识，通常按规则与子目标顺序进行搜索。顺序虽不一定改变声明含义，却会改变终止和效率。

append([], Y, Y).
append([X|L], Y, [X|Z]) :- append(L, Y, Z).

这两条既能拼接两个列表，也能回答append(A,B,[1,2])，枚举A=[]、[1]、[1,2]及对应B。这体现关系式程序与仅能“输入两个列表输出一个”的函数写法的差异。

家谱例子的谓词参数顺序必须由定义解释。课件中daughter规则若写father(X,Y)∧female(Y)，其参数约定实际把X当父亲、Y当女儿，不应仅凭英文谓词名就把顺序读反。查询grandfather(X,yuqing)需要沿父亲关系连接中间人。

8.8 一阶归结与Skolem化课件 56–59 页

一阶CNF转换包括消去蕴含、推进否定、标准化变量、Skolem化、去掉隐含全称量词、分配合取析取。归结时还要统一互补文字，并将替换应用到剩余文字。

∀x∃y Loves(y,x)中的见证可依赖x，因此y应换成Skolem函数F(x)；∃y∀x Loves(y,x)里的见证对所有x相同，可用新常量c。误用常量会把“人人有人爱”加强成“同一个人爱所有人”。

难点Skolem化通常保持可满足性，而不是在原语言中逐模型保持逻辑等价；引入了新的符号与解释。反证归结需要的是相应的可满足性关系。

课件“爱所有动物的人被某人爱”的CNF，在标准化与Skolem化后可得到两类子句：Animal(F(x))∨Loves(G(x),x)，以及¬Loves(x,F(x))∨Loves(G(x),x)。观察F与G都依赖外层x，而不是同一个全局见证。

9.1 为什么从逻辑转向概率课件 1–8 页

一句“开车30分钟能到”往往有拥堵、天气等未列条件，难以给出绝对保证。概率不是承认“逻辑不正确”，而是用数字表达给定知识下的不确定程度。模糊概念的程度与对事件真假的不确定性也不完全相同。

决策需要同时考虑概率和效用。某动作成功率高却损失极大，未必比稍低成功率但后果温和的动作更好。最大期望效用原则写成a*=argmax_a Σs P(s|证据,a)U(s,a)，概率模型与偏好模型分别承担不同作用。

9.2 概率的语法与基本运算课件 9–16 页

随机变量可取有限离散值或连续值。事件是可能取值/世界的集合。联合概率P(A,B)表示同时成立，边缘概率P(A)=ΣbP(A,b)，条件概率P(A|B)=P(A,B)/P(B)，要求P(B)>0。

概率满足非负、总和为1和不交事件可加。两事件相加应减交集：P(A∨B)=P(A)+P(B)−P(A∧B)。连续变量用密度和积分，单点密度值不是“恰好该点的概率”；密度可以大于1，只要积分为1。

乘积法则P(A,B)=P(A|B)P(B)可连用形成链式分解。这个等式永远成立，不要求独立；独立才允许把条件去掉。

易错P(A|B)与P(B|A)分母不同，不能交换。条件概率通常表达“信息给定后的分布”，本身不等于因果干预。

9.3 联合分布枚举与归一化课件 17–22 页

完整联合表为每个变量组合保存概率。查询P(X|e)时固定证据e，对隐藏变量Y求和：P(X|e)=αΣY P(X,e,Y)，最后归一化使X各值之和为1。

若两个候选值的未归一化权重为0.06与0.14，答案为0.3与0.7。α只是1/(0.06+0.14)，不是额外主观权重。若证据概率为0，普通条件概率没有定义，不能用任意小常数悄悄替代并仍声称精确推断。

9.4 独立 条件独立与Bayes公式课件 23–27 页

独立A⊥B表示P(A,B)=P(A)P(B)。条件独立A⊥B|C表示给定C后P(A,B|C)=P(A|C)P(B|C)。给定原因后症状可能独立，不表示不给定原因时也独立。

由联合概率两种写法相等，P(A|B)P(B)=P(B|A)P(A)，得到Bayes公式：P(A|B)=P(B|A)P(A)/P(B)。分母可用全概率展开。

例题工厂次品率1%，检测器对次品报警率90%，对良品误报率5%。报警后的次品概率是0.9×0.01/[0.9×0.01+0.05×0.99]≈15.38%。报警可靠性不能只看90%，还要看大量良品带来的误报。

9.5 贝叶斯网络的全局与局部语义课件 28–35 页

贝叶斯网络由有向无环图与每个节点在父节点给定下的条件概率表CPT构成。联合分布分解为P(x1,…,xn)=∏iP(xi|Parents(Xi))。

课件报警网有Burglary盗窃B、Earthquake地震E、Alarm报警A、JohnCalls电话J、MaryCalls电话M，结构为B→A←E，A→J、A→M。其联合为P(B)P(E)P(A|B,E)P(J|A)P(M|A)。

若n个二值变量每个至多k个父节点，局部表大致需O(n2^k)参数，而完整联合表有2^n−1个自由参数。节省来自条件独立结构，不是图画得简洁就自动拥有更高真实性。

局部Markov语义是：给定父节点后，一个变量与其非后代条件独立。图上的箭头可按因果知识构造，但仅从统计拟合得到依赖边，不能自动宣布证明了因果方向。

9.6 三种基本路径与解释消除课件 30–38 页

链A→B→C和共同原因A←B→C，在给定中间B后路径被阻断；碰撞点A→B←C在未观察B及其后代时阻断，观察B或其后代反而可能打开路径。这是d-separation的基本图形。

报警例中，盗窃与地震原可独立。得知报警后，两者成为竞争解释；再得知地震，会减少“必须由盗窃解释报警”的需要，称explaining away。它是由条件化引起的依赖变化，不是说两个自然事件突然相互作用。

一个节点的Markov blanket包括父、子以及子的其他父。给定这些后，该节点与图中其他节点条件独立。Rain的blanket可能含Cloudy、WetGrass及Sprinkler，因为Sprinkler也是WetGrass的原因。

9.7 构建网络与紧凑条件分布课件 37–41 页

可按合适顺序加入变量，为每个变量选择足以使它与已加入其余变量条件独立的父集合。不同顺序可能让同一联合分布得到稀疏或稠密的图，结构选择有计算代价。

确定性节点可直接用函数表达结果，如逻辑门或总和，不需独立列出全部自由概率。Noisy-OR假设多个原因各自独立地尝试触发结果；若当前有的原因触发率为p1…pk，无漏因时P(结果假)=∏i(1−pi)。触发率0.6与0.8的两个原因给真概率1−0.4×0.2=0.92。

这种简化依赖“独立因果影响”等额外假设；任意CPT不能不加论证地换成Noisy-OR。汽车诊断网的价值在于把观测、部件故障与依赖关系组织起来，使更新证据后可系统传播判断。

9.8 精确推断与变量消去课件 42–49 页

枚举算法在证据确定后对隐藏变量求和，但可能在不同分支重复算相同子表达式。变量消去把中间结果缓存为因子：因子是若干变量取值的函数，不一定自身归一化为分布。

消去变量X时，找出所有包含X的因子相乘，再对X求和，生成新因子。与X无关的因子可以移出求和。点乘要求公共变量取值对齐，例如f1(A,B)f2(B,C)成为f(A,B,C)。

9.9 无关变量与复杂度课件 50–52 页

未观测且不影响查询或证据的后代常可删去。例如P(J|B)中，没有被观察也没有后代证据的M，求和ΣmP(m|A)=1，所以不影响结果。

图分离判断需使用正确图规则。若用moral graph，道德化前应限制到查询、证据及待判断变量等相关祖先子图，再连接共同父并去掉箭头；不能在完整图中随便删箭头，就声称等价于所有d-separation判断。

9.10 先验采样与拒绝采样课件 53–64 页

先验采样按拓扑顺序取值：先采无父节点，再根据已采父值查CPT。生成一个完整事件的概率恰是局部条件概率之积，也就是网络联合分布。因此样本频率在适当大数定律条件下趋近目标先验概率。

拒绝采样先生成完整样本，证据不匹配就丢弃，在保留样本中统计查询。保留率约为P(e)。证据稀少时，生成一百万条也可能只剩很少可用条。

例题证据概率10⁻⁴，希望平均得到1000条保留样本，预期需约10⁷次采样。增加原始样本数不如先改变采样方法有效。

9.11 似然加权为何能避免直接拒绝课件 65–72 页

似然加权固定证据变量，只采其他变量，样本权重为各证据条件概率乘积w=∏jP(ej|Parents(Ej))。查询分布用权重累计，再归一化。

9.12 MCMC与Gibbs采样课件 73–81 页

MCMC构造一个在完整变量赋值之间移动的Markov链，固定证据，反复只改一部分非证据变量。Gibbs每次从P(Xi|其余变量当前值)采样，由网络结构可只看Markov blanket。

局部条件需要归一化：P(xi|mb)∝P(xi|parents)∏子节点Zj P(zj|parents)。课件第81页的乘积式应理解为未归一化权重，不能忽略最后除以各候选权重总和。

例如二值变量两种候选权重为0.18与0.06，实际采样概率是0.75与0.25。把0.18直接当概率会使总概率小于1。

链需满足适当不可约、非周期等条件才能得到所需稳态性质；强确定性约束可能让局部更新无法在不同可行区域间移动。即便稳态正确，有限运行也会受初始偏差、自相关和混合速度影响。100个样本不等于100个独立样本。

9.13 从分布距离到KL散度课件 82–87 页

变分推断用优化代替采样，先要说明怎样衡量分布差异。KL(q||p)=E_q[ln q(z)−ln p(z)]，离散情形为Σq ln(q/p)。它非负，q=p时为0，但不对称，也不满足一般距离的三角不等式。

若q在p=0处仍给正质量，KL可能无穷。最小化KL(q||p)在受限近似族中常倾向避免把质量放进p很小的区域；这可能忽略某些模式，但不能只凭方向就保证某次优化会如何收敛。

9.14 ELBO怎样绕开未知证据课件 88–92 页

后验p(z|x)=p(x,z)/p(x)中的p(x)正是难计算的归一化常数。取近似q(z)，有：

KL(q||p(z|x))
= E_q[log q(z) − log p(x,z) + log p(x)]
= log p(x) − E_q[log p(x,z) − log q(z)]

ELBO(q) = E_q[log p(x,z) − log q(z)]
log p(x) = ELBO(q) + KL(q||p(z|x))

因为KL非负，ELBO是log p(x)的下界；x固定时，最大化ELBO等价于在可选q族中最小化这方向的KL。ELBO中的第一项奖励对联合模型的解释，减log q项对应q的熵。

难点最大化下界不意味着一定得到精确后验。q族可能表达不了依赖，优化也可能停在局部解；“下界提高”与“真实后验已完全还原”是不同层次的结论。

从 Bayes 公式推到 ELBO

依据 Lecture 9 · PDF第88–91页整理

KL(q || p(θ|y))
= E_q[log q(θ) − log p(θ|y)]
= E_q[log q(θ) − log p(y,θ)] + log p(y)
ELBO(q) = E_q[log p(y,θ) − log q(θ)]
log p(y) = ELBO(q) + KL(q || p(θ|y)) ≥ ELBO(q)
ELBO(q) = E_q[log p(y|θ)] − KL(q || p(θ))

θ 是隐变量或参数，y 是观测，q 是我们选择的近似分布。把 Bayes 分母 log p(y) 从 KL 中移出来，得到“常数=下界+非负差距”。因此固定观测时，最大化 ELBO 等价于最小化 q 到真实后验的 KL；计算 ELBO 需要联合密度与 q，而不必先算出后验归一化常数。

10.2 决策树的表达能力与假设空间课件 13–15 页

决策树在内部节点测试属性，分支对应结果，叶子给预测。有限布尔输入的任意函数都可以用一棵足够大的树表示：沿路径询问所有属性，最后按真值表给标签。

按属性A分裂后的剩余不确定性为Σv P(A=v)H(Y|A=v)，信息增益Gain=H(Y)−H(Y|A)。课件个别页把剩余熵写成I(X;split)，此处按该页定义读取；它不是通常信息论中表示互信息的同名符号。

餐厅例中原来6正6负，熵为1 bit。按Patrons分裂后剩余约0.459 bit，增益约0.541；按餐厅类型仍约1 bit，增益0，因此优先顾客数量。

10.5 连续属性 增益率与Gini课件 23–28 页

连续属性先排序，在相邻不同取值之间尝试阈值，变为x≤t和x>t两组。课件重量例可在95与98之间分：小的一组5个，1甜4不甜；大的一组8个，6甜2不甜。剩余熵约(5/13)0.5004+(8/13)0.5623=0.5385，增益约0.1517。

ID这样的属性能把每个训练样本单独分叶，剩余熵为0，却无法为新ID提供可靠规律。增益率以Gain/IV校正，IV=−Σv P(v)log P(v)是分裂本身的信息量。分母为0要特别处理；增益率也不是对无意义特征的万能判别器。

Gini=1−Σc pc²，纯节点为0。CART常选择使加权子节点Gini最小的二分；ID3使用信息增益，C4.5使用增益率并处理连续、缺失等情况。训练错误率可能在许多候选分裂上相同，熵/Gini仍能区分纯度，所以它们提供更细的优化信号。

易错更大信息增益、更低训练误差都不直接保证泛化更好。属性泄漏、样本ID和过深树可能使训练指标漂亮而测试失败。

10.6 最近邻的预测与计算成本课件 29–34 页

1-NN复制最近训练样本的标签；k-NN分类可用多数或距离加权投票，回归可用平均或加权平均。它把“输入接近则输出接近”作为先验，得到非线性边界，天然能处理多类。

距离度量需要与数据语义匹配。欧氏距离受量纲影响，特征标准化常很重要；离散类别用任意整数编码后算距离可能制造错误顺序。选择k也影响平滑程度：小k对局部噪声敏感，大k更平滑但可能抹去小结构。

n样本、d维时，直接算所有距离需O(nd)。维护k个最近者还需选择或堆开销，例如O(n log k)，因此常可写O(nd+n log k)；课件给出的是一种较粗的实现量级。低维索引可能加速，高维距离集中会降低许多索引的优势。

1-NN在适当正则条件、样本充分多时，其渐近错误可与Bayes最优错误建立上界关系；二分类常见界不超过2R*(1−R*)≤2R*。这是有条件的渐近结果，不表示任意小样本都达到“两倍最优”保证。

课件说“无训练时间”应理解为无需复杂参数拟合，仍需存储、预处理和可能建立索引。预测慢、训练集存储大、度量敏感是主要代价。

10.7 从Bayes决策到朴素贝叶斯课件 35–40 页

0–1分类损失下选择后验最大的类：argmax_y P(y|x)=argmax_y P(x|y)P(y)，因为P(x)对各类相同。类别先验可由频率估计。

多个特征的联合条件分布难估，朴素贝叶斯假设在类别给定时特征条件独立：P(x|y)=∏jP(xj|y)。它不要求特征在整体数据中独立。例如颜色与重量可因共同类别产生相关，给定类别后再近似分解。

score(y) = log P(y) + Σj log P(xj|y)
预测 argmax_y score(y)

用对数避免很多小概率连乘下溢。需要真正后验时再用稳定归一化，而不是把未归一化分数直接当概率。条件独立近似即使不完全真实，分类边界仍可能有效；概率校准却未必好。

10.8 零计数与Laplace平滑课件 41–43 页

课件5个样本的例子中，yes有2个、no有3个。测试颜色3、重量3时，未归一化权重为0.1与0.06，所以yes后验0.625、no为0.375，而不是“0.1就是10%”。

若颜色或重量取值在某类未出现，频率0会让整个乘积归零。Laplace平滑用(count+1)/(类样本数+可能取值数)。先验类别若也平滑，分母用总样本数+类别数。

测试颜色0、重量1时，平滑后yes权重=(1/6)(1/7)(3/7)≈0.010204，no权重=(2/7)(1/8)(4/7)≈0.020408，因此no约2/3。颜色有4种、重量有5种，两个条件概率的分母不能写成一样。

11.1 训练误差 真实误差与版本空间课件 1–7 页

训练误差εt是在样本上的平均损失；泛化误差εg是对未知测试分布D的期望。版本空间保存与已见样本完全一致的假设，随着新样本加入不断删除不一致假设。若数据含噪或真实函数不在H中，版本空间可能变空。

i.i.d.假设要求训练样本独立地来自同一分布，未来测试也与该分布对应。采集方式变化、时间漂移或重复样本泄漏都会影响这一前提。固定真实目标f是课件简化设定，不能把训练集与测试集“文件名不同”当成统计独立的证据。

重点训练误差由我们看到的数据计算，真实误差定义在整个分布上；理论与验证集是估计后者的不同工具。

11.2 偏差方差分解课件 8–13 页

固定测试点x，反复抽取训练集D，学习器得到hD(x)。令平均预测为h̄(x)=E_D hD(x)，在无噪声平方损失下：

E_D[(hD(x)−f(x))²]
= E_D[(hD(x)−h̄(x))²] + (h̄(x)−f(x))²

展开平方后交叉项为0，因为E_D[hD−h̄]=0。第一项是方差，反映不同训练集造成的波动；第二项是偏差平方，反映平均预测离真值的距离。有噪声且满足相应条件时，还会出现不可约噪声项。

简单模型可能稳定却系统性偏离，复杂模型可降低某些偏差，却可能对样本变化敏感。训练误差常随复杂度增加而下降，测试误差却可能回升。这个经典权衡是分析框架，不应说所有现代模型都必然出现同一条U形曲线。

难点这类推导需要说明期望针对训练集和测试点怎样取。课件第8页的“训练MSE”字样不宜机械照搬；对用于拟合的同一批样本，模型和样本并不独立，不能无条件套测试预测分解。

平方误差的偏差方差分解

依据 Lecture 11 · PDF第8–13页整理

E_D[(h_D(x)−f(x))²]
= E_D[(h_D(x)−h̄(x)+h̄(x)−f(x))²]
= E_D[(h_D(x)−h̄(x))²] + (h̄(x)−f(x))²
= variance(x) + bias²(x)

f(x) 是固定的无噪声目标函数，h_D 是在随机训练集 D 上学出的预测器，h̄=E_D h_D。加入并减去 h̄ 后展开平方；交叉项因 E_D(h_D−h̄)=0 消失。有标签噪声时，还要再加不可约噪声项。

11.3 训练一致情形的泛化界课件 14–18 页

假设有限H、独立样本、存在与训练完全一致的h。若某坏假设真实错误率大于ε，它恰好不犯错地通过m个训练点的概率至多(1−ε)^m≤e^(−mε)。

我们不是提前固定一个h，而是可能从整个H中挑，所以用并集上界：P(存在训练一致却错误率>ε的h)≤|H|e^(−mε)。令右边≤δ，解得足够样本量m≥[ln|H|+ln(1/δ)]/ε，或相应的误差上界。

以至少1−δ的概率，对训练一致的候选有：
εg(h) ≤ [ln|H| + ln(1/δ)] / m
例题|H|=1000，δ=0.05，希望ε≤0.1，足够条件约m≥(ln1000+ln20)/0.1≈99.03，因此向上取100。这个上界常保守，不表示少于100必定学不会。

H更大提高表达力，但ln|H|使挑到偶然拟合坏假设的风险上升；增加样本可以抵消部分风险。无限参数空间需用其他复杂度度量，不能把∞代入ln|H|后就说无法学习。

有限假设空间的一致学习泛化界

依据 Lecture 11 · PDF第14–18页整理

P(存在训练一致但真实误差≥ε的假设)
≤ |H|(1−ε)^m ≤ |H|e^(−mε)
若 m ≥ [ln|H|+ln(1/δ)]/ε，失败概率≤δ。
等价地，以至少1−δ概率：εg ≤ [ln|H|+ln(1/δ)]/m

单个真实错误率至少 ε 的坏假设，偶然通过 m 个独立样本的概率不超过(1−ε)^m。再对有限 H 中所有候选用并合界，最后令该上界不超过 δ。这里需要 i.i.d.、有限 H 及无训练错误等相应前提。

11.4 有训练错误的情形与PAC课件 19–23 页

对固定h，分类错误指示变量在[0,1]，Hoeffding给出经验平均偏离期望的尾界。再对有限H作并集界，可得到常见单侧式：

εg(h) ≤ εt(h) + sqrt((ln|H| + ln(1/δ))/(2m))

以至少1−δ概率同时约束H里的候选。为了得到这个上界，应控制εg−εt的正尾概率；课件第21页中间写出的相反差值，与最后想证明的上界方向不一致，阅读时按该目标校正。

PAC是Probably Approximately Correct：以高概率达到近似小误差。可PAC学习还包含样本与计算资源随关键参数多项式增长等要求；“有好假设”不等于“能高效找到”。

易错δ不是分类错误率，而是理论保证可能失败的概率；ε是期望预测误差门槛。把置信度1−δ与测试准确率混成一个百分比会读错结论。

11.5 决策树过拟合与剪枝课件 24–30 页

课件重新观察复杂树的边界。树越深越能隔离单点噪声，训练错误下降但边界碎片增加。预剪枝可限制深度、样本数或增益；后剪枝先建树，再用更简单叶子替换某子树。

Reduced-error pruning用验证数据比较替换前后错误，若不变差便接受简化。用训练集判断剪枝可能继续偏好过拟合结构；用测试集反复选择又泄漏测试信息。斜决策树的测试可为线性组合，而不只沿单坐标轴分裂，表达能力和学习难度都改变。

11.6 线性回归与最小二乘课件 31–37 页

预测ŷ=wᵀx+b。线性是对参数线性；若先把x映射为多项式特征φ(x)，模型可以对原输入呈现非线性。平方损失L=(1/m)Σ(ŷi−yi)²，惩罚偏差的大小。

把截距并入扩展特征得到矩阵形式。无正则且XᵀX可逆时w=(XᵀX)⁻¹Xᵀy；不可逆时可以用伪逆或更稳定数值分解。实际实现不宜把显式求逆当成唯一方法。

中心化数据时b=ȳ−wᵀx̄，w可写成协方差与方差矩阵的关系。多重共线性会使解对数据扰动敏感，系数很大但训练误差仍小，这引出正则化。

最小二乘正规方程与截距

依据 Lecture 11 · PDF第34–35页整理

L(w)=||Xw−y||²/m
∇L(w)=(2/m)Xᵀ(Xw−y)=0
XᵀXw=Xᵀy
w=(XᵀX)⁻¹Xᵀy    [仅在 XᵀX 可逆时]
b=ȳ−wᵀx̄

令 X 的每一行是一个样本，r=Xw−y。写成平均平方损失时，梯度前有2/m，令其为零后消失。若含截距，可对 x、y 中心化，最后还原 b；矩阵不可逆时需用伪逆或稳定数值分解，而不是硬求逆。

11.7 Ridge LASSO与LAD课件 38–43 页

Ridge最小化L+λ||w||²，偏好小幅度权重，缓和病态。若L定义为平均平方损失，正规方程是(XᵀX+mλI)w=Xᵀy；若平方损失用求和形式，常写(XᵀX+λI)。课件的简写应连同归一化定义读取，不能漏掉m后继续声称数值相同。

LASSO用L+λ||w||1，L1在0处的几何形状有利于产生稀疏系数，常用于选择部分特征。LAD则改变数据误差为Σ|ŷ−y|，与LASSO的“惩罚权重绝对值”不是一回事。

11.8 梯度下降与优化条件课件 44–46 页

梯度指局部增长最快方向，下降更新w←w−η∇L。平方损失的梯度为(2/m)Xᵀ(Xw−y)，L2再加2λw。η太大可能越过低谷并发散，太小则慢。

凸函数满足f(αx+(1−α)y)≤αf(x)+(1−α)f(y)。在适当可微性、步长等条件下，梯度下降可逼近全局最小；凸性本身不保证任意步长都成功。L1与hinge在某些点不可微，需次梯度、近端或专门求解法。

11.9 线性分类 感知机与逻辑回归课件 47–53 页

线性分类用sign(wᵀx+b)，标签±1。带符号间隔m=y(wᵀx+b)为正表示分对。0–1损失I(m≤0)直接计错误，但不连续且难优化。

感知机替代损失max(0,−m)；逻辑回归用log(1+e^(−m))，对应P(y|x)=1/[1+exp(−y(wᵀx+b))]的负对数似然。逻辑回归虽叫“回归”，这里用于分类概率建模。

概率为正类时σ(z)=1/(1+e^(−z))，logit=ln[p/(1−p)]=z。它把无界线性分数映射为0到1。交叉熵梯度鼓励预测概率接近标签，不是先阈值化再求导。

11.10 支持向量机与最大间隔课件 54–57 页

12.1 交互闭环与长期回报课件 1–13 页

智能体在状态st选择at，环境返回奖励rt+1与下一状态st+1，形成轨迹s0,a0,r1,s1,a1,r2…。策略π(a|s)是动作概率，确定策略则直接给a=π(s)。

目标通常是最大化期望回报Gt=Σk≥0 γ^k rt+k+1。0≤γ<1使远期奖励折扣，并在有界奖励下帮助无限和收敛；有限幕任务也可使用不折扣回报，但需有终止等条件。奖励是任务定义的一部分，不一定等于人类笼统的“好”。

规划通常在已知转移和奖励模型上求行动；强化学习从交互样本学习，模型可能未知。监督数据往往被动给定，强化学习的动作会改变后续数据分布，存在延迟反馈和信用分配。

课件将一般二进制优化编码成终末奖励树，说明隐式大状态空间能包含难问题；这不表示任意显式给出的有限折扣MDP都同样NP-hard。复杂度要按状态表示和输入规模分析。

12.2 Markov过程与稳态分布课件 14–16 页

Markov性为P(st+1|st,…,s0)=P(st+1|st)：当前状态已经包含预测下一步所需的历史信息。“无记忆”不表示智能体不能存数据，而是模型的状态设计把相关历史压进当前状态。

课件天气链可用行随机矩阵P表示，从晴、阴、雨到下一天气的三行分别为(0.2,0.7,0.1)、(0.3,0.3,0.4)、(0.2,0.5,0.3)。分布向量μt+1=μtP，不能把单个离散状态符号直接当成分布矩阵乘。

稳态μ满足μ=μP。存在稳态与从任意初态都收敛到同一稳态是不同结论；唯一性与收敛需要不可约、非周期等相应条件。给定当前天气，采样下一天并不断重复，就能生成链轨迹。

12.3 Markov奖励过程与Bellman期望方程课件 17–20 页

MRP在转移中加入奖励。在常用记号下V(s)=E[rt+1+γV(st+1)|st=s]。这是把无限未来拆成“眼前一步+剩下同类问题”。

若固定策略下的期望即时奖励向量为r，有V=r+γPV；当γ<1等条件成立，V=(I−γP)⁻¹r。也可从V0=0开始反复迭代Vt+1=r+γPVt，无需显式求逆。

例题只有一个状态，每步奖励1并回到自身，γ=0.9。V=1+0.9V，所以V=10。迭代值为0、1、1.9、2.71…，逐步累计越来越远的未来。

有限时域的递推还应带时间下标，终点VT=0后向计算。课件前几页省略γ的式子可按有限和或当时约定理解，不应因此断言无限无折扣任务总有有限价值。

Bellman 期望备份与单状态算例

V(s)=Σ_s′ P(s′|s)[R(s,s′)+γV(s′)]
V = r + γPV ⇒ (I−γP)V=r
γ=0.9，r=1，P=1：V=1+0.9V=10

12.4 MDP 策略与Q函数课件 21–28 页

MDP加入动作集合A，转移P(s′|s,a)和奖励R(s,a,s′)受动作影响。固定策略后就诱导一个MRP。m个状态、k个可选动作时，确定策略最多k^m种；看似少量状态也会产生大策略空间。

Vπ(s)是从状态s开始按π行动的回报，Qπ(s,a)是先选a、之后按π行动的回报。关系为Vπ(s)=Σaπ(a|s)Qπ(s,a)，Qπ(s,a)=Σs′P(s′|s,a)[R+γVπ(s′)]。

最优值满足V*(s)=maxaQ*(s,a)，进而得到Bellman最优方程：V*(s)=maxaΣs′P(s′|s,a)[R+γV*(s′)]。MAX针对自己的动作，期望针对环境转移；双人对抗若对手可策略性行动，不能直接用固定MDP替代。

重点有限状态动作、折扣小于1且奖励有界等标准条件下，存在合适的最优确定平稳策略，Bellman最优算子有唯一价值不动点。γ=1或非终止任务需另行分析。

12.5 策略迭代与价值迭代课件 29–33 页

策略迭代先评价当前π得到Vπ，再令新策略选择argmaxaQπ(s,a)。因为选到的动作在旧价值衡量下不差于原动作，反复展开一步期望即可证明新策略价值不低于旧策略，这就是策略改进定理的直觉。

策略迭代：
    初始化策略π
    重复：评价π的价值；对每状态选贪心动作改进π
    策略不再改变时结束

价值迭代：
    V0=0
    Vt+1(s)=max_a Σs′ P(s′|s,a)[R+γVt(s′)]
    变化足够小时提取贪心策略

同步更新全部使用上一轮Vt；异步更新可立刻使用已更新值，但需要恰当访问和收敛条件。最优算子在折扣设定下是γ收缩：||TV−TW||∞≤γ||V−W||∞，因为期望和最大操作不会把最大差放大到超过该界。

维数灾难来自状态数而非公式长度。棋盘的所有合法配置可能天文庞大，即使每次Bellman更新是简单加法乘法，也无法逐状态存表。

12.6 从未知模型到Monte Carlo学习课件 34–39 页

Model-based方法估计R与P后求解或规划；model-free方法直接从样本学习价值或策略，并非完全没有任何表示模型，而是不显式建立环境动力学。

MC评价在完整幕结束后计算实际回报G，对访问过的(s,a)求平均。首次访问与每次访问方式统计位置不同，实际实现需约定。策略改进再根据Q选择动作。

如果只按当前贪心策略走一条路径，没走过的动作永远得不到纠正，因此需要探索。评价过程也要注意正在被评价的策略是否随着数据不断改变，不能把任意混合历史平均都当成某固定π的无偏估计。

12.7 探索策略与on policy off policy课件 40–46 页

一状态MDP就是Bandit，故ε-greedy、softmax和UCB可用于动作层探索。ε-greedy给所有动作正概率，但这并不自动保证所有状态可达或被无限访问，仍取决于转移、起始分布和持续探索。

On-policy用某策略生成数据并评价/改进它；off-policy用行为策略b生成数据，却评价目标π。重要性采样通过ρ=∏k π(ak|sk)/b(ak|sk)矫正轨迹概率，前提是目标会使用的路径在行为分布中也有正概率。

这是E_p[f]=E_q[(p/q)f]在轨迹上的应用，环境转移因子在相同动力学下抵消。长轨迹的权重乘积可能极大或极小，方差会很高；“有理论矫正”不等于有限样本很好用。

12.8 增量平均与时间差分课件 47–50 页

平均值不用保存所有历史：μn=μn−1+(1/n)(xn−μn−1)。把1/n推广为学习率α，就得到旧估计加误差修正的形式。恒定α能适应非平稳变化，但不再是严格的等权样本平均。

MC目标为完整回报G；TD目标为rt+1+γV(st+1)，不等整幕结束就能更新。TD使用自己的未来估计来修正当前估计，称bootstrap。它通常减少等待和某些方差，也引入估计相依与偏差。

开车回家的例子中，起初预计总共30分钟，见到下雨后改为40；TD能立即把新信息传给前一状态，而MC要等实际43分钟结束后再回头修正。DP使用模型对所有后继求期望，TD从一次后继采样，MC沿整条实际轨迹。

12.9 SARSA与Q学习课件 51–53 页

SARSA用五元组(s,a,r,s′,a′)更新：Q(s,a)←Q(s,a)+α[r+γQ(s′,a′)−Q(s,a)]。a′由当前行为策略实际选出，所以它评价包含探索在内的策略，是on-policy控制。

Q-learning目标用maxbQ(s′,b)，即使行为仍ε探索，也朝贪心目标策略学习，是off-policy：Q(s,a)←Q(s,a)+α[r+γmaxbQ(s′,b)−Q(s,a)]。

悬崖行走例中，持续ε探索可能让沿悬崖的路线有真实掉落风险。SARSA把这种行为风险计入目标，可能偏安全；Q-learning学习理想贪心策略的价值，行为探索期间却仍可能跌落。这不是说其中一个永远更好。

终局未来项应为0。表格Q-learning的收敛还依赖充分访问、合适学习率序列等，不能把有限几次更新或任意恒定步长都称为已收敛。

SARSA 与 Q-learning 的完整回合

依据 Lecture 12 · PDF第51–53页整理

算法与流程 · 可直接复制
SARSA:
    initialize Q; for each episode:
        s ← initial state
        a ← ε-GREEDY(Q,s)
        while s is not terminal:
            (s_next,r,done) ← STEP(a)
            if done: target ← r
            else:
                a_next ← ε-GREEDY(Q,s_next)
                target ← r + γ × Q(s_next,a_next)
            Q(s,a) ← Q(s,a) + α × (target-Q(s,a))
            if done: break
            (s,a) ← (s_next,a_next)    // 执行刚才已采样的同一个 a_next

Q-LEARNING:
    initialize Q; for each episode:
        s ← initial state
        while s is not terminal:
            a ← ε-GREEDY(Q,s)
            (s_next,r,done) ← STEP(a)
            target ← r if done else r + γ × max_b Q(s_next,b)
            Q(s,a) ← Q(s,a) + α × (target-Q(s,a))
            s ← s_next

SARSA 的目标动作 a_next 是随后真的要执行的动作；不能更新后重新抽一个不同动作却仍声称是这条五元组。Q-learning 的 max 只决定学习目标，不意味着行为从此不再探索。

12.10 连续状态与函数近似课件 54–60 页

用V̂w(s)=wᵀφ(s)或Q̂w(s,a)=wᵀφ(s,a)代替为每个状态单独存表。特征可为粗编码、网格指示或核函数，近邻状态可以共享参数。共享带来推广，也可能让更新一个状态破坏另一个状态。

目标target与预测之间的平方误差给出更新w←w+α(target−Q̂)∇wQ̂。MC用实际G，TD用r+γQ̂(s′,a′)，Q-learning用r+γmaxbQ̂(s′,b)。TD常将目标中的未来估计在这一步视为固定，属于半梯度思路。

资格迹et=γλet−1+∇wV̂(st)把近期访问的梯度痕迹带到当前，允许一个TD误差影响多个过去状态。λ调节传播跨度，具体与MC或TD的等价关系依赖算法和步长设定，不能只令λ=1就宣称任意实现完全相同。

神经网络是非线性可微近似器，用反向传播传递梯度。函数近似、bootstrap、off-policy组合可能不稳定，不能直接继承有限表格算法的所有保证，这为下一讲DQN的稳定化机制提供背景。

函数近似的半梯度 Q-learning

算法与流程 · 可直接复制
for each transition (s,a,r,s_next,done):
    target ← r if done else r + γ × max_b Q_w(s_next,b)

13.2 自编码器与PCA的联系课件 6–8 页

编码器z=fθ(x)，解码器x̂=gφ(z)，以重建损失如||x−x̂||²训练。中间瓶颈迫使模型保留足够重建的结构，而不是逐输入维度原样抄写。

若网络容量不受限，学会恒等映射并不令人惊讶，表示也未必有用。低维瓶颈、去噪、稀疏性或其他约束赋予学习目标结构。线性单瓶颈、平方重建等条件下，自编码器与主成分子空间有关；一般非线性网络能表达不同于PCA的弯曲结构，但优化和泛化仍需检查。

课件展示先逐层预训练、再整体微调的历史流程，并比较低维表示中的类别结构。图上分得开是有用现象，但不能只看可视化就断言所有下游任务提升。

13.3 卷积的稀疏连接与权重共享课件 9–10 页

全连接让每个输出依赖所有输入；卷积让一个输出只看局部窗口，同一个卷积核在各位置复用参数。前者是稀疏局部连接，后者是权重共享，两者是不同概念。

一个kH×kW卷积核跨越全部Cin输入通道，单输出通道计算局部点积再加偏置。Cout个核得到Cout张特征图，参数数为kH·kW·Cin·Cout+Cout，不随输入图像的宽高逐像素增加。

例题输入32×32×3，用8个3×3核、stride1、padding1，输出32×32×8；参数为3×3×3×8+8=224。特征图每个位置重复使用同一组224参数，不是每个像素都有独立224个参数。

输出单维长度为⌊(n+2p−k)/s⌋+1，假设普通卷积、给定padding和步长且没有膨胀等扩展。7×7输入、3×3核、p=0、s=2，输出3×3；公式中的向下取整不能随意省略。

13.4 下采样 激活与多层结构课件 11–16 页

最大池化在局部区域取最大，平均池化取平均。2×2窗口步长2会压缩宽高，保留局部强响应；它引入一定局部稳定性，但不能声称对所有平移严格不变。卷积本身更接近平移等变：输入移动会带来输出位置对应移动，边界和步长会影响这种性质。

Sigmoid将值映到(0,1)，tanh映到(−1,1)，ReLU为max(0,x)。若层层只做线性变换，多层合成仍是一次线性变换；非线性使深度能表达更复杂函数。Sigmoid饱和区梯度小，ReLU可能出现长期无激活单元，各有使用条件。

反向传播是链式法则的高效组织：先前向计算并保存中间值，从损失向后累积各参数梯度，再由优化器更新。它不是网络结构，也不等于某一种优化器。课件未单列完整BP推导，这里补足理解后续DQN“更新CNN”所需的联系。

AlexNet等网络图展示卷积、非线性、池化与全连接的组合。GPU适合大规模张量运算；工具页中的框架名称属于当时课程背景，算法理解不依赖安装某个特定历史版本。

13.6 文本的one hot 顺序卷积与词袋卷积课件 27–31 页

词表大小|V|时，one-hot用一个维度表示一个词。窗口p个词若按位置拼接，region向量维数p|V|，保留窗口内顺序；seq-CNN在这些局部序列上卷积。

bow-CNN把局部窗口内词计数合成|V|维向量，减少参数但丢失窗口内部顺序，仍可保留不同窗口的位置结构。因此“局部词袋”不是“整篇文档完全无序”的同一个表示。

例如词表[don’t,hate,I,it,love]，“I love”与“love I”的局部词袋相同，而顺序拼接不同。需要区分词序的任务会受影响；样本不足时较低维的局部词袋可能更易学习，体现表达力与数据量的折中。

池化将不同长度文本的局部响应汇成固定维表示。浅层CNN直接在词嵌入或局部窗口上提取模式，字符CNN则把字母/字符作为输入，减少分词依赖但需学习更长程组合。课件的9层字符网络是一个具体结构，不是所有文本CNN必须有9层。

13.7 从Q学习到DQN课件 32–36 页

DQN用神经网络Qw(s,a)估计动作价值，以视觉帧等高维输入直接学习。若每次直接用当前连续经验并立刻用同一网络更新目标，样本相关、目标漂移和bootstrap容易导致不稳定。

经验回放把(s,a,r,s′,done)存入缓存，随机抽取小批次，减少相邻样本强相关并复用数据。目标网络w−延迟更新，构造y=r+γ(1−done)maxa′Qw−(s′,a′)，在线网络最小化(y−Qw(s,a))²。

使用ε贪心选择动作，执行并保存转移
从回放缓存随机取一批
终局样本：y=r
非终局样本：y=r+γ max_a′ Qtarget(s′,a′)
对在线Q网络做损失梯度更新
每隔一段时间用在线参数刷新目标网络

课件提及百万级缓存和batch32等是当时DQN实验配置，不是算法必须的固定常数。消融图比较回放、目标网络等机制贡献；它们改善稳定性，但不提供对任意环境和网络的普遍收敛保证。

DQN：经验回放与延迟目标网络

依据 Lecture 13 · PDF第34–36页整理

算法与流程 · 可直接复制
initialize replay buffer D
initialize online Q network parameters w and target parameters w_target ← w
repeat environment steps:
    a ← ε-greedy action from Q_w(s,·)
    (s_next,r,done) ← STEP(a)
    store (s,a,r,s_next,done) in D
    sample a minibatch of transitions from D
    for each sampled transition i:
        yi ← ri if done_i else ri + γ × max_b Q_w_target(s_next_i,b)

回放缓冲减弱相邻样本的强相关，目标网络让一段时间内的回归目标较稳定。它们改善训练，并不构成任意神经网络离策略学习的普遍收敛证明。课件中的100万条回放和32条小批量是历史实验设置，不是 DQN 的定义。

13.8 原始AlphaGo的分工课件 37–42 页

策略网络π(a|s)给动作概率，帮助筛选和排序；价值网络v(s)预测终局结果，减少大量rollout的需要；快速rollout策略能低成本模拟到终局；MCTS把这些估计整合到当前决策。

先用人类棋谱监督训练策略，再自我对弈用强化学习改进策略；价值网络用自我对弈产生的状态与终局结果训练。样本相关性需处理，不能把同一盘很多近似状态随便拆到训练测试后声称独立泛化。

原始系统的叶子估计组合价值网络与rollout结果，搜索边保存访问N、回报Q及策略先验P。选择时考虑价值与探索奖励，既利用网络，也通过实际模拟纠正某些局部估计。

重点本讲描述的是课件引用的原始AlphaGo体系，不把后来的AlphaGo Zero、AlphaZero等流程混进同一张训练图。策略网络回答“值得试什么”，价值网络回答“局面有多好”，搜索回答“考虑后续变化后现在选什么”。
