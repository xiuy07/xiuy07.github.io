# 讲义正文版改进说明

## 这次改变了什么

原版把707页课件图放在“课件原图”弹窗和逐页索引里，正文主要是中文解释。
新版按教材组织：重要算法、公式、算例和图例直接出现在对应主题正文中。
阅读正文不需要打开附件、切换原图弹窗或展开隐藏面板。

范围仍为13讲、120个主题，按原707页课件的知识顺序整理。
重复动画选取关键过程，标题页和重复视频占位页不机械重复排入正文。

- 新增53组可复制的算法与流程，包含一组内的辅助函数及完整控制流程。
- 新增28组独立公式推导、数值算例或符号对照。
- 182幅课件图例直接进入正文，配中文读图说明和实际PDF页码。
- 保留原有26幅重绘图解、5个互动演示、重难点与自测。
- 本地HTML嵌入全部正文图片，可离线阅读；网页版使用普通正文图片和懒加载。

## 源码和文件修改

1. **讲义生成器 `build_book.py`**：在每个主题结束、自测之前插入相关算法、公式与图例，并把新增内容加入搜索索引。
2. **新增 `textbook_material.py`**：保存按课件核对的算法、符号解释、图注和页码对应关系，生成正文材料；裁去图片的重复页眉，不把公式OCR结果当作准确原图。
3. **新增 `textbook.css`**：增加算法、推导、正文插图和图注排版，兼容手机、平板及打印。长算法可跨打印页，避免整块挤出页面。
4. **导出脚本 `prepare_web.py`**：把本地HTML内嵌图像替换为网页同目录的图片路径。图片是正文中的 `<img>`，接近阅读位置时加载，不需要点击才能看到。
5. **交付文件 `index.html`**：移除旧课件弹窗、707条弹窗按钮及其脚本；加入53组算法、28组推导/算例、182幅正文插图及图解定位索引。
6. **新增 `inline-assets/`**：保存182幅正文课件图例。原 `assets/` 的707幅完整页图仍留在私有仓库作资料备份，不参与正文阅读流程。
7. **新增验证脚本 `qa_textbook.cjs`**：检查主题覆盖、图片加载、无隐藏核心内容、目录链接、搜索、互动、离线版和打印输出。

生成器位于本次任务的本地工作目录；私有仓库保存可直接部署的HTML、图片和说明。
实验Lab2的目录、源代码及Word报告没有在这次改版中修改。

## 为便于实现而明确的约定与校订

伪代码是依据课件控制逻辑整理的可读版本，统一符号并补充边界情况，不声称是课件英文程序的逐字符转录。

- UCS/A* 用“插入改进条目，弹出时跳过过期条目”表达路径替换；A*保留重新进入队列的能力。
- BFS明确生成时目标测试版本，并与课件出队测试的计数约定区分。
- 回溯加入取值域快照恢复；AC-3在域为空时返回失败，避免只检查赋值而漏掉域变化。
- 前向链补充目标本身就是已知事实的处理；WalkSAT失败明确不等于不可满足。
- 一阶逻辑合一加入有限项的occurs check，说明变量改名及替换合成。
- Lecture12第32页未来项的一处下标与第33页不一致，正文使用正确的下一状态V(s′)，并在对应位置注明。
- SARSA继续执行更新时采样的同一个下一动作；终局的未来价值设为0。
- Ridge平均损失采用对应的mλ矩阵缩放，避免与求和损失约定混用。
- 图中的历史结果和课件模型按当时背景解释，未当作新的实测或当前排行榜。
