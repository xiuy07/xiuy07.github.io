# 第三方资源与许可

网页布局、SVG标志、代码、正文和教学数据为本次重新制作。

- Noto Sans SC：SIL Open Font License 1.1，来自本机安装的NotoSansSC变量字体，仅保留讲义使用字形，转换为WOFF2。许可见 `assets/fonts/OFL-NotoSansSC.txt`。
- Noto Serif SC：SIL Open Font License 1.1，来自本机安装的NotoSerifSC变量字体，子集化用于标题。许可见 `assets/fonts/OFL-NotoSerifSC.txt`。
- 代码区使用设备已有的Cascadia Code/Consolas等宽字体，未分发系统商业字体。
- 语法高亮类由Python-Markdown/Pygments生成，配色为自定义。运行时没有外部JavaScript依赖。

字体项目与许可证来源：

- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notoserifsc

正文参考来源见SOURCES.md。LeetCode只作为两道题的题型参考，题面与测试重新编写。
