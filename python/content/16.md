# 16 特征衍生与表格重塑

assign、map、字符串、日期与 melt

学习目标：从已有字段产生可解释的新变量，并理解长宽表。

## 衍生字段先写业务定义
订单收入=单价×数量，达标=分数≥60。定义决定缺失、异常值和单位如何传播。优先用整列算术、str/dt 访问器、map 或 assign；apply(axis=1) 虽方便，却常把向量问题退回逐行 Python 调用。

map 用字典映射时，未命中的键变成缺失；如果这是非法类别，应检查并报告，不能悄悄填成任意类别。字符串规范化时先明确是否保留原列，便于追踪清理。

## 时间是类型，不只是文本
`pd.to_datetime(..., errors="coerce")` 把无法解析的值转成 NaT；随后统计解析失败数。明确输入日期格式能避免歧义。`.dt` 提取年月、星期等特征；时区和自然日边界需要结合业务约定。

## 长表与宽表
melt 把多个测量列展开为变量列和值列。pivot 需要索引列组合唯一；存在重复时要先定义聚合，再用 pivot_table。别为了成功运行而随意选择 mean 掩盖重复记录。

## 运行示例

```python
import pandas as pd
df = pd.DataFrame({"item": [" tea ", "milk"], "price": [5, 8], "qty": [3, 2]})
df = df.assign(item=df["item"].str.strip().str.upper(), revenue=lambda x: x["price"] * x["qty"])
print(df[["item", "revenue"]].to_dict("records"))
wide = pd.DataFrame({"name": ["A"], "math": [80], "python": [90]})
print(wide.melt(id_vars="name", var_name="subject", value_name="score").to_dict("records"))
```

预期输出

```text
[{'item': 'TEA', 'revenue': 15}, {'item': 'MILK', 'revenue': 16}]
[{'name': 'A', 'subject': 'math', 'score': 80}, {'name': 'A', 'subject': 'python', 'score': 90}]
```

assign 中 revenue 的 lambda 接收当前表。melt 将一个学生的两列成绩变为两条记录，学生名字保留为标识字段。

运行：`python demos/16.py`

## 易错点

不要在不知道重复行含义时用 pivot_table 默认聚合；不要用逐行 apply 替代简单整列乘法。
