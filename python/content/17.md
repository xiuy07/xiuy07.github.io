# 17 数据清洗与预处理

缺失、重复、异常与数据泄漏

学习目标：记录清洗规则及损失的行数，保留可追溯性。

## 缺失不是某一个数
None、NaN、pd.NA、NaT 可能表示不同类型中的缺失。检测用 isna，不要用 `== NaN`。可空整数用 Int64，可空布尔用 boolean。某些运算传播缺失，聚合可能默认跳过缺失，不能只凭最终结果猜过程。

空字符串和字符串 "NA" 是否表示缺失需要业务约定。`to_numeric(errors="coerce")` 可将非法文本转为缺失，转换后应报告新增缺失数。填补方法取决于含义：未知年龄不等于0；缺失销量也未必表示没有销售。

## 去重必须说明键与保留规则
drop_duplicates(subset=["id"], keep="last") 表示同一id保留最后出现的记录；如果“最新”由时间字段定义，应先解析并排序时间。整行相同不等于业务上重复，反之亦然。

## 异常值与泄漏
IQR、分位数和业务范围都可用于识别可疑值，但检测不代表应直接删除。用于建模时，均值、标准差、缺失填充值等只能从训练集估计，再作用于验证或测试集，避免泄漏。保留原始列与清理日志，结果才可复核。

## 运行示例

```python
import pandas as pd
df = pd.DataFrame({"id": [1, 2, 2, 3], "score": ["80", "bad", "90", None]})
df["score"] = pd.to_numeric(df["score"], errors="coerce")
df = df.drop_duplicates("id", keep="last")
missing = int(df["score"].isna().sum())
df["score"] = df["score"].fillna(0).astype("Int64")
print(df.to_dict("records"))
print("filled", missing)
```

预期输出

```text
[{'id': 1, 'score': 80}, {'id': 2, 'score': 90}, {'id': 3, 'score': 0}]
filled 1
```

示例明确定义“保留最后行，缺失填0”，只是演示约定；真实成绩数据应确认0是否合理。先去重再统计缺失，结果为1。

运行：`python demos/17.py`

## 易错点

不要无记录地全表 fillna(0)；不要在分割训练测试数据前拟合清洗参数。
