# 13 NumPy 数组与广播

shape、axis、dtype 与视图

学习目标：用形状推导向量运算，避免错误的广播和溢出。

## 数组比列表多了什么
ndarray 用统一 dtype 描述元素，shape 描述各轴长度，ndim 是轴数，size 是总元素数。二维表 shape=(行数,列数)，`sum(axis=0)` 沿行方向消去第0轴，得到每列之和；`sum(axis=1)` 得到每行之和。

## 广播从右侧对齐
两个形状从最右侧逐维比较，维度相同或其中一个为1即可兼容。`(3,2) + (2,)` 让同一行向量作用于每一行；`(3,2) + (3,)` 不兼容。按行减均值时使用 `mean(axis=1, keepdims=True)` 保持 (3,1)。

## 视图和副本
基本切片通常返回共享底层数据的视图，布尔索引和整数数组高级索引通常产生副本。需要独立修改就显式 copy。这里是 NumPy 的规则，不要直接套到不同版本的 pandas。

固定宽度整数存在溢出风险，除法还要定义分母为0如何处理。向量化减少 Python 层循环开销，但不应为中间广播结果制造巨大数组。

## 运行示例

```python
import numpy as np
a = np.array([[1, 2], [3, 4], [5, 6]], dtype=np.int64)
print(a.shape, a.sum(axis=0).tolist())
centered = a - a.mean(axis=1, keepdims=True)
print(centered.tolist())
b = a[:1]
b[0, 0] = 9
print(a[0].tolist())
```

预期输出

```text
(3, 2) [9, 12]
[[-0.5, 0.5], [-0.5, 0.5], [-0.5, 0.5]]
[9, 2]
```

axis=0 消去行轴后留下两列结果。每行的均值保持列维度1，广播为两列；切片 b 修改了共享数据。

运行：`python demos/13.py`

## 易错点

不要认为 int64 与 Python int 一样不会溢出；不要把视图当独立副本。
