## 使用者应该知道多少内部细节

假设区间有两个端点。业务代码只需要询问起点、终点和包含关系，不必到处写 `obj[0]`、`obj[1]`。把表示方式藏在小接口后面，未来改成dataclass时，调用者可以少改很多地方。

构造器负责建立合法值，选择器负责读取逻辑组成部分，操作函数负责组合它们。抽象边界不意味着神秘封装，而是明确“哪些约定允许调用者依赖”。

## 用property维护一个可检查的约束

### 先猜一猜：像读属性一样访问，也可以带计算和检查吗？

先在纸上写出输出，再运行这段代码。

```python
class Rectangle:
    def __init__(self, width, height):
        if width < 0 or height < 0:
            raise ValueError("negative side")
        self._width, self._height = width, height
    @property
    def area(self):
        return self._width * self._height

r = Rectangle(3, 5)
print(r.area)
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
15
```

area是计算得到的属性，访问时不写括号。这里没有setter，所以不能直接把area改成与边长不一致的值。下划线表示内部使用约定，并不是无法绕过的访问控制。

</details>

本例可单独运行：`python demos/features/24-property.py`。

## 一个对象如何接入Python语法

| 使用方式 | 常用协议入口 | 应保持的含义 |
|---|---|---|
| `len(obj)` | `__len__` | 非负整数长度 |
| `for x in obj` | `__iter__`，迭代器的`__next__` | 逐项产生，耗尽时StopIteration |
| `x in obj` | `__contains__`，或迭代回退 | 是否包含，不能误改数据 |
| `repr(obj)` | `__repr__` | 有助于识别和调试 |
| `a + b` | `__add__`等 | 返回符合约定的计算结果 |
| `with obj` | `__enter__` / `__exit__` | 明确资源进入与退出行为 |

Python语言层的特殊操作通常从类型上查找相应特殊方法。不要指望在某一个实例上随意挂一个同名属性，就能改变所有内置操作的行为。

## 可迭代对象与迭代器不要混成一个东西

容器的 `__iter__` 通常每次返回新的迭代器，以便两次循环相互独立；迭代器自己的 `__iter__` 通常返回self，当前位置随next变化。yield可以轻松实现一个可迭代容器的方法。

### 先猜一猜：两个for循环为什么不一定共享进度？

先在纸上写出输出，再运行这段代码。

```python
class Countdown:
    def __init__(self, start):
        self.start = start
    def __iter__(self):
        for value in range(self.start, 0, -1):
            yield value

items = Countdown(3)
a, b = iter(items), iter(items)
print(next(a), next(a), next(b))
print(list(items), list(items))
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
3 2 3
[3, 2, 1] [3, 2, 1]
```

每次调用iter(items)都创建一个新生成器，所以a推进两次不影响b。每次list(items)也取得新迭代器。对一个已经创建的生成器对象直接连续list，则会出现第07章的耗尽现象。

</details>

本例可单独运行：`python demos/features/24-iterable.py`。

## 比较、哈希与不可变对象

相等对象必须同哈希；同哈希不保证相等。若对象放进set以后，参与相等和哈希的状态改变，查找就可能失效。不可变值对象通常适合做字典键；普通可变记录通常不应随意强加hash。

`dataclass(frozen=True)` 可帮助约束字段重新赋值，但不能自动冻结字段里嵌套的可变对象。`slots=True` 限制常见实例属性布局，并非把整个对象变成不可变值。

## 接口相同，不要求共同父类

一个函数只需要遍历并求和时，可以接收任何合适的可迭代对象。typing.Protocol可描述静态接口约束；它帮助类型检查器沟通预期，并不会自动实现运行时业务校验。先让小接口含义清楚，再决定是否需要继承体系。

## 完整运行示例

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Window:
    start: int
    stop: int
    def __iter__(self):
        return iter(range(self.start, self.stop))
    def __len__(self):
        return max(0, self.stop - self.start)
    def __contains__(self, value):
        return value in range(self.start, self.stop)

w = Window(2, 5)
print(list(w), len(w), 4 in w, 5 in w)
```

预期输出

```text
[2, 3, 4] 3 True False
```

运行：`python demos/24.py`。
