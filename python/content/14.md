# 14 pandas 入门与数据获取

Series、DataFrame、索引与读入

学习目标：读入后先检查数据的形状、模式和缺失情况。

## 表格有标签
Series 是带索引的一维数据；DataFrame 是共享行索引、按列组织的表格。不同列可有不同 dtype。`df["score"]` 是 Series，`df[["score"]]` 是单列表，后续方法和形状不同。

从 CSV 读入时，先约定编码、字段含义和缺失标记；标识符例如001不能当成数字吞掉前导零，可指定 dtype。日期列用显式解析，错误值如何处理需事先定义。网页表格或 Excel 读取依赖额外包，最小可复现实验优先使用本包提供的 CSV。

## 五分钟数据体检
依次查看 shape、head、info/dtypes、isna().sum() 和关键列唯一性。head 只展示前几行，不能证明整列干净。空表也应该保留列模式，以便后续流程得到可预测输出。

## 标签自动对齐
两个 Series 运算按索引标签匹配，不按当前行位置配对。标签不一致会产生缺失，重复索引还会让对齐复杂化。位置运算可以显式转换为数组，但此时你放弃了标签保护。

## 运行示例

```python
import pandas as pd
from io import StringIO
df = pd.read_csv(StringIO("id,score\n001,80\n002,\n003,90\n"), dtype={"id": "string"})
print(df["id"].tolist())
print(df.shape, df["score"].isna().sum().item())
a = pd.Series([10, 20], index=["A", "B"])
b = pd.Series([1, 2], index=["B", "A"])
print((a + b).to_dict())
```

预期输出

```text
['001', '002', '003']
(3, 2) 1
{'A': 12, 'B': 21}
```

dtype 保留001；空分数读为缺失。a 的 A 与 b 的 A 配对，所以 A 为12，B 为21。

运行：`python demos/14.py`

## 手推与修改

把 b 的 A 改成 C，预测相加后的索引和缺失位置。

## 易错点

不要用首几行判断整列类型；不要忽略索引自动对齐。
