# 08 类与 Python 数据模型

dataclass、组合与特殊方法

学习目标：用小型类表达约束，而不是复制其他语言的样板代码。

## 从一个小问题开始

### 从“数据长什么样”走向“对象能做什么”

一个对象不一定要继承某个指定父类，才能被for遍历或被len询问长度。Python通过一组约定好的方法连接这些语言操作，这些约定称为协议。

### 先猜一猜：方法中的self是谁？

先在纸上写出输出，再运行这段代码。

```python
class Basket:
    def __init__(self, items):
        self.items = list(items)
    def __len__(self):
        return len(self.items)
    def add(self, item):
        self.items.append(item)

b = Basket(["tea"])
Basket.add(b, "milk")
print(len(b), b.items)
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
2 ['tea', 'milk']
```

b.add("milk")与Basket.add(b,"milk")在这个普通实例方法例子中完成相同操作。通过实例取方法时，实例会被绑定为第一个参数self。len(b)则使用类提供的__len__协议。

</details>

本例可单独运行：`python demos/features/08-method-binding.py`。

`__repr__` 偏重调试表示，`__str__` 偏重面向人的显示。`@property` 让属性访问经过计算或检查。`dataclass(frozen=True)` 限制字段重新赋值，但其中若存了列表，列表仍可能改变。更多完整例子见 [第24章](../content/24.md)。


## 实例状态与类状态
`self.items = []` 为每个实例建立列表；类体中的 `items = []` 会被实例共享。dataclass 可生成初始化、比较等常见方法；容器字段用 field(default_factory=list)。约束放在构造或方法入口，明确非法输入如何处理。

## 让对象遵循协议
`__len__` 支持 len，`__iter__` 支持遍历，`__repr__` 帮助调试。`__eq__` 与 `__hash__` 有契约：相等必须同哈希，放入哈希容器后参与哈希的状态不应改变。可变 dataclass 默认不提供可用哈希，通常是合理保护。

## 组合与继承
如果一个对象“使用”另一个对象，让它持有那个对象往往更简单。仅当子类确实能替代父类时才采用继承。Python 不要求所有可用对象继承同一基类：能提供所需方法即可，这称为鸭子类型；静态协议可用 typing.Protocol 描述。

普通业务数据先尝试 dataclass；不要为了两个字段建立复杂继承层级。重写特殊方法应维持调用者熟悉的含义。

## 运行示例

```python
from dataclasses import dataclass, field
@dataclass
class Notebook:
    owner: str
    pages: list[str] = field(default_factory=list)
    def __len__(self):
        return len(self.pages)

a, b = Notebook("Alice"), Notebook("Bob")
a.pages.append("objects")
print(len(a), len(b))
print(a.owner, a.pages)
```

预期输出

```text
1 0
Alice ['objects']
```

default_factory 每次构造时调用，得到独立列表。len(a) 通过 __len__ 获得页数。

运行：`python demos/08.py`

## 易错点

不要让可变实例内容参与稳定哈希；不要在 dataclass 中直接写列表默认值。
