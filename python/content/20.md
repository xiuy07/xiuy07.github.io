# 20 可视化与完整分析项目

从原始订单到可复核报告

学习目标：跑通读取、清洗、衍生、汇总、绘图和结论的闭环。

## 先问问题，再选图
比较类别用条形图，观察时间趋势用折线图，两个数值关系用散点图，分布用直方图或箱线图。图标题、轴标签、单位、排序、时间窗口必须明确。不要用截断的条形图纵轴夸大差异，不要只用颜色传递类别。

## 一个可重复的小项目
本包 data/orders.csv 是原创教学数据，含重复订单、空数量和非法数值。统一规则：同订单id保留最后行；price、qty转数值；删除缺失或负值；计算 revenue；按城市汇总；显式按城市排序。先保存清洗日志，再解释结果。

运行 `python demos/project.py` 会在当前目录的 project-output 中生成 cleaned.csv、summary.csv、report.json 和 revenue.png。图表使用英文轴标签以减少中文字体缺失问题；网页示例用中文解释字段。结果只是这份小数据的描述，不外推真实人群。

## 学完以后继续什么
课程导论还列出机器学习、神经网络与文本挖掘，但当前资料没有对应专题课件。本版覆盖已提供的模块1和2。后续学习路线：先补训练/验证分离与指标，再学线性模型和树模型；文本任务先明确分词、特征和评估，避免用训练集效果充当泛化能力。

交付报告应回答：数据来自哪里、一行是什么、删除了什么、分母是什么、结论适用什么范围。读者能够依据脚本和数据重现你的数值，才算完成分析。

## 运行示例

```python
import pandas as pd
df = pd.DataFrame({"city": ["A", "B", "A"], "price": [10, 5, 8], "qty": [2, 3, 1]})
df["revenue"] = df["price"] * df["qty"]
summary = df.groupby("city", as_index=False)["revenue"].sum().sort_values("city")
print(summary.to_dict("records"))
print("total", int(summary["revenue"].sum()))
```

预期输出

```text
[{'city': 'A', 'revenue': 28}, {'city': 'B', 'revenue': 15}]
total 43
```

同一城市先按订单计算金额再相加。A为20+8=28，B为15，总额43；不要用平均单价乘总数量代替逐行收入之和。

运行：`python demos/20.py`

## 手推与修改

设计两笔不同价格、不同数量的订单，证明 mean(price)*sum(qty) 不一定等于真实收入。

## 易错点

不要先选图再强找结论；不要把清洗规则藏在代码细节里。
