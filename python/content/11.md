## 从一个小问题开始

### 用不变式决定下一步

二分定位时，先说明左边满足什么、右边满足什么；BFS时，先说明队列为什么按距离分层。记住一个能维持的条件，比把循环模板背下来更可靠。

### 先猜一猜：一个重复值占据的下标范围如何找到？

先在纸上写出输出，再运行这段代码。

```python
from bisect import bisect_left, bisect_right
values = [1, 3, 3, 3, 8]
left = bisect_left(values, 3)
right = bisect_right(values, 3)
print(left, right, values[left:right])
print(max([], default=None))
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
1 4 [3, 3, 3]
None
```

left是第一个不小于3的位置1；right是第一个大于3的位置4。切片[1:4]正好覆盖全部三个3。max的default只在可迭代对象为空时使用，避免把合法最大值与“没有元素”混在一起。

</details>

本例可单独运行：`python demos/features/11-bisect.py`。

## 常见任务的标准库选择
频次统计用 Counter，分组收集可用 defaultdict(list)，队列用 deque，优先队列用 heapq，已排序序列定位用 bisect。记住容器维护的顺序或不变式，比背 API 更有用。

heapq 默认最小堆。维护最大的 k 个数时，堆中只保留 k 个候选，堆顶是其中最小的；新数大于堆顶才值得替换。时间 O(n log k)，空间 O(k)。k=0 必须先处理。

bisect_left 返回第一个不小于目标的位置，bisect_right 返回第一个大于目标的位置；相减得到重复次数。查找本身 O(log n)，但 Python 列表中间插入仍是 O(n)，不要把二分定位与搬移元素的成本混为一谈。

## 算法选择比微优化有效
两数和用哈希，匹配括号用栈，最短无权路径用 BFS。BFS 在入队时标记访问，避免同一节点重复入队；带权最短路需要其他算法，不能直接套 BFS。先写小规模正确版本，再用 timeit/cProfile 判断瓶颈。

## 运行示例

```python
from collections import deque
graph = {0: [1, 2], 1: [3], 2: [3], 3: []}
dist = {0: 0}
queue = deque([0])
while queue:
    u = queue.popleft()
    for v in graph[u]:
        if v not in dist:
            dist[v] = dist[u] + 1
            queue.append(v)
print(sorted(dist.items()))
```

预期输出

```text
[(0, 0), (1, 1), (2, 1), (3, 2)]
```

dist 同时存最短距离和已访问标记。节点3有两条路径，但入队一次；队列按距离层次处理节点。

运行：`python demos/11.py`

## 易错点
