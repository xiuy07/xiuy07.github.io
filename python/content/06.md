# 06 函数与参数机制

调用、默认值、作用域与注解

学习目标：把计算封装成无隐藏状态、可单独测试的函数。

## 从一个小问题开始

### 一次函数调用，分成四步看

先计算实参，再把值绑定给形参，接着执行函数体，最后取得返回值。定义函数时会创建函数对象，函数体此时不会执行。`f` 是函数对象，`f(3)` 是调用这个对象。

### 位置参数和关键字参数怎样对应

读签名 `def report(name, /, score=0, *, passed=60)`：name只能按位置传；score可以按位置或关键字传；passed只能写关键字。`/` 和 `*` 都是签名中的分隔符，不是这次调用的参数。

### 先猜一猜：同一个函数的两种调用，参数怎样绑定？

先在纸上写出输出，再运行这段代码。

```python
def report(name, /, score=0, *, passed=60):
    return f"{name}: {score >= passed}"

print(report("Lin", 58))
print(report("Lin", score=58, passed=50))
parts = ["Mei", 80]
options = {"passed": 70}
print(report(*parts, **options))
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
Lin: False
Lin: True
Mei: True
```

第一行使用默认passed=60。第二行只改变判定门槛。最后一行在调用位置解包：列表提供两个位置实参，字典提供passed关键字。定义处的 `*args` 用于收集，调用处的 `*parts` 用于展开，作用不同。

</details>

本例可单独运行：`python demos/features/06-argument-binding.py`。

先读懂参数绑定，再读下面的共享对象与默认值。高阶函数和闭包不需要另一套调用规则，见 [第21章](../content/21.md)。


## 参数绑定到对象
形参是局部名字。函数里给形参重新赋值不会重绑调用者的名字；修改共享的可变对象则会被调用者观察到。因此设计 API 时必须说明是否修改输入。优先返回新结果，确实需要原地操作时在名字或文档中说明。

## 默认值何时计算
默认参数在执行 def 时计算一次。`def f(x, history=[])` 会跨调用复用列表；使用 None 占位，在函数内部新建列表。`*args` 收集位置参数为元组，`**kwargs` 收集关键字参数为字典，单独的 `*` 要求后续参数只能按关键字传。

## 返回值和类型注解
没有 return 或裸 return 都返回 None。`return a, b` 返回一个元组。`def mean(xs: list[float]) -> float` 帮助阅读和静态检查，并不会自动验证传入值；输入校验仍需自己写。

局部名字先在函数作用域查找，再找外层、模块和内建作用域。不要依靠可变全局变量传递中间结果；尽量让函数输出只取决于输入。

## 运行示例

```python
def record(value, history=None, *, copy_input=True):
    if history is None:
        history = []
    elif copy_input:
        history = history.copy()
    history.append(value)
    return history

old = [1]
print(record(2, old), old)
print(record(3), record(4))
```

预期输出

```text
[1, 2] [1]
[3] [4]
```

默认 history=None 不保存之前的调用记录。显式复制传入列表让默认行为不修改调用者数据；copy_input=False 则选择共享。

运行：`python demos/06.py`

## 手推与修改

将 copy_input 改为False，写出 old 的最终内容；为什么追加整数与重绑整数表现不同？

## 易错点

别用可变对象作默认参数；不要把注解当作运行时类型验证。
