# 03 字符串与文本处理

切片、编码、拆分与正则

学习目标：把一段文本稳定地转换成结构化字段。

## 文本不是字节
str 是 Unicode 码点序列，bytes 是字节序列。`"中文".encode("utf-8")` 得到6字节；`len("中文")` 是2。可见字符也可能由多个码点构成，所以 len 不是排版宽度。文件读取明确写 `encoding="utf-8"`，不要猜测运行机器的默认编码。

## 字符串方法返回新值
字符串不可变，`strip`、`replace`、`lower` 都返回新字符串。`strip("ab")` 删除两端属于字符集合 {a,b} 的字符，不是删除完整前后缀；精确前缀用 `removeprefix`。`split()` 可合并连续空白，`split(",")` 保留中间空字段；CSV 包含引号和逗号时应交给 csv 模块。

切片 `[start:stop:step]` 不包含 stop，负下标从末尾算起。切片可越界，单个下标越界则抛 IndexError。拼接多段文本优先 `separator.join(parts)`。

## 什么时候使用正则
固定分隔符用 split，简单清理用字符串方法，变化的模式才用正则。`re.fullmatch` 校验整段，`re.search` 寻找局部。先写几个正反例，再写表达式；正则无法替代所有结构化解析器。

## 运行示例

```python
import re
raw = "  Alice: 88; Bob: 72  "
pairs = re.findall(r"([A-Za-z]+):\s*(\d+)", raw)
print([(name.lower(), int(score)) for name, score in pairs])
print(len("中文"), len("中文".encode("utf-8")))
```

预期输出

```text
[('alice', 88), ('bob', 72)]
2 6
```

findall 提取两组字符串；列表推导式同时规范名字、转换分数。模式中的 \s* 表示零个或多个空白。

运行：`python demos/03.py`

## 易错点

不要在字符串上调用 strip 后忘记接收返回值；不要手工按逗号解析有引号的 CSV。
