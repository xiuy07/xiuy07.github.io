## 递归函数先写一份承诺

例如 `count_leaves(tree)` 的承诺是“返回嵌套列表中非列表元素的数量”。读函数体时，先允许自己相信更小输入上的调用能履行承诺，再检查当前层如何把这些结果组合起来。

这只是一种设计与检查方法；正确性还需要基例成立、每次调用更接近基例，并且组合规则符合定义。不要通过“把整个调用树无限展开”来理解所有递归。

### 先猜一猜：空列表算一个叶子吗？

先在纸上写出输出，再运行这段代码。

```python
def count_leaves(tree):
    if not isinstance(tree, list):
        return 1
    return sum(count_leaves(child) for child in tree)

print(count_leaves([1, [2, 3], []]))
print(count_leaves([]))
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
3
0
```

非列表元素是叶子，直接贡献1。列表把子项结果相加；空列表的求和为0，所以不是一个叶子。第一个输入的三部分分别贡献1、2、0。

</details>

本例可单独运行：`python demos/features/22-nested-leaves.py`。

## 一条调用链：调用时展开，返回时收拢

考虑 `power_two(n)`：当n=0返回1，否则返回2乘上更小问题的答案。调用n=3时，外层乘法需要等内层返回。

| 阶段 | 当前要解决的事 | 尚未完成的乘法 |
|---|---|---|
| 调用3 | 计算power_two(2) | 2×? |
| 调用2 | 计算power_two(1) | 2×(2×?) |
| 调用1 | 计算power_two(0) | 2×(2×(2×?)) |
| 基例0 | 返回1 | 开始逐层交回 |
| 返回 | 依次得到2、4、8 | 最外层得到8 |

每次调用都有自己的n。内层把n变小，不会改写外层n。Python不会普遍进行尾递归消除；很深的链状递归可以触发RecursionError，线性累计常用循环更稳妥。

## 树递归：一个问题需要多个子问题

假设走到第n层，最后一步只可能跨1层或3层。两类路线互不重叠，可以把数量相加。负层数没有路线，到第0层有一条“什么也不走”的空路线。

`ways(n) = ways(n-1) + ways(n-3)` 体现的是“按最后一步分解”。只有分类完整且不重复，才能直接相加。换一组步长，递归关系也会改变。

### 先猜一猜：为什么到0层的路线数是1？

先在纸上写出输出，再运行这段代码。

```python
def ways(n):
    if n < 0:
        return 0
    if n == 0:
        return 1
    return ways(n - 1) + ways(n - 3)

print([ways(n) for n in range(6)])
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
[1, 1, 1, 2, 3, 4]
```

空路线是继续组合其他路线的起点，故ways(0)=1。对于3层，路线是1+1+1或3，共2条；对于4层，还包括1+3和3+1。若把基例改为0，所有向上组合都会被错误地抹成0。

</details>

本例可单独运行：`python demos/features/22-tree-recursion.py`。

## 缓存改变重复工作，不改变问题定义

上面的调用树会多次遇到同一n。`functools.cache` 保存已算过的实参对应结果；它要求参数可哈希，缓存状态会占内存。它适用于这类纯计算，不适合结果取决于变化外部状态的函数。

不加缓存时，本例分支调用数量随n快速增长；加缓存后，非负状态只有n+1种，每种只需常数次组合。若按固定宽度算术估计，时间与状态数成线性关系；Python大整数位数增长仍会带来额外算术成本。递归深度仍可能是O(n)，缓存没有消除调用栈。

## 先判断是否值得使用递归

嵌套数据天然按“当前项+子项”定义，递归常更清楚；几十万项的一条线性序列则更适合迭代。写完先检查空结构、一个元素、最小非基例，再对小规模输入与循环或暴力版本核对。

## 完整运行示例

```python
from functools import cache

@cache
def ways(n):
    if n < 0:
        return 0
    if n == 0:
        return 1
    return ways(n - 1) + ways(n - 3)

print(ways(8))
print(ways(20))
```

预期输出

```text
13
1278
```

运行：`python demos/22.py`。
