# 15 选择、筛选与安全赋值

loc、iloc 与布尔掩码

学习目标：把筛选条件和赋值目标写在同一个操作中。

## 从一个小问题开始

### 把筛选条件先当作一列布尔值

先单独计算mask，再观察每行True/False，最后交给loc。不要一开始把所有操作压进很长的一行。

<details class="checkpoint" markdown="1">
<summary>检查理解：索引是[10,20,30]时，loc[10:20]和iloc[0:2]分别选什么？</summary>

前者按标签选10到20且包含右端；后者按位置选0和1。这个例子结果相同，但规则不同。

</details>


## 标签和位置分清楚
loc 使用标签，标签切片通常包含右端；iloc 使用从0开始的位置，切片不含右端。整数索引可能就是业务标签，不代表位置。单个标量可用 at/iat，初学阶段统一 loc/iloc 更易检查。

## 向量条件
多个 Series 条件用 `&`、`|`、`~`，每个比较表达式加括号。Python 的 and/or 需要单个真值，不能直接用于一列。`isin` 适合多个候选值判断，缺失条件需用 isna/notna 显式处理。

## 一次定位完成赋值
使用 `df.loc[mask, "score"] = value`，不要写 `df[mask]["score"] = value`。后者操作的是中间对象，无法表达对原表的可靠修改。在 pandas 3.0 默认且唯一的 Copy-on-Write 模式下，链式赋值不会按预期更新原表；本讲义所有修改都显式定位原表。

要独立加工筛选结果时使用 `.copy()` 表达意图。区分“返回子集”与“修改原表”，不要让调用者猜测副作用。

## 运行示例

```python
import pandas as pd
df = pd.DataFrame({"name": ["A", "B", "C"], "score": [58, 80, 95]}, index=[10, 20, 30])
mask = (df["score"] >= 60) & (df["score"] < 90)
print(df.loc[mask, "name"].tolist())
df.loc[df["score"] < 60, "score"] = 60
print(df.loc[10:20, "score"].tolist())
print(df.iloc[0:2]["name"].tolist())
```

预期输出

```text
['B']
[60, 80]
['A', 'B']
```

条件选出B。loc[10:20] 包含两个标签；iloc[0:2] 选前两行，也恰好两行，但语义不同。
