# 09 异常、文件与结构化数据

with、路径、CSV 与 JSON

学习目标：把脏数据和程序错误区分处理，明确资源生命周期。

## 从一个小问题开始

### 先写清“哪一种失败可以恢复”

用户把分数写成unknown，可以记录坏行并继续。程序把score键写错成scroe，则需要修复代码。两种失败都返回空列表，会让你失去定位问题的证据。

### 先猜一猜：正常返回和异常退出，清理会执行吗？

先在纸上写出输出，再运行这段代码。

```python
from contextlib import contextmanager

@contextmanager
def section():
    print("enter")
    try:
        yield
    finally:
        print("leave")

try:
    with section():
        print("body")
        raise ValueError("bad row")
except ValueError:
    print("handled")
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
enter
body
leave
handled
```

进入with时推进到yield之前，执行enter。with中的代码抛异常后，异常被交回生成器；finally仍运行leave。异常没有被这个管理器吞掉，随后由外层except处理。

</details>

本例可单独运行：`python demos/features/09-context-manager.py`。

这是用生成器编写上下文管理器的方式。这里的yield应恰好执行一次；不要把这个用途与“生成多项数据”混为一谈。


## 看 traceback 的最后几行
异常包含类型、消息和调用位置。只捕获能恢复的异常，例如把文本转整数时捕获 ValueError。裸 except 会连中断也吞掉；过宽的 Exception 捕获会把程序缺陷伪装成正常空结果。

try 的 else 在 try 正常完成时执行；finally 负责必做清理，但不应写 return 覆盖原结果或异常。with 使用上下文管理协议管理资源，正常返回和异常退出时都会尝试关闭文件。

## 路径与编码
相对路径基于当前工作目录，而非总是脚本目录。需要脚本旁的数据时，用 `Path(__file__).resolve().parent` 构造。open 明确指定 encoding；默认值受 Python 版本、平台和 UTF-8 模式影响。CSV 可用 utf-8-sig 处理带 BOM 的文件。

## 数据格式对应解析器
CSV 用 csv.DictReader，JSON 用 json.loads/json.load。JSON 的 null、true、false 分别转为 None、True、False。解析成功不代表业务字段有效，还需检查必填字段、类型和取值范围。不要用 eval 读取外部文本。

## 运行示例

```python
import csv, io, json
text = 'name,score\nAlice,88\nBob,unknown\nCai,0\n'
good, rejected = [], 0
for row in csv.DictReader(io.StringIO(text)):
    try:
        score = int(row["score"])
    except ValueError:
        rejected += 1
        continue
    good.append({"name": row["name"], "score": score})
print(json.dumps(good, ensure_ascii=False))
print("rejected", rejected)
```

预期输出

```text
[{"name": "Alice", "score": 88}, {"name": "Cai", "score": 0}]
rejected 1
```

0 是合法值，不能被当作缺失删除。这里只跳过数值格式错误，缺少 score 字段仍会暴露 KeyError，便于发现模式变化。

运行：`python demos/09.py`

## 手推与修改

把第二条 unknown 改为0，再把 score 表头改名，分别说明应该恢复还是报错。

## 易错点

不要用 split(",") 替代 CSV 解析；不要把解析失败悄悄替换为0。
