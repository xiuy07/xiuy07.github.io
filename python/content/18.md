# 18 描述统计与分组汇总

agg、transform、相关性与统计口径

学习目标：在计算前明确每个数的分母和缺失处理。

## 从一个小问题开始

### 每个统计数都带着一个分母

两行成绩[80,缺失]：size是2，count是1，mean是80。只写“平均80分”还不够，应说明使用了1个有效成绩。

<details class="checkpoint" markdown="1">
<summary>检查理解：先把缺失填0，再求均值，为什么会变成40？</summary>

填0增加了一条有效的零分观测，分母变成2。它改变了数据含义，不能视为无影响的格式修复。

</details>


## 先定义分母
mean 是非缺失观测的均值；count 统计非缺失值；size 统计行数。三者回答的问题不同。pandas std 默认样本标准差 ddof=1，NumPy std 默认总体标准差 ddof=0。比较两个结果时先统一统计口径。

## 分组就是拆分、计算、组合
`groupby("city").agg(...)` 把每个城市压缩为一行，适合报告。`transform("mean")` 返回与原行数相同的结果，可计算每个人相对组均值的偏差。缺失分组键默认可能被排除，想保留要显式 `dropna=False`。

分组后仍需显式排序以得到确定输出。多级索引可用 reset_index 还原成列；命名聚合让输出字段表达意义，而不是留下含混的多级列名。

## 相关性有边界
Pearson 相关描述线性关联，不证明因果，也不能概括所有非线性关系。缺失处理、异常点、样本量和分组混杂都可能影响结论。报告除数值外，应写样本范围、有效数量与清理规则。

## 运行示例

```python
import pandas as pd
df = pd.DataFrame({"city": ["A", "A", "B"], "score": [80, None, 90]})
report = df.groupby("city", as_index=False).agg(rows=("score", "size"), valid=("score", "count"), mean=("score", "mean"))
print(report.to_dict("records"))
print(df.groupby("city")["score"].transform("mean").tolist())
```

预期输出

```text
[{'city': 'A', 'rows': 2, 'valid': 1, 'mean': 80.0}, {'city': 'B', 'rows': 1, 'valid': 1, 'mean': 90.0}]
[80.0, 80.0, 90.0]
```

A组有2行，但有效分数只有1个，均值为80。transform 把80映射回A组的两条原记录，包括缺失分数所在的行。

运行：`python demos/18.py`

## 手推与修改

若先将缺失填0，A组均值会怎样变化？哪种回答更符合“有效成绩平均分”？

## 易错点

不要把 size 和 count 混用；不要将相关关系直接写成因果关系。
