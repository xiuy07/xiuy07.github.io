## 从一个小问题开始

### 先把“算出值”和“显示值”分开

一句表达式会算出一个值，`print` 把信息写到屏幕上，`return` 把值交给调用者。初学时最容易把后两件事混在一起。先看一个很小的例子，再读本章的环境准备。

### 先猜一猜：屏幕出现了什么，变量拿到了什么？

先在纸上写出输出，再运行这段代码。

```python
def announce(x):
    print(x + 1)

def calculate(x):
    return x + 1

a = announce(4)
b = calculate(4)
print(a, b)
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
5
None 5
```

第一步，`announce(4)` 在屏幕上显示5。第二步，它没有执行return，因此a得到None。第三步，calculate返回5，但不会自行显示。最后一行才把a和b显示出来。

</details>

本例可单独运行：`python demos/features/01-return-print.py`。

**再改一步：** 把 `print(x + 1)` 换成 `return x + 1`，哪一行屏幕输出会消失？你可以先回答，再改文件验证。


## 程序怎样开始执行
把代码保存为 `hello.py`，在文件所在目录运行 `python hello.py`。终端里输入 `python` 进入的是交互解释器，提示符 `>>>` 不是程序内容。Python 会先编译为字节码，再由解释器执行；不要把“脚本语言”理解为完全没有编译步骤。

`input()` 返回字符串，`int()`、`float()` 才负责数值转换。自动评测只接收结果，不能输出“请输入一个数”等提示语。`print(a, b)` 默认以空格分隔并换行；格式化精度用 `f"{value:.2f}"`。

## 为课程建立独立环境
先执行 `python -m venv .venv`。Windows 可直接用 `.venv\Scripts\python.exe`，无需更改执行策略；macOS/Linux 用 `.venv/bin/python`。后续安装也用这同一个解释器的 `-m pip`，避免包装进另一个 Python。

```text
python --version
python -c "import sys; print(sys.executable)"
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-data.txt
```

本讲义以 Python 3.12+ 为目标。基础练习只依赖标准库；第13章起按需安装 NumPy、pandas、Matplotlib。先运行 `python practice/judge.py doctor` 检查当前解释器。

## 运行示例

```python
def receipt(price, count):
    total = price * count
    return f"{total:.2f}"

print(receipt(12.5, 3))
print("Python", "ready", sep=" / ")
```

预期输出

```text
37.50
Python / ready
```

`price * count` 先算数值，再格式化为字符串。`.2f` 控制显示，并不会改变浮点数的存储方式。第二行演示分隔符。

运行：`python demos/01.py`
