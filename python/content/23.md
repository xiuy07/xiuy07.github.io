## 简洁的前提是能展开解释

看到推导式，先把它还原成for与if；看到解包，先写出每个名字拿到的对象；看到条件表达式，先确定只会执行哪一支。能说清楚求值顺序，才能判断一行代码是否适合保留。

列表推导式立即收集结果，生成器表达式按需产生结果。`sum(x*x for x in nums)` 不用先建立平方列表；但它仍会遍历所有需要求和的元素，不是省去计算。

### 先猜一猜：一个星号可以收集什么，也可以展开什么？

先在纸上写出输出，再运行这段代码。

```python
first, *middle, last = [2, 4, 6, 8]
print(first, middle, last)
print([first, *middle, last, 10])
defaults = {"limit": 5, "reverse": False}
options = {**defaults, "limit": 2}
print(options)
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
2 [4, 6] 8
[2, 4, 6, 8, 10]
{'limit': 2, 'reverse': False}
```

赋值目标中的星号接收中间元素组成的列表；列表显示中的星号展开已有可迭代对象；字典显示中的双星号展开映射。同名键后写的值覆盖先写的值。函数调用中重复提供同一个关键字通常会报错，不要把字典合并规则直接搬到调用上。

</details>

本例可单独运行：`python demos/features/23-unpacking.py`。

## 比较、短路与条件表达式

`0 <= x < 10` 是链式比较。`yes if condition else no` 只计算选中的那一支。`and/or` 也会跳过不必要的后续表达式，但返回操作数；需要布尔结果时可显式bool。

优先把这些特性用于表达条件，避免把写文件、打印或修改列表藏进复杂表达式。读者应能直接判断每行是否改变状态。

## 赋值表达式：一边取得结果，一边给它名字

### 先猜一猜：如何在筛选时只算一次文本长度？

先在纸上写出输出，再运行这段代码。

```python
words = ["py", "python", "data", "x"]
result = [(word, n) for word in words if (n := len(word)) >= 4]
print(result)
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
[('python', 6), ('data', 4)]
```

先对当前word求len并把结果绑定给n，再检查是否至少4。通过筛选后，元组表达式使用同一个n。若这一行让你停下来反复解读，展开成普通循环也是好选择。不要依赖推导式中的名字泄漏来传递业务状态。

</details>

本例可单独运行：`python demos/features/23-walrus.py`。

## match匹配结构，不只是比较一个常量

序列模式 `case ["add", x, y]` 要求长度与结构合适，并把对应部分绑定给x、y；`case ["sum", *items]` 收集后面的零个或多个项。映射模式可以取出指定键，额外键通常不妨碍匹配。

`case name:` 是捕获模式，会把名字绑定到匹配对象；它通常不是“与一个已有同名变量比较”。用字面量或合适的限定名表达值匹配，使用 `_` 表达不关心的部分。守卫 `if condition` 在结构匹配完成后进一步检查。

### 先猜一猜：结构相同之后，守卫还能筛掉什么？

先在纸上写出输出，再运行这段代码。

```python
def describe(value):
    match value:
        case ["point", x, y] if x == y:
            return "diagonal"
        case ["point", x, y]:
            return "other point"
        case {"kind": "text", "value": str(text)}:
            return text.upper()
        case _:
            return "unknown"

print(describe(["point", 2, 2]))
print(describe({"kind": "text", "value": "py", "extra": 1}))
print(describe(["point", 2]))
```

<details class="checkpoint" markdown="1">
<summary>展开结果与逐步解释</summary>

```text
diagonal
PY
unknown
```

第一个输入先匹配三项结构，再通过x==y守卫。第二个输入含额外键仍可匹配指定键，str(text)要求对应值为字符串。最后一个输入长度不足，不匹配point分支。

</details>

本例可单独运行：`python demos/features/23-match.py`。

## 完整运行示例

```python
def summarize(values):
    first, *middle, last = values
    return {"ends": [first, last], "middle_sum": sum(middle)}

print(summarize([2, 4, 6, 8]))
print(summarize([2, 8]))
```

预期输出

```text
{'ends': [2, 8], 'middle_sum': 10}
{'ends': [2, 8], 'middle_sum': 0}
```

运行：`python demos/23.py`。
