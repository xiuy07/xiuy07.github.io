# p04 整除与余数

所属第02章 · 进阶

## 任务与接口

输入 [[a,b],...]，返回每组 [a//b,a%b]。最多100组，|a|,|b|≤10^6 且 b≠0；遵循 Python 向负无穷取整。

在 `practice/solutions/p04/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[[-7, 3], [7, -3], [-7, -3], [0, 2]]
```

返回值

```json
[[-3, 2], [-3, -2], [2, -1], [0, 0]]
```

## 提示

余数满足 a=b*q+r。负数时不能用 int(a/b)。

## 复杂度目标

时间 O(n)，空间 O(n)
