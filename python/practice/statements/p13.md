# p13 惰性分块

所属第07章 · 基础

## 任务与接口

输入 {"values":数组,"size":正整数}，数组长≤10000，1≤size≤1000。编写生成器分块（最后一块可不足），solve 返回各块组成的数组。

在 `practice/solutions/p13/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"values": [], "size": 3}
```

返回值

```json
[]
```

示例2输入

```json
{"values": [1], "size": 3}
```

返回值

```json
[[1]]
```

## 提示

先迭代输入，每次积累满 size 就 yield；不要丢掉最后一块。

## 复杂度目标

时间 O(n)，输出空间 O(n)，生成器额外空间 O(size)

## 本地测试

```text

```
