# p05 空白规范化

所属第03章 · 基础

## 任务与接口

输入字符串，删除两端空白，把内部连续空白变为一个ASCII空格。返回字符串，长度≤10000。

在 `practice/solutions/p05/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
"  hello   world  "
```

返回值

```json
"hello world"
```

示例2输入

```json
""
```

返回值

```json
""
```

## 提示

无参数 split 会把多种空白合并。

## 复杂度目标

时间 O(n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p05
```
