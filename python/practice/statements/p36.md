# p36 相对组均值偏差

所属第18章 · 进阶

## 任务与接口

输入 [{"city":非空字符串,"score":数值或null},...]，≤10000项。使用pandas transform返回每行 score 减去本city有效分数均值；原score缺失则结果null，保留原顺序。

在 `practice/solutions/p36/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"city": "A", "score": null}]
```

返回值

```json
[null]
```

## 提示

transform 保持原行数，agg 会压缩。

## 复杂度目标

时间 O(n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p36
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
