# p28 按标签相加

所属第14章 · 进阶

## 任务与接口

输入 {"left":{"标签":数值,...},"right":{...}}，每侧≤100个标签，均非空字符串。使用pandas按标签相加，返回 [[标签,结果或null],...]，标签升序，任一侧缺少该标签则结果null。

在 `practice/solutions/p28/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"left": {}, "right": {}}
```

返回值

```json
[]
```

示例2输入

```json
{"left": {"A": 10, "B": 20}, "right": {"B": 1, "A": 2}}
```

返回值

```json
[["A", 12], ["B", 21]]
```

## 提示

Series 算术自动对齐，输出前把缺失转成 None。

## 复杂度目标

时间 O(k log k)，空间 O(k)

## 本地测试

```text
python practice/judge.py p28
```
