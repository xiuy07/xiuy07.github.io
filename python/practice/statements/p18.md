# p18 JSON 记录验证

所属第09章 · 进阶

## 任务与接口

输入对象数组（≤1000项）。每项合法条件：name是非空字符串（strip后不空），age的类型严格为int（不接受bool）且0..150。返回 {"valid":[[清理后姓名,age],...],"invalid":[非法原下标,...]}；允许其他字段。

在 `practice/solutions/p18/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
{"valid": [], "invalid": []}
```

示例2输入

```json
[{"name": " A ", "age": 0}]
```

返回值

```json
{"valid": [["A", 0]], "invalid": []}
```

## 提示

先检查类型再比较范围，bool 是 int 子类。

## 复杂度目标

时间 O(n+文本总长)，空间 O(n)

