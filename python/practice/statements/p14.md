# p14 滑动窗口和

所属第07章 · 进阶

## 任务与接口

输入 {"values":整数数组,"k":正整数}。返回所有长度恰为k的连续窗口和，k>n返回[]。n≤10000，k≤10000。请使用生成器或滚动状态，避免每个窗口重新求和。

在 `practice/solutions/p14/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"values": [], "k": 1}
```

返回值

```json
[]
```

示例2输入

```json
{"values": [1], "k": 1}
```

返回值

```json
[1]
```

## 提示

离开一个元素、进入一个元素，窗口和只需一次减法和加法。

## 复杂度目标

时间 O(n)，除输出外空间 O(1)

## 本地测试

```text
python practice/judge.py p14
```
