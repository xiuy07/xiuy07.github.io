# p11 加权平均

所属第06章 · 基础

## 任务与接口

输入 {"values":[数字,...],"weights":[非负整数,...]}，长度相同且≤10000，|value|≤10000，weight≤10000。返回加权平均数，权重和为0时返回null。

在 `practice/solutions/p11/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"values": [], "weights": []}
```

返回值

```json
null
```

示例2输入

```json
{"values": [1], "weights": [0]}
```

返回值

```json
null
```

## 提示

先计算分母，使用 zip(strict=True)。

## 复杂度目标

时间 O(n)，空间 O(1)

```text
python practice/judge.py p11
```
