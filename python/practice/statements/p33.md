# p33 去重并填补

所属第17章 · 基础

## 任务与接口

输入 [{"id":整数,"score":数值、十进制字符串、"bad"、空串或null},...]，≤10000项，数值绝对值≤10000，不含Infinity。使用pandas：同id仅保留最后出现行，并按这些行原顺序排列；score无法转数值或缺失则填0。返回对象数组。

在 `practice/solutions/p33/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"id": 1, "score": "bad"}, {"id": 1, "score": "90"}, {"id": 2, "score": null}]
```

返回值

```json
[{"id": 1, "score": 90.0}, {"id": 2, "score": 0}]
```

## 提示

to_numeric(coerce)，drop_duplicates(keep=last)，fillna(0)。

## 复杂度目标

平均时间 O(n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p33
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
