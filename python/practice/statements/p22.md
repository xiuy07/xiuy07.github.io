# p22 最大的 k 个数

所属第11章 · 进阶

## 任务与接口

输入 {"values":整数数组,"k":0..n}，n≤10000。返回最大的k个数，降序排列，保留重复。使用容量为k的最小堆。

在 `practice/solutions/p22/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"values": [], "k": 0}
```

返回值

```json
[]
```

示例2输入

```json
{"values": [1], "k": 0}
```

返回值

```json
[]
```

## 提示

堆顶为当前候选中最小值，新值更大时替换。

## 复杂度目标

时间 O(n log(k+1)+k log k)，空间 O(k)

## 本地测试

```text
python practice/judge.py p22
```
