# p29 成绩区间筛选

所属第15章 · 基础

## 任务与接口

输入 {"rows":[{"name":字符串,"score":数值或null},...],"low":下界,"high":上界}。使用pandas返回 low≤score<high 的姓名数组，保留原序；缺失不入选。行≤10000。

在 `practice/solutions/p29/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"rows": [], "low": 0, "high": 100}
```

返回值

```json
[]
```

示例2输入

```json
{"rows": [{"name": "A", "score": null}, {"name": "B", "score": 0}, {"name": "C", "score": 100}], "low": 0, "high": 100}
```

返回值

```json
["B"]
```

## 提示

每个比较两边加括号，使用 &。

## 复杂度目标

时间 O(n)，空间 O(n)
