# p06 提取合法成绩

所属第03章 · 进阶

## 任务与接口

输入一段最多10000字符的日志。提取所有匹配 ASCII 姓名、冒号、可选空白、1到3位数字的字段，例如 Alice: 88。匹配不得在更长数字中截断；只保留0..100，返回按出现顺序的 [姓名小写,分数] 数组。

在 `practice/solutions/p06/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
"Alice: 88; Bob: 72"
```

返回值

```json
[["alice", 88], ["bob", 72]]
```

示例2输入

```json
"X: 101; Y: 0"
```

返回值

```json
[["y", 0]]
```

## 提示

用 finditer 和数字边界，转换后再检查范围。

## 复杂度目标

时间 O(n)，空间 O(k)
