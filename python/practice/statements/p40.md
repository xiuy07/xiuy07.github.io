# p40 直方图数据准备

所属第20章 · 进阶

## 任务与接口

输入 {"values":[数值,...],"edges":[严格递增边界,...]}，数值≤10000个，边界2..100个。使用NumPy返回各箱计数。各箱左闭右开，最后一箱包含最右边界；区间外数据忽略。

在 `practice/solutions/p40/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"values": [], "edges": [0, 1]}
```

返回值

```json
[0]
```

示例2输入

```json
{"values": [0, 1, 2, 3, -1, 4], "edges": [0, 1, 2, 3]}
```

返回值

```json
[1, 1, 2]
```

## 提示

np.histogram 的最后一个区间右端也包含。

## 复杂度目标

时间 O(n log b)，空间 O(n+b)
