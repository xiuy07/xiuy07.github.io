# p26 逐行中心化

所属第13章 · 进阶

## 任务与接口

输入非空数字矩阵，行列1..100，元素绝对值≤10000。使用 NumPy，让每行减去本行平均值，返回二维数字数组。

在 `practice/solutions/p26/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[[1, 2], [3, 4]]
```

返回值

```json
[[-0.5, 0.5], [-0.5, 0.5]]
```

示例2输入

```json
[[1]]
```

返回值

```json
[[0]]
```

## 提示

mean(axis=1,keepdims=True) 保持可广播形状。

## 复杂度目标

时间 O(rc)，空间 O(rc)
