# p47 规范化的分数对象

所属第24章 · Python特性专题

## 任务与接口

输入 {"fractions":[[分子,分母],...]}，≤100项，分子绝对值≤1000，分母非零且绝对值≤1000。定义不可变Rational类：构造时约分，分母保持正数，支持+。返回全部分数之和的[分子,分母]；空输入返回[0,1]。参考实现不使用fractions.Fraction。

在 `practice/solutions/p47/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
{"fractions": [[1, 6], [1, 3]]}
```

返回值

```json
[1, 2]
```

示例2输入

```json
{"fractions": []}
```

返回值

```json
[0, 1]
```

## 提示

构造器统一符号并用gcd约分；加法返回新的合法对象，让调用者不重复维护表示约束。

## 复杂度目标

k次分数加法与gcd约分；整数位数随输入增长，成本不视为固定O(1)。
