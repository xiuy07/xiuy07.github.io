# p19 可测试的统计函数

所属第10章 · 基础

## 任务与接口

输入有限数字数组（≤10000，绝对值≤10^6）。返回 {"count":数量,"mean":均值或null,"min":最小或null,"max":最大或null}。计算函数不得读写文件。

在 `practice/solutions/p19/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
{"count": 0, "mean": null, "min": null, "max": null}
```

示例2输入

```json
[0]
```

返回值

```json
{"count": 1, "mean": 0, "min": 0, "max": 0}
```

## 提示

空集合的极值不要伪造为0。

## 复杂度目标

时间 O(n)，空间 O(1)

## 本地测试

```text
python practice/judge.py p19
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
