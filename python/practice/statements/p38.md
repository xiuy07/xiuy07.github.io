# p38 合并月度数据

所属第19章 · 进阶

## 任务与接口

输入按月份排列的对象数组的数组，行字段为 {"id":整数,"value":数值}。月份≤100，总行数≤10000。使用pandas concat，增加month字段为从1开始的输入批次序号；保留批次内顺序，返回对象数组。

在 `practice/solutions/p38/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[[], []]
```

返回值

```json
[]
```

## 提示

先为每张表赋month，再一次concat；空批次不改变后面月份编号。

## 复杂度目标

时间 O(n)，空间 O(n)
