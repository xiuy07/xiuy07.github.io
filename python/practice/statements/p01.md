# p01 整数计算器

所属第01章 · 基础

## 任务与接口

输入为两个整数的数组 [a,b]，返回 a+b。-10^12≤a,b≤10^12。

在 `practice/solutions/p01/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[0, 0]
```

返回值

```json
0
```

示例2输入

```json
[3, 7]
```

返回值

```json
10
```

## 提示

解包两个元素后相加。

## 复杂度目标

时间 O(1)，空间 O(1)（固定输入范围）

## 本地测试

```text
python practice/judge.py p01
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
