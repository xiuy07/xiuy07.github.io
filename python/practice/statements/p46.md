# p46 用match解释小命令

所属第23章 · Python特性专题

## 任务与接口

输入字符串数组，≤1000项，每项长度≤100。支持add x y、neg x、sum（后跟零个或多个数）；操作数格式为可选正负号加ASCII十进制数字，值绝对值≤10000。分别返回计算结果，未知指令、项数不符或数字非法返回null。空sum返回0。用split与match拆分结构，不用eval。

在 `practice/solutions/p46/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
["add 2 3", "neg -4", "sum 1 2 3"]
```

返回值

```json
[5, 4, 6]
```

示例2输入

```json
["sum", "add 1", "unknown 2", ""]
```

返回值

```json
[0, null, null, null]
```

## 提示

序列模式约束操作名和长度，sum分支用星号收集；再逐项验证数值格式。

## 复杂度目标

时间O(输入文本总长)，空间O(输入文本总长)。

## 本地测试

```text
python practice/judge.py p46
```

测试验证返回结果；指定的闭包、递归、match或对象协议写法需要对照题面自查。
