# p42 彼此独立的计数器

所属第21章 · Python特性专题

## 任务与接口

输入 {"starts":[整数初值,...],"calls":[[计数器下标,增量],...]}。最多100个计数器、1000次调用，初值和增量绝对值≤10000，下标合法。用闭包工厂为各初值建立计数器，返回 {"results":每次调用的返回值数组,"final":各计数器最终值数组}。允许没有计数器（此时calls为空）。

在 `practice/solutions/p42/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
{"starts": [10, 100], "calls": [[0, 2], [0, 3], [1, 1]]}
```

返回值

```json
{"results": [12, 15, 101], "final": [15, 101]}
```

示例2输入

```json
{"starts": [], "calls": []}
```

返回值

```json
{"results": [], "final": []}
```

## 提示

工厂每次调用建立独立total；内部add用nonlocal更新。读取最终值可调用add(0)。

## 复杂度目标

时间O(n+m)，空间O(n+m)。
