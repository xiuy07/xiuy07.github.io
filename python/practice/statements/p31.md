# p31 订单特征衍生

所属第16章 · 基础

## 任务与接口

输入 [{"item":字符串,"price":非负整数,"qty":非负整数},...]，≤10000项，数值≤10000。使用pandas返回 [{"item":去空白后大写,"revenue":price*qty},...]，保留顺序。

在 `practice/solutions/p31/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"item": " tea ", "price": 5, "qty": 3}]
```

返回值

```json
[{"item": "TEA", "revenue": 15}]
```

## 提示

str.strip().str.upper() 和整列相乘。

## 复杂度目标

时间 O(n+文本总长)，空间 O(n)

