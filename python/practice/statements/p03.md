# p03 独立矩阵

所属第02章 · 基础

## 任务与接口

输入 {"n":行数,"m":列数,"updates":[[行,列,值],...]}，创建全0矩阵并按顺序修改，返回最终二维数组。0≤n,m≤30，更新位置保证合法。

在 `practice/solutions/p03/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"n": 2, "m": 3, "updates": [[0, 0, 9]]}
```

返回值

```json
[[9, 0, 0], [0, 0, 0]]
```

示例2输入

```json
{"n": 0, "m": 2, "updates": []}
```

返回值

```json
[]
```

## 提示

每一行都必须新建列表。

## 复杂度目标

时间 O(nm+u)，空间 O(nm)

## 本地测试

```text
python practice/judge.py p03
```
