# p21 无权图最短距离

所属第11章 · 基础

## 任务与接口

输入 {"n":顶点数,"edges":[[u,v],...],"start":起点}，无向图，1≤n≤100，顶点0..n-1，边≤1000，允许重复边与自环。返回到各点距离，不可达为-1。

在 `practice/solutions/p21/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"n": 1, "edges": [], "start": 0}
```

返回值

```json
[0]
```

示例2输入

```json
{"n": 4, "edges": [[0, 1], [1, 2]], "start": 0}
```

返回值

```json
[0, 1, 2, -1]
```

## 提示

deque 维护 BFS 队列，入队时标记。

## 复杂度目标

时间 O(n+m)，空间 O(n+m)
