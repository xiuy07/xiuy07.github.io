# p45 解包两端与中段

所属第23章 · Python特性专题

## 任务与接口

输入长度2..10000的整数数组，元素绝对值≤10000。用星号目标解包第一个、中间若干个、最后一个元素，返回 {"ends":[首元素,尾元素],"middle_sum":中间元素和}。恰好两项时中段为空，和为0。

在 `practice/solutions/p45/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
[2, 4, 6, 8]
```

返回值

```json
{"ends": [2, 8], "middle_sum": 10}
```

示例2输入

```json
[2, 8]
```

返回值

```json
{"ends": [2, 8], "middle_sum": 0}
```

## 提示

first,*middle,last = data；middle始终是列表。

## 复杂度目标

时间O(n)，星号解包中段空间O(n)。
