# p16 二维向量协议

所属第08章 · 进阶

## 任务与接口

输入 [[[x1,y1],[x2,y2]],...]，最多1000对，坐标整数绝对值≤10000。定义不可变 Vec2 类，支持 +，solve 返回所有相加结果 [[x,y],...]。

在 `practice/solutions/p16/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[[[0, 0], [1, 2]]]
```

返回值

```json
[[1, 2]]
```

## 提示

frozen dataclass 表示不可变数据，__add__ 返回新对象。

## 复杂度目标

时间 O(n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p16
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
