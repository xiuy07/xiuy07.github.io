# p37 订单左连接

所属第19章 · 基础

## 任务与接口

输入 {"orders":[{"user":整数,"amount":整数},...],"users":[{"user":唯一整数,"city":字符串},...]}，各≤1000项。使用pandas左连接，返回 [{"user":...,"amount":...,"city":匹配值或null},...]，保持订单原序。

在 `practice/solutions/p37/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"orders": [], "users": []}
```

返回值

```json
[]
```

示例2输入

```json
{"orders": [{"user": 1, "amount": 0}], "users": []}
```

返回值

```json
[{"user": 1, "amount": 0, "city": null}]
```

## 提示

merge how=left，validate=many_to_one，缺失转None。

## 复杂度目标

平均时间 O(n+m)，空间 O(n+m)

