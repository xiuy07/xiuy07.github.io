# p35 分组成绩摘要

所属第18章 · 基础

## 任务与接口

输入 [{"city":非空字符串,"score":数值或null},...]，≤10000项。使用pandas按city升序返回 [{"city":...,"rows":总行数,"valid":有效分数数,"mean":均值或null},...]。

在 `practice/solutions/p35/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"city": "A", "score": null}]
```

返回值

```json
[{"city": "A", "rows": 1, "valid": 0, "mean": null}]
```

## 提示

命名聚合中 size、count、mean 各有含义。

## 复杂度目标

时间 O(n+k log k)，空间 O(n)

## 本地测试

```text
python practice/judge.py p35
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
