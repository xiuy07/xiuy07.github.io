# p24 并发批次统计

所属第12章 · 进阶

## 任务与接口

输入字符串数组（≤1000，每项长度≤10000）。用线程池计算每项 split() 后的词数，返回与输入同序的整数数组。不得用完成顺序代替输入顺序。

在 `practice/solutions/p24/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
["a b", "x", ""]
```

返回值

```json
[2, 1, 0]
```

## 提示

每个任务只返回本项结果，不更新共享计数器。

## 复杂度目标

时间 O(文本总长)，空间 O(n)

## 本地测试

```text
python practice/judge.py p24
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
