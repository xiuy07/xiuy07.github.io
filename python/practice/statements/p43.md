# p43 嵌套结构的三种摘要

所属第22章 · Python特性专题

## 任务与接口

输入由整数和列表组成的嵌套结构，根可以是整数或列表；整数绝对值≤10000，节点≤1000，嵌套列表深度≤30。递归返回 {"sum":所有整数之和,"leaves":整数个数,"depth":列表最大嵌套层数}。整数的depth为0，空列表为1；例如[1,[2],[]]深度为2。

在 `practice/solutions/p43/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
0
```

返回值

```json
{"sum": 0, "leaves": 1, "depth": 0}
```

示例2输入

```json
[]
```

返回值

```json
{"sum": 0, "leaves": 0, "depth": 1}
```

## 提示

整数直接返回(sum=x,leaves=1,depth=0)；列表合并子结果，depth取1+子项最大深度，空列表用默认0。

## 复杂度目标

时间O(节点数)，除返回值外空间O(最大深度)。
