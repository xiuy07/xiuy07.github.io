# p39 城市收入流水线

所属第20章 · 基础

## 任务与接口

输入 [{"id":整数,"city":非空字符串,"price":数字/数字串/"bad"/null,"qty":同前},...]，≤10000项，数值绝对值≤10000。用pandas同id保留最后行；两数coerce；删除缺失或负值；计算收入并按city汇总。返回城市升序的 [[city,revenue],...]。

在 `practice/solutions/p39/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"id": 1, "city": "A", "price": 10, "qty": 2}, {"id": 1, "city": "B", "price": "bad", "qty": 3}]
```

返回值

```json
[]
```

## 提示

去重→转换→过滤→相乘→分组，顺序不可随意互换。

## 复杂度目标

时间 O(n+k log k)，空间 O(n)
