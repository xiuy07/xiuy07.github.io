# p48 接入len、for与in的整数区间

所属第24章 · Python特性专题

## 任务与接口

输入 {"start":整数,"stop":整数,"step":非零整数,"queries":整数数组}。端点绝对值≤100，step绝对值≤20，queries≤100项。定义IntSpan类，支持__iter__、__len__与__contains__。从start按step前进，不越过stop；恰好到达stop时包含它。方向不合则为空。返回 {"values":遍历值,"length":长度,"contains":每次成员判断结果数组}。

在 `practice/solutions/p48/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
{"start": 1, "stop": 5, "step": 2, "queries": [0, 1, 3, 4, 5]}
```

返回值

```json
{"values": [1, 3, 5], "length": 3, "contains": [false, true, true, false, true]}
```

示例2输入

```json
{"start": 5, "stop": 1, "step": -2, "queries": [1, 2, 3, 5]}
```

返回值

```json
{"values": [5, 3, 1], "length": 3, "contains": [true, false, true, true]}
```

## 提示

底层可包装range；正步长用stop+1，负步长用stop-1。不能把stop无条件加1。

## 复杂度目标

生成输出O(n+q)；可用range使整数成员判断不遍历整个区间。
