# p10 括号校验

所属第05章 · 进阶

## 任务与接口

输入仅包含 ()[]{} 的字符串，长度0..10000。返回是否完整匹配的布尔值，空串视为合法。

在 `practice/solutions/p10/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
""
```

返回值

```json
true
```

示例2输入

```json
"()"
```

返回值

```json
true
```

## 提示

栈顶必须是当前右括号对应的左括号。

## 复杂度目标

时间 O(n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p10
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
