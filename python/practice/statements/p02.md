# p02 收据金额

所属第01章 · 进阶

## 任务与接口

输入 {"cents":整数单价分,"qty":数量}。单价、数量均在0..10^6。返回两位小数的金额字符串，使用整数计算避免浮点误差。

在 `practice/solutions/p02/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"cents": 1250, "qty": 3}
```

返回值

```json
"37.50"
```

示例2输入

```json
{"cents": 1, "qty": 1}
```

返回值

```json
"0.01"
```

## 提示

先计算总分，再 divmod(total,100)。

## 复杂度目标

时间 O(1)，空间 O(1)

