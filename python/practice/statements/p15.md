# p15 独立笔记本

所属第08章 · 基础

## 任务与接口

输入 {"owners":[名字,...],"writes":[[下标,内容],...]}。为每个owner创建Notebook实例并追加内容，返回 [[owner,pages],...]。owner≤100，追加≤1000，位置合法。使用 dataclass 和独立容器字段。

在 `practice/solutions/p15/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"owners": [], "writes": []}
```

返回值

```json
[]
```

示例2输入

```json
{"owners": ["A", "B"], "writes": [[0, "x"]]}
```

返回值

```json
[["A", ["x"]], ["B", []]]
```

## 提示

pages 使用 field(default_factory=list)。

## 复杂度目标

时间 O(n+w)，空间 O(n+w)
