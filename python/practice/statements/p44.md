# p44 有封闭台阶的路线

所属第22章 · Python特性专题

## 任务与接口

输入 {"n":目标层数,"blocked":[禁止落脚层数,...]}。0≤n≤60，每次跨1层或3层，从0层出发，禁止层数在1..n且允许重复。返回到n层的不同步长序列数。到0层有一条空路线；目标被封闭则返回0。使用递归与记忆化。

在 `practice/solutions/p44/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
{"n": 0, "blocked": []}
```

返回值

```json
1
```

示例2输入

```json
{"n": 4, "blocked": []}
```

返回值

```json
3
```

## 提示

负层数或被封闭层数返回0；0返回1；最后一步从n-1或n-3来。缓存放在solve内部，避免不同题目实例共享规则。

## 复杂度目标

O(n)个状态、O(n)调用栈；大整数算术成本另计。
