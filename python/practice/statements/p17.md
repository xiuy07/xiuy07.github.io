# p17 CSV 成绩审计

所属第09章 · 基础

## 任务与接口

输入带 name,score 表头的CSV字符串（≤10000字符，结构合法）。score用int解析且须0..100，不合法行计入rejected。返回 {"rows":[[姓名,整数分数],...],"rejected":数量}；保留顺序，允许CSV引号姓名。

在 `practice/solutions/p17/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
"name,score\n"
```

返回值

```json
{"rows": [], "rejected": 0}
```

示例2输入

```json
"name,score\nA,0\nB,100\n"
```

返回值

```json
{"rows": [["A", 0], ["B", 100]], "rejected": 0}
```

## 提示

使用 DictReader 和 StringIO，只捕获数值转换错误。

## 复杂度目标

时间 O(n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p17
```
