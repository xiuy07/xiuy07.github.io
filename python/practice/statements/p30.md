# p30 统一补考下限

所属第15章 · 进阶

## 任务与接口

输入 {"scores":[数值或null,...],"floor":数值}，≤10000分数。使用pandas将非缺失且低于floor的值改为floor，缺失保留null，返回列表。

在 `practice/solutions/p30/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"scores": [], "floor": 60}
```

返回值

```json
[]
```

示例2输入

```json
{"scores": [null, 0, 60, 100], "floor": 60}
```

返回值

```json
[null, 60, 60, 100]
```

## 提示

用 loc 一次定位赋值。

## 复杂度目标

时间 O(n)，空间 O(n)

```text
python practice/judge.py p30
```
