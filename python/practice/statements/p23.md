# p23 按输入顺序收集任务

所属第12章 · 基础

## 任务与接口

输入整数数组，≤1000个，绝对值≤10000。使用ThreadPoolExecutor并发计算平方，按输入顺序返回结果。无需模拟耗时或证明加速。

在 `practice/solutions/p23/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[3, 1, 2]
```

返回值

```json
[9, 1, 4]
```

## 提示

pool.map 的输出顺序对应输入。

## 复杂度目标

时间 O(n)，空间 O(n)（忽略执行器调度开销）

## 本地测试

```text
python practice/judge.py p23
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
