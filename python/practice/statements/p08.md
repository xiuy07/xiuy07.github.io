# p08 两数配对

所属第04章 · 进阶

## 任务与接口

输入 {"nums":整数数组,"target":目标和}，返回两个不同下标 [j,i]，j<i。若多解，选i最小、再j最小；无解返回[]。n≤10000，值绝对值≤10^9。

在 `practice/solutions/p08/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"nums": [2, 7, 11, 15], "target": 9}
```

返回值

```json
[0, 1]
```

示例2输入

```json
{"nums": [3, 3], "target": 6}
```

返回值

```json
[0, 1]
```

## 提示

从左到右扫描，先查补数，再只记录每个数最早的下标。

## 复杂度目标

平均时间 O(n)，空间 O(n)
