# p25 列汇总

所属第13章 · 基础

## 任务与接口

输入非空二维整数数组，1≤行列≤100，值绝对值≤10000，矩形结构。使用 NumPy 返回每列和的整数数组。

在 `practice/solutions/p25/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[[1, 2], [3, 4]]
```

返回值

```json
[4, 6]
```

示例2输入

```json
[[0]]
```

返回值

```json
[0]
```

## 提示

将第0轴消去。

## 复杂度目标

时间 O(rc)，空间 O(rc)

## 本地测试

```text
python practice/judge.py p25
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
