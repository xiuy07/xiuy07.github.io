# p12 互不串联的记录

所属第06章 · 进阶

## 任务与接口

输入 [[本次添加值,...],...]，最多100次调用、每次最多100值。对每一项单独调用 record(value,history=None) 累积该项，返回每项最终列表；空项返回[]。实现不得跨调用保留状态。

在 `practice/solutions/p12/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[[], []]
```

返回值

```json
[[], []]
```

## 提示

默认值用 None，各组重新创建 history。

## 复杂度目标

时间 O(总元素数)，空间 O(总元素数)

```text
python practice/judge.py p12
```
