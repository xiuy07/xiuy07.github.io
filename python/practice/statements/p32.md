# p32 宽成绩转长表

所属第16章 · 进阶

## 任务与接口

输入 [{"name":字符串,"math":数值,"python":数值},...]，≤1000项。使用pandas melt，返回 [{"name":...,"subject":"math"或"python","score":...},...]；先按科目顺序math、python，再按原行顺序。

在 `practice/solutions/p32/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"name": "A", "math": 80, "python": 90}]
```

返回值

```json
[{"name": "A", "subject": "math", "score": 80}, {"name": "A", "subject": "python", "score": 90}]
```

## 提示

id_vars=name，value_vars 显式指定列序。

## 复杂度目标

时间 O(n)，空间 O(n)
