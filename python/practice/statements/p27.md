# p27 数据体检

所属第14章 · 基础

## 任务与接口

输入含id、score的对象数组（≤10000项）；id为字符串，score为数字或null。使用pandas返回 {"rows":行数,"columns":2,"missing":score缺失数,"unique_ids":id不同值数}。空输入仍保留两列模式。

在 `practice/solutions/p27/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
{"rows": 0, "columns": 2, "missing": 0, "unique_ids": 0}
```

示例2输入

```json
[{"id": "001", "score": null}]
```

返回值

```json
{"rows": 1, "columns": 2, "missing": 1, "unique_ids": 1}
```

## 提示

DataFrame 构造时显式 columns。

## 复杂度目标

时间 O(n)，空间 O(n)
