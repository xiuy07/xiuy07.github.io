# p07 词频榜

所属第04章 · 基础

## 任务与接口

输入单词字符串数组（≤10000项），区分大小写。返回 [[词,次数],...]，按次数降序，同次数按词的 Unicode 字典序升序。

在 `practice/solutions/p07/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
["pear", "apple", "pear"]
```

返回值

```json
[["pear", 2], ["apple", 1]]
```

## 提示

Counter 统计，再用 (-count,word) 排序。

## 复杂度目标

时间 O(n+k log k)，空间 O(k)

