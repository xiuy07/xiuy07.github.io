# p20 确定性的成绩报告

所属第10章 · 进阶

## 任务与接口

输入 [{"name":字符串,"score":0..100整数},...]，≤10000项。返回新的排序对象数组，按score降序、name升序；完全同键保持原顺序。不要修改传入列表。

在 `practice/solutions/p20/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[]
```

示例2输入

```json
[{"name": "A", "score": 0}]
```

返回值

```json
[{"name": "A", "score": 0}]
```

## 提示

sorted 返回新列表，key返回元组。

## 复杂度目标

时间 O(n log n)，空间 O(n)

## 本地测试

```text
python practice/judge.py p20
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
