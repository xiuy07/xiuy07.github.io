# p34 训练集标准化

所属第17章 · 进阶

## 任务与接口

输入 {"train":[数值,...],"test":[数值,...]}。train非空，长度≤1000，test可空，绝对值≤10000。仅用train总体均值和总体标准差(ddof=0)标准化test；train标准差为0时返回与test等长的全0数组。使用NumPy。

在 `practice/solutions/p34/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
{"train": [1, 1], "test": [100, 0]}
```

返回值

```json
[0, 0]
```

示例2输入

```json
{"train": [0, 2], "test": [1, 3]}
```

返回值

```json
[0.0, 2.0]
```

## 提示

所有参数只从训练集估计。

## 复杂度目标

时间 O(n+m)，空间 O(n+m)

## 本地测试

```text
python practice/judge.py p34
```

测试仅验证可观察结果；类、生成器、并发、NumPy/pandas 的使用与复杂度需要对照题面自查。
