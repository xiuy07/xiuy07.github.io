# p41 把运算组合成函数

所属第21章 · Python特性专题

## 任务与接口

输入 {"value":整数,"ops":[["add"或"mul",整数参数],...]}，按ops从左到右作用于value，返回最终整数。操作数与参数绝对值≤100，操作数≤20个。编写compose与闭包，把每个运算封装成函数；空ops返回原值。

在 `practice/solutions/p41/main.py` 中实现 `solve(data)`，返回JSON兼容的值。驱动器处理输入输出，不要额外print。

## 示例

示例1输入

```json
{"value": 4, "ops": [["add", 2], ["mul", 3]]}
```

返回值

```json
18
```

示例2输入

```json
{"value": 4, "ops": [["mul", 3], ["add", 2]]}
```

返回值

```json
14
```

## 提示

compose(outer,inner)返回x→outer(inner(x))；按执行顺序累计时，新操作应包在外层。

## 复杂度目标

O(k)次算术与O(k)个函数对象；大整数算术成本另计。
