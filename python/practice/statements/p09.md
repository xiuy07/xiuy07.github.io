# p09 成绩等级统计

所属第05章 · 基础

## 任务与接口

输入0..100的整数数组（≤10000项），返回 [A,B,C,D,F] 各等级人数，分界分别是90、80、70、60。

在 `practice/solutions/p09/main.py` 中实现 `solve(data)` 并返回结果；驱动器负责读取和输出JSON。不要在 solve 中 input 或 print。

## 示例

示例1输入

```json
[]
```

返回值

```json
[0, 0, 0, 0, 0]
```

示例2输入

```json
[0, 59, 60, 69, 70, 79, 80, 89, 90, 100]
```

返回值

```json
[2, 2, 2, 2, 2]
```

## 提示

从高到低判断互斥区间。

## 复杂度目标

时间 O(n)，空间 O(1)

## 本地测试

```text
python practice/judge.py p09
```
