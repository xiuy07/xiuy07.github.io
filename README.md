## 界面与交互

- 个人主页支持中英文页面，适配手机、平板和电脑。
- 生活记录使用 Hexo Butterfly，配有静态海面背景、交错波纹和点击水纹。
- 音乐页提供音频播放、音量调节与静音控制；小作品页面连接独立小游戏。
- 字体随静态资源提供；动态效果遵循系统“减少动态效果”设置。

## 维护与预览

根目录为个人主页，`en/` 为英文页面，`journal/` 为生活记录，`cv/` 为简历模板；共享图片、字体、样式与脚本位于 `assets/`。

仓库保存可直接发布的静态文件。推送 `main` 后由 GitHub Pages 发布，预览时可在仓库根目录运行：

```sh
python -m http.server 8000
```

浏览器打开 `http://localhost:8000/`。更新样式或脚本时同步调整资源版本，避免浏览器沿用旧缓存。

## 资源与许可

第三方主题、字体和程序的许可随对应资源提供。生活记录使用志莽行书、霞鹜文楷和 Noto 字体；404 跑酷玩法参考 zzzmhcn/dino。图片、音乐等引用素材的权利归相应权利人，仓库不额外授予其再分发许可。
