# 修源的个人主页与学习讲义

个人主页、生活记录与学习讲义，使用 GitHub Pages 发布。

- 职业主页：https://xiuy07.github.io/
- 生活记录：https://xiuy07.github.io/journal/
- 简历模板：https://xiuy07.github.io/cv/

- 讲义入口：https://xiuy07.github.io/handbooks/
- 计算机组成原理：https://xiuy07.github.io/coa/
- 人工智能导论（IAI）：https://xiuy07.github.io/iai/

`coa/` 与 `iai/` 是相互独立的静态讲义，图片、公式、代码和图解直接在正文中阅读。修改并推送 `main` 分支后，GitHub Pages 自动发布。

职业主页位于根目录，生活记录位于 `journal/`。学习讲义仍从 `handbooks/` 进入，`coa/` 与 `iai/` 保持原有地址。

计组以文字、公式、表格和代码组织知识与练习，保留22幅有助于理解的局部电路、运算部件和数据通路原图，附读图说明；8幅原题图紧邻题干。IAI保留教材正文版。

本仓库仅包含网页与讲义资源，不含实验提交材料、个人报告、账户凭据或本机临时文件。课件及引用素材的权利归相应权利人；不额外授予原素材再分发许可。第三方程序许可证保存在相应资源目录中。


生活记录使用 Hexo Butterfly，标题字体为 OFL 授权的志莽行书，正文字体为 Noto Sans SC。字体与主题许可证随静态资源提供。海浪与点击水纹由原生 SVG/CSS 实现，支持暂停与减少动态效果。
