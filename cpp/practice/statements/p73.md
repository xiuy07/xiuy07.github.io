# p73 滑动窗口最大值

## 题目

求长度固定为 K 的每个连续窗口中的最大值，按窗口从左到右输出。

## 输入格式

n K；第二行 n 个整数。

## 输出格式

一行 n-K+1 个最大值，以空格分隔。

## 数据范围与约定

1≤K≤n≤200000，|a[i]|≤10^9。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
8 3
1 3 -1 -3 5 3 6 7
```

输出：

```text
3 3 5 5 6 7
```

## 练习要求

目标复杂度为 O(n) 时间、O(K) 空间。先写朴素解核对小数据，再实现目标解。所有 22 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
