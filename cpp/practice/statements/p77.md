# p77 N 皇后方案计数

## 题目

在 N×N 棋盘放 N 个皇后，任意两个不能处于同一行、列或对角线。不同格子集合视为不同方案。

## 输入格式

一个整数 N。

## 输出格式

方案数量，不合并旋转和镜像。

## 数据范围与约定

1≤N≤12。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
4
```

输出：

```text
2
```

## 练习要求

目标复杂度为 O(N·N!) 上界时间、O(N) 空间。先写朴素解核对小数据，再实现目标解。所有 12 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
