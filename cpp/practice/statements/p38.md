# p38 手写循环队列

## 任务与接口

实现 CircularQueue(size_t capacity)，以及 size() const、bool push(long long)、long long front() const、long long pop()。容量固定，满时 push 返回 false 且不改变内容；空时 front/pop 抛 out_of_range。输入 capacity q，再给命令 P x、O、F、S，分别输出 push 成功的 1/0、出队值、队首、长度；空队列的 O/F 输出 EMPTY。

## 范围与要求

1≤capacity≤10000，q≤100000，|x|≤10⁹。每个操作 O(1)，使用环形数组。

## 示例输入

```text
3 8
P 1
P 2
F
O
P 3
P 4
P 5
S
```

## 示例输出

```text
1
1
1
1
1
1
0
3
```
