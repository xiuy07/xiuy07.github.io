# p16 static：活跃对象数量

## 任务与接口
实现 Live 类。默认构造和拷贝构造使活跃数量加一，析构减一，拷贝赋值不改变数量。static alive() 返回当前数量；使用 C++17 inline static 成员。

## 输入与输出
输入 n（0≤n≤100）。入口创建外层对象，再在内层创建 n 个它的副本并执行一次自赋值（若 n>0）。输出：初始数量、外层创建后、内层创建后、内层退出后、全部退出后，均各占一行。
入口使用 unique_ptr 管理副本，避免可选复制消除影响对象数量。

## 示例输入

```text
0
```

## 示例输出

```text
0
1
1
1
0
```
