# p11 账户类与不变式

## 任务
设计余额非负的 Account 类，余额用 long long 表示。deposit x 与 withdraw x 成功输出 OK，金额为负或余额不足输出 REJECT，并保持余额不变；balance 输出余额。

## 输入与输出
第一行 initial q，随后 q 条命令。0≤initial≤10¹²，q≤10000，|x|≤10¹²，保证累计合法余额不超过 10¹⁶。金额单位为整数分，允许存取 0。
请将余额设为 private，由公开成员函数维护约束。

## 示例输入

```text
100 4
deposit 20
withdraw 30
withdraw 100
balance
```

## 示例输出

```text
OK
OK
REJECT
90
```
