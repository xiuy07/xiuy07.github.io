# p66 最长无重复窗口

## 题目

给定 ASCII 字符串，求不含重复字符的最长连续片段长度。大小写不同视为不同字符。

## 输入格式

一行非空字符串 s。

## 输出格式

最长片段长度。

## 数据范围与约定

1≤|s|≤200000，字符 ASCII 码在 33..126。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
abcaacbb
```

输出：

```text
3
```

## 练习要求

目标复杂度为 O(n) 时间、O(字符集大小) 空间。先写朴素解核对小数据，再实现目标解。所有 25 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
