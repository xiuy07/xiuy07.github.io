# p23 模板栈：整数与字符串

## 任务与接口
实现 `template<class T> class Stack`，提供 push(const T&)、T pop()、const T& top() const、size() const。pop/top 空栈时抛 std::out_of_range；不需要默认构造 T。

## 输入与输出
第一行类型 I 或 S 和命令数 q。随后命令为 push value、pop、top、size。I 是整数，S 是不含空格的字符串。q≤10000。
push 不输出；pop 输出被删除的值；top 输出栈顶；size 输出长度；空栈访问输出 EMPTY（入口负责 catch）。期望 push 摊还 O(1)，其他操作 O(1)。

## 示例输入

```text
I 8
push 3
push -2
top
size
pop
top
pop
pop
```

## 示例输出

```text
-2
2
-2
3
3
EMPTY
```
