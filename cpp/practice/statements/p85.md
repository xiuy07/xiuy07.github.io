# p85 有障碍网格的路径计数

## 题目

从左上角到右下角，每次只能向右或向下。点可通行，星号不可通行。求路径数，对 1000000007 取模。

## 输入格式

H W；H 行网格。

## 输出格式

路径数模 1000000007；起点或终点被阻挡时为 0。

## 数据范围与约定

1≤H,W≤500。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
3 3
...
*..
...
```

输出：

```text
3
```

## 练习要求

目标复杂度为 O(HW) 时间、O(W) 空间。先写朴素解核对小数据，再实现目标解。所有 23 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
