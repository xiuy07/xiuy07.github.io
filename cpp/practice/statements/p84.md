# p84 正负号表达式计数

## 题目

为每个非负整数独立添加正号或负号，统计表达式值为目标 K 的符号分配数。零的正负号也视为不同选择。

## 输入格式

n K；第二行 n 个非负整数。

## 输出格式

符号分配数，不取模。

## 数据范围与约定

0≤n≤30，sum(a)≤1000，|K|≤2000。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
5 3
1 1 1 1 1
```

输出：

```text
5
```

## 练习要求

目标复杂度为 O(n·sum(a)) 时间、O(sum(a)) 空间。先写朴素解核对小数据，再实现目标解。所有 22 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
