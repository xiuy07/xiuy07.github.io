# p39 KMP：包括重叠的所有匹配

## 任务与接口

输入两行 text 与 pattern，允许空行，仅小写字母。输出所有匹配起点，下标从 0 开始；允许重叠。没有匹配输出空行；空模式匹配 0..text.length 的所有边界。

## 范围与要求

每行长度≤100000。手写前缀函数与 KMP，要求 O(|text|+|pattern|+输出长度)。

## 示例输入

```text
aaaaa
aaa
```

## 示例输出

```text
0 1 2
```
