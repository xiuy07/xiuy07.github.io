# p56 Bellman–Ford：可达负环

## 任务与接口

输入 n m s，再给 m 条有向边 u v w。若存在从 s 可达的负环，只输出 NEGATIVE CYCLE；否则输出每个点的最短距离，不可达用 INF。不受理不可达负环作为错误。

## 范围与要求

1≤n≤500，m≤3000，|w|≤10⁹，点从 0 开始。要求 O(nm)。

## 示例输入

```text
4 1 0
0 1 5
```

## 示例输出

```text
0 5 INF INF
```
