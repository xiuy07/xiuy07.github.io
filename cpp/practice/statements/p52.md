# p52 DFS：连通分量计数

## 任务与接口

输入 n m 与 m 条无向边 u v。输出连通分量个数，孤立点也是一个分量。

## 范围与要求

1≤n≤100000，m≤200000，0≤u,v<n，允许自环与重复边。O(n+m)，使用显式 DFS 栈。

## 示例输入

```text
5 3
0 1
0 2
1 3
```

## 示例输出

```text
2
```
