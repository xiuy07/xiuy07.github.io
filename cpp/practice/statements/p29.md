# p29 柱状图最大矩形

## 任务
给出每根宽为 1 的柱子的非负高度，求完全位于柱状图内的最大矩形面积。

## 输入与输出
第一行 n，第二行 n 个高度。0≤n≤100000，0≤height≤10⁹。输出最大面积，空柱状图为 0。
要求 O(n) 时间，面积使用 long long。练习维护保存下标的单调栈和末尾零哨兵。

## 示例输入

```text
3
2 3 1
```

## 示例输出

```text
4
```
