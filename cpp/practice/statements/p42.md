# p42 从先序、中序重建二叉树

## 任务与接口

输入 n，随后一行先序、一行中序。结点值互不相同，保证序列描述同一棵合法二叉树。输出后序序列。n=0 时三行序列均可为空。

## 范围与要求

0≤n≤100000，|value|≤10⁹。要求 O(n)；避免每一层线性寻找根位置与深递归。

## 示例输入

```text
3
0 1 2
0 1 2
```

## 示例输出

```text
2 1 0
```
