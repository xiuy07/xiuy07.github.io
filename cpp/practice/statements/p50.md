# p50 冗余边的数量

## 任务与接口

输入 n m 与 m 条无向边 u v，按输入顺序加入。若加入前端点已经连通，则这条边是冗余边。输出冗余边总数；自环和重复边也计入。

## 范围与要求

1≤n≤100000，m≤200000，结点从 0 开始。要求并查集。

## 示例输入

```text
3 4
0 1
1 2
0 2
1 1
```

## 示例输出

```text
2
```
