# p25 哈希查找：确定顺序的两数之和

## 任务
找不同下标 i<j，使 a[i]+a[j]=target。存在多个答案时，先取 j 最小者，再取 i 最小者；不存在则输出 -1 -1。

## 输入与输出
第一行 n target，第二行 n 个整数，0≤n≤100000，所有数绝对值≤10⁹。输出一行 i j，下标从 0 开始。
要求期望 O(n) 时间、O(n) 空间。用 long long 计算补数。

## 示例输入

```text
4 8
5 1 7 3
```

## 示例输出

```text
1 2
```
