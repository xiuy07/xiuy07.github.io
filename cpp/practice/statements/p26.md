# p26 词频统计与 Lambda 排序

## 任务
统计每个词出现次数，按次数降序输出；次数相同按字典序升序。

## 输入与输出
输入 n 及 n 个单词。0≤n≤100000，单词仅含小写字母、长度≤30。先输出不同词数量，再逐行输出 `word count`。
用 map/unordered_map 计数，再将结果排序。期望 O(输入长度+k log k)。

## 示例输入

```text
6
cpp code cpp book code cpp
```

## 示例输出

```text
3
cpp 3
code 2
book 1
```
