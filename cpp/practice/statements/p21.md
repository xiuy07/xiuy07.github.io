# p21 有理数运算符

## 任务与接口
实现 Rational(long long numerator,long long denominator)，以及非修改性的 +、-、< 和流输出。结果约分、分母为正，零输出 0/1。

## 输入与输出
输入 a b c d，表示 a/b 和 c/d。分母非零，每个输入绝对值≤1000。输出和、差、a/b<c/d 的结果（0/1），各占一行。
固定入口使用 const 对象和 ostringstream，运算不能改变原对象。

## 示例输入

```text
1 2 1 3
```

## 示例输出

```text
5/6
1/6
0
```
