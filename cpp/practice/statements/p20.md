# p20 NVI 与多态流输出

## 任务与接口
实现 Report：公开 render(ostream&) const 输出方括号，内部调用虚 write(ostream&) const。实现非成员 operator<< 返回原流。TextReport(string) 和 NumberReport(long long) 分别写入文本与数字，基类有虚析构。

## 输入与输出
输入 n，随后 T word 或 N number。word 为无空格字母串，数字绝对值≤10⁹，n≤1000。每个对象一行，格式如 [hello]、[42]。
入口传入 ostringstream 并通过 const Report& 输出，不能在内部写死 cout。

## 示例输入

```text
2
T hello
N 42
```

## 示例输出

```text
[hello]
[42]
```
