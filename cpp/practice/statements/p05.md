# p05 有序序列原地去重

## 任务
输入非递减整数序列，原地把不同值放到序列前部，保持递增顺序。

## 输入与输出
第一行 n，第二行 n 个整数。先输出不同值的数量 k，再输出有效前缀中的 k 个数（空序列的第二行为空）。0≤n≤100000，|aᵢ|≤10⁹。
要求 O(n) 时间，除输入数组外 O(1) 空间；不要用 set 代替原地操作。

## 示例输入

```text
5
1 1 2 4 4
```

## 示例输出

```text
3
1 2 4
```
