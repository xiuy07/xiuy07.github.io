# p78 网格中的单词路径

## 题目

从任意格开始，沿上下左右相邻格拼出目标单词。同一条路径不能重复使用格子，判断是否存在。

## 输入格式

H W；H 行大写字母网格；最后一行目标单词。

## 输出格式

存在输出 YES，否则 NO。

## 数据范围与约定

1≤H,W≤6，1≤单词长度≤12。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
3 4
ABCE
SFCS
ADEE
ABCCED
```

输出：

```text
YES
```

## 练习要求

目标复杂度为 O(HW·4^L) 上界时间、O(HW+L) 空间。先写朴素解核对小数据，再实现目标解。所有 22 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
