# p53 拓扑排序：字典序最小

## 任务与接口

输入 n m 与 m 条有向边 u v。输出字典序最小的拓扑序列；有环则只输出 CYCLE。允许重复边。

## 范围与要求

1≤n≤100000，m≤200000，0≤u,v<n。使用 Kahn 算法与最小堆，O((n+m)log n)。

## 示例输入

```text
4 1
1 3
```

## 示例输出

```text
0 1 2 3
```
