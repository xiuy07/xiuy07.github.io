# p55 Dijkstra：非负边单源最短路

## 任务与接口

输入 n m s，再给 m 条有向边 u v w。输出从 s 到每个点的最短距离，不可达用 INF。允许自环、重边。

## 范围与要求

1≤n≤100000，m≤200000，0≤w≤10⁹，点从 0 开始。使用堆优化 Dijkstra，O((n+m)log(n+m))。

## 示例输入

```text
4 8 0
0 0 18
3 2 61
0 2 21
3 3 30
3 2 1
2 3 36
1 0 100
0 0 33
```

## 示例输出

```text
0 INF 21 57
```
