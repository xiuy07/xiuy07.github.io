# p90 最少移除障碍：0–1 BFS

## 题目

网格中 0 可直接进入，1 需要移除一个障碍。允许四方向移动，求从左上到右下最少移除数量。起终点保证为 0。

## 输入格式

H W；H 行只含 0 和 1 的字符串。

## 输出格式

最少移除数。

## 数据范围与约定

1≤H,W≤500。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
3 3
010
111
000
```

输出：

```text
1
```

## 练习要求

目标复杂度为 O(HW) 时间、O(HW) 空间。先写朴素解核对小数据，再实现目标解。所有 22 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
