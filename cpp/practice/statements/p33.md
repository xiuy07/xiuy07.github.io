# p33 二分查找的第一个边界

## 任务与接口

输入 n q，接着 n 个非降序整数，再给 q 个查询 x。每次输出第一个满足 a[i]≥x 的下标；不存在则输出 n。下标从 0 开始。

## 范围与要求

0≤n≤100000，1≤q≤100000，|数值|≤10¹²。手写半开区间二分，每次查询 O(log n)。

## 示例输入

```text
4 6
1 2 2 8
-1000000000000 -3 0 2 9 1000000000000
```

## 示例输出

```text
0
0
0
1
4
4
```
