# p22 前置与后置自增

## 任务与接口
实现 StepCounter(int)、value() const、前置 ++ 与后置 ++。前置返回自身引用，后置返回修改前的值。

## 输入与输出
输入 x（|x|≤10⁹）。入口先执行 old=c++，输出 old 和 c 的值；再执行 ref=++c，输出 ref 的值以及 ref 是否就是 c（0/1）。
固定入口用 static_assert 检查返回类型。不得返回局部变量的引用。

## 示例输入

```text
4
```

## 示例输出

```text
4 5
6 1
```
