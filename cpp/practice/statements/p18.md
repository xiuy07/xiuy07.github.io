# p18 多态对象的独立克隆

## 任务与接口
基类 Record 提供虚析构、value() const、bump()、clone() const。clone 返回 `unique_ptr<Record>`。ValueRecord(int) 保存整数，实现这些接口。

## 输入与输出
输入 x k（|x|≤10⁹，0≤k≤100）。入口通过基类指针 clone，再把副本 bump k 次。依次输出三行：原对象的值、副本的值，以及销毁原对象后再次读取的副本值。
clone 必须返回独立对象，不得把 this 包装成新的 unique_ptr。

## 示例输入

```text
5 3
```

## 示例输出

```text
5
8
8
```
