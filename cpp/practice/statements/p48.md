# p48 哈希计数：首个只出现一次的值

## 任务与接口

输入 n 与 n 个整数。输出第一个在整段序列中仅出现一次的元素下标（从 0 开始）；不存在输出 −1。

## 范围与要求

0≤n≤100000，|a[i]|≤10¹²。允许 unordered_map。期望 O(n)，注意哈希最坏复杂度不保证线性。

## 示例输入

```text
5
4 2 4 3 2
```

## 示例输出

```text
3
```
