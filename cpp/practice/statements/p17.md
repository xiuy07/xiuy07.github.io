# p17 虚函数：图形面积

## 任务与接口
实现抽象类 Shape，提供 virtual long long area() const 和虚析构；Rect(a,b)、Square(a) 分别计算矩形和正方形面积。

## 输入与输出
输入 n，随后 n 行 R a b 或 S a。0≤n≤1000，0≤边长≤10⁶。固定入口用 `vector<unique_ptr<Shape>>` 保存对象，通过 const Shape& 查询。
每个面积一行，最后输出 `total 总面积`。不能用类型标签在基类里 switch 代替虚调用。

## 示例输入

```text
2
R 2 5
S 3
```

## 示例输出

```text
10
9
total 19
```
