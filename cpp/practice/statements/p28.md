# p28 optional 与 variant 状态盒

## 任务
用 `optional<variant<long long,string>>` 保存可能为空的状态，初始为空。支持 INT x、TEXT word、CLEAR、ADD x、PRINT。

## 输入与输出
第一行 q，随后 q 条命令，q≤10000。INT/TEXT 替换状态，CLEAR 清空，均不输出。ADD 只给整数加值；空状态输出 EMPTY、文本状态输出 TYPE_ERROR，失败不改变状态。PRINT 输出 EMPTY、I 数字 或 S 文本。
|整数|≤10⁹，保证累加不溢出 long long；文本无空格。请用 get_if/visit 进行类型安全访问。

## 示例输入

```text
9
PRINT
INT 7
ADD 3
PRINT
TEXT cpp
ADD 1
PRINT
CLEAR
PRINT
```

## 示例输出

```text
EMPTY
I 10
TYPE_ERROR
S cpp
EMPTY
```
