# p09 单链表原地反转

## 任务
把输入序列构造成单链表，迭代反转 next 连接，再输出反转后的序列。结束前释放全部结点。

## 输入与输出
第一行 n，第二行 n 个整数。0≤n≤100000，|aᵢ|≤10⁹。输出一行反转序列；空链表输出空行。
要求 O(n) 时间、O(1) 反转额外空间。测试输出不能自动保证你真的改变连接，请自行检查实现与释放。

## 示例输入

```text
3
4 1 7
```

## 示例输出

```text
7 1 4
```
