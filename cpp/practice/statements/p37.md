# p37 括号匹配与栈不变式

## 任务与接口

输入一整行，只含 ()[]{}，允许空行。若括号正确嵌套输出 1，否则输出 0。

## 范围与要求

长度≤100000。要求 O(n) 时间，使用栈而不是反复删除子串。

## 示例输入

```text
([]{})
```

## 示例输出

```text
1
```
