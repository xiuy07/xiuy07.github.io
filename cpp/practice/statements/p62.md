# p62 0/1 背包：为什么倒序更新

## 任务与接口

输入 n capacity，随后 n 行 weight value。每件物品最多使用一次，总重量不能超过 capacity，不必装满。输出最大总价值。

## 范围与要求

0≤n≤1000，0≤capacity≤10000，1≤weight≤10000，0≤value≤10⁹，n×capacity≤10⁷。要求 O(n×capacity) 时间、O(capacity) 空间。

## 示例输入

```text
3 21
8 36
14 16
8 9
```

## 示例输出

```text
45
```
