# p67 不同的零和三元组

## 题目

从不同下标选三个整数，和为零。只按三个数的值区分方案，排列及重复下标组合不增加方案数。

## 输入格式

第一行 n；第二行 n 个整数。

## 输出格式

不同数值三元组的数量。

## 数据范围与约定

0≤n≤800，|a[i]|≤10^9。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
6
-1 0 1 2 -1 -4
```

输出：

```text
2
```

## 练习要求

目标复杂度为 O(n²) 时间、排序 O(log n) 辅助栈空间。先写朴素解核对小数据，再实现目标解。所有 19 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
