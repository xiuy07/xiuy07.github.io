# p30 最大空白矩形

## 任务
网格中的 . 可用、* 为障碍，求只包含可用格子的最大轴对齐矩形。

## 输入与输出
每个测试文件可能包含多组 H W 和 H 行网格；以 0 0 结束。1≤H,W≤500，数据集≤20。每组输出一行最大面积，全障碍为 0。
要求 O(HW) 时间、O(W) 额外空间。每行重置栈但保留 height；每个数据集重置答案和 height。

## 示例输入

```text
3 5
..*..
.....
*....
0 0
```

## 示例输出

```text
8
```
