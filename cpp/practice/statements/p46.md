# p46 Huffman：最小合并代价

## 任务与接口

输入 n 与 n 个非负权值。每次合并两个权值，代价为其和，再将和放回，直到剩下一个。求最小总代价。n≤1 时答案为 0。

## 范围与要求

0≤n≤100000，0≤w≤10⁹。要求 O(n log n)，总代价使用 long long。

## 示例输入

```text
4
1 2 3 4
```

## 示例输出

```text
19
```
