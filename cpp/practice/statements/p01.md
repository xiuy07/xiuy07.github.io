# p01 大整数累计

## 任务
读入 n 个整数，输出总和。用于确认编译、输入输出和 64 位累计。

## 输入与输出
第一行 n，第二行 n 个整数。输出一行总和；n=0 时输出 0。
范围：0≤n≤100000，|aᵢ|≤10⁹。期望 O(n) 时间、O(1) 额外空间。

## 示例输入

```text
4
1000000000 1000000000 1000000000 1000000000
```

## 示例输出

```text
4000000000
```
