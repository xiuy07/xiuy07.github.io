# p31 综合：最小值栈

## 任务
设计 MinStack，支持 push x、pop、top、min。push 不输出；pop 输出并删除栈顶；top 输出栈顶；min 输出当前最小值。空栈访问输出 EMPTY。

## 输入与输出
第一行 q，随后 q 条命令。0≤q≤100000，|x|≤10⁹。要求 top/min/pop 为 O(1)，push 摊还 O(1)，总空间 O(q)。重复最小值也必须正确。

## 示例输入

```text
8
push 3
push 1
push 1
min
pop
min
pop
min
```

## 示例输出

```text
1
1
1
1
3
```
