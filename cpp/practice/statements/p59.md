# p59 稳定归并排序

## 任务与接口

输入 n，随后 n 行 key id。仅按 key 从小到大排序并输出 n 行 key id；key 相同必须维持输入先后，id 不参与比较。

## 范围与要求

0≤n≤100000，|key|,|id|≤10⁹。手写稳定归并 O(n log n)，不要使用 sort/stable_sort。

## 示例输入

```text
5
-2 44
-5 -10
1 -100
-2 -30
-1 35
```

## 示例输出

```text
-5 -10
-2 44
-2 -30
-1 35
1 -100
```
