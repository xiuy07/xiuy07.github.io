# p76 折半搜索：子集目标和

## 题目

每个下标可选或不选，统计所选数之和为 K 的子集数量。包含空集，相同数在不同下标视为不同选择。

## 输入格式

n K；第二行 n 个整数。

## 输出格式

满足条件的子集数量。

## 数据范围与约定

0≤n≤36，|a[i]|、|K|≤10^9。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
4 2
2 -1 3 0
```

输出：

```text
4
```

## 练习要求

目标复杂度为 O(n·2^(n/2)) 时间、O(2^(n/2)) 空间。先写朴素解核对小数据，再实现目标解。所有 21 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
