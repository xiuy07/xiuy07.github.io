# p02 最小值、最大值与总和

## 任务
扫描一组整数，输出最小值、最大值和总和，三个数用空格隔开。

## 输入与输出
第一行 n，第二行 n 个整数。1≤n≤100000，|aᵢ|≤10⁹。输出一行 `minimum maximum sum`。
不要将最小值或最大值无条件初始化为 0。期望 O(n)。

## 示例输入

```text
4
8 -2 8 0
```

## 示例输出

```text
-2 8 14
```
