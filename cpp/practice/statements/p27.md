# p27 异常边界：受检整数除法

## 任务
编写 divide(a,b)：b=0 时抛 std::domain_error，否则返回 C++ 整数除法结果。main 捕获该异常并输出 ERROR，然后继续处理后续输入。

## 输入与输出
第一行 q，随后 q 行 a b。0≤q≤10000，|a|,|b|≤10⁹。每行输出商或 ERROR。整数除法向零截断。
不要先执行除法再检查 b；题目范围排除了最小有符号整数除以 -1 的额外溢出问题。

## 示例输入

```text
3
7 2
-7 2
3 0
```

## 示例输出

```text
3
-3
ERROR
```
