# p54 AOE：工期与关键活动

## 任务与接口

输入 n m，再给 m 行 u v w，活动从事件 u 指向 v、耗时 w，活动编号从 1 开始。允许多个源和汇。若有环输出 CYCLE；否则第一行输出全部活动完成的最短工期，第二行按输入次序输出关键活动编号。空集合输出空行。

## 范围与要求

1≤n≤100000，m≤200000，0≤u,v<n，0≤w≤10⁹。所有汇共用最早可行的统一项目截止时间。O(n+m) 或带堆拓扑的 O((n+m)log n)。

## 示例输入

```text
4 1
1 3 0
```

## 示例输出

```text
0
1
```
