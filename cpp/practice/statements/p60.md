# p60 归并与逆序对

## 任务与接口

输入 n 与 n 个整数。输出满足 i<j 且 a[i]>a[j] 的下标对数；相等不算逆序。

## 范围与要求

0≤n≤200000，|a[i]|≤10¹²。O(n log n)，答案 long long。

## 示例输入

```text
3
3 1 2
```

## 示例输出

```text
2
```
