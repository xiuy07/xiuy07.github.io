# p80 编辑距离

## 题目

一次操作可插入、删除或替换一个字符。求把第一行字符串变为第二行所需的最少次数。

## 输入格式

恰好两行小写字母字符串，允许空行。

## 输出格式

最少操作次数。

## 数据范围与约定

0≤两行长度≤1000。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
horse
ros
```

输出：

```text
3
```

## 练习要求

目标复杂度为 O(nm) 时间、O(m) 空间。先写朴素解核对小数据，再实现目标解。所有 24 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
