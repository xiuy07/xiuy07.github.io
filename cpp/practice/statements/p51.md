# p51 BFS：无权最短距离

## 任务与接口

输入 n m s 与 m 条无向边 u v。输出从 s 到 0..n−1 的最少边数，不可达输出 −1。允许自环与重复边。

## 范围与要求

1≤n≤100000，m≤200000，0≤s,u,v<n。邻接表与 BFS，O(n+m)。

## 示例输入

```text
5 3 0
0 1
0 2
1 3
```

## 示例输出

```text
0 1 1 2 -1
```
