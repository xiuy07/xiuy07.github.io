# p15 const 查询与 mutable 统计

## 任务与接口
实现 Counter(int)，inc() 将值加一，get() const 返回当前值并增加查询次数，reads() const 返回查询次数且不增加它。使用 mutable 保存统计字段。

## 输入与输出
输入 initial k（|initial|≤10⁹，0≤k≤100）。入口通过 const 引用调用一次 get，调用 inc k 次，再调用一次 get，最后读取 reads。输出三行：初值、增加后的值、查询次数 2。
不能通过全局变量保存统计；每个对象拥有独立状态。

## 示例输入

```text
5 2
```

## 示例输出

```text
5
7
2
```
