# p93 最多不冲突活动

## 题目

每个活动占用半开区间 [start,end)，结束时可立即开始下一项。选择最多个两两不冲突活动。

## 输入格式

n；随后 n 行 start end。

## 输出格式

最多可选活动数。

## 数据范围与约定

0≤n≤200000，-10^9≤start<end≤10^9。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
5
7 9
-10 -6
-2 0
0 2
-2 -1
```

输出：

```text
4
```

## 练习要求

目标复杂度为 O(n log n) 时间、O(n) 存储空间。先写朴素解核对小数据，再实现目标解。所有 21 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
