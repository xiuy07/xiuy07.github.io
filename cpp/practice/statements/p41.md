# p41 二叉树的三种遍历

## 任务与接口

输入 n root，接着 n 行 value left right，结点编号为 0..n−1，空孩子为 −1。保证为合法二叉树，所有结点都从 root 可达；n=0 时 root=−1。输出三行：先序、中序、后序的值。

## 范围与要求

0≤n≤100000，|value|≤10⁹。要求 O(n)，使用显式栈以支持长链。

## 示例输入

```text
3 0
0 -1 1
1 -1 2
2 -1 -1
```

## 示例输出

```text
0 1 2
0 1 2
2 1 0
```
