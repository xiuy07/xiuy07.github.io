# p86 最长公共子序列

## 题目

可分别删除两行字符串中的字符，求两者能够得到的相同子序列的最大长度。保留字符顺序，字符不要求连续。

## 输入格式

恰好两行小写字母字符串，允许空行。

## 输出格式

最长公共子序列长度。

## 数据范围与约定

0≤两行长度≤1000。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
abcde
ace
```

输出：

```text
3
```

## 练习要求

目标复杂度为 O(nm) 时间、O(m) 空间。先写朴素解核对小数据，再实现目标解。所有 23 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
