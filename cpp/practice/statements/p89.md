# p89 二叉树最大路径和

## 题目

结点有正负权值，求一条非空简单路径的最大权值和。路径不要求经过根，可以只含一个结点。

## 输入格式

n；接下来 n 行，第 i 行为 value left right，孩子编号 0 表示不存在；保证是一棵以 1 为根的二叉树。

## 输出格式

最大路径和。

## 数据范围与约定

1≤n≤200000，|value|≤10^9。结点和位置编号从 1 开始；字符串不含空白。时限为每个测试文件 2 秒，使用 C++17。

## 自编样例

输入：

```text
5
9 5 2
-6 3 4
9 0 0
9 0 0
-8 0 0
```

输出：

```text
12
```

## 练习要求

目标复杂度为 O(n) 时间、O(n) 空间。先写朴素解核对小数据，再实现目标解。所有 22 组测试在学习包内公开，可自行增加数据；通过测试还需能解释不变式与复杂度。
