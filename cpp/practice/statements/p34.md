# p34 允许空段的最大子段和

## 任务与接口

输入 n，随后 n 个整数。输出连续子段的最大和，允许选择空段，因此答案至少是 0。

## 范围与要求

0≤n≤100000，|a[i]|≤10¹²。要求 O(n) 时间、O(1) 额外状态。

## 示例输入

```text
5
-4 3 -1 5 -9
```

## 示例输出

```text
7
```
