# p82 每件最多一次的背包：题解

## 从朴素解到目标解

以容量为状态，一维压缩后每件物品倒序枚举容量。价值用 long long。

## 为什么正确

倒序让 dp[c-weight] 仍属于上一物品层，确保当前物品不重复使用；不选与选择覆盖全部方案。

## 复杂度

O(nC) 时间、O(C) 空间。

## 易错点与手动复盘

正序会变成完全背包；本题不要求恰好装满，所以初值可以全 0。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n, c;
    cin >> n >> c;
    vector<ll> d(c + 1);
    while (n--) {
        int w;
        ll v;
        cin >> w >> v;
        for (int j = c; j >= w; --j)
            d[j] = max(d[j], d[j - w] + v);
    }
    cout << d[c] << '\n';
}
```
