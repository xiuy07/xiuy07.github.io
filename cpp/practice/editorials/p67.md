# p67 不同的零和三元组：题解

## 从朴素解到目标解

排序后固定第一个数，双指针搜索另外两个。和太小时左端右移，和太大时右端左移；命中后跳过重复值。

## 为什么正确

固定首值后，有序性保证可以排除当前左值或右值；跳过相同首值和左右值让每个数值三元组只被统计一次。

## 复杂度

O(n²) 时间、排序 O(log n) 辅助栈空间。

## 易错点与手动复盘

不是统计下标三元组；求和用 long long；固定首值也要去重。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    vector<ll> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    ll ans = 0;
    for (int i = 0; i < n; ++i) {
        if (i && a[i] == a[i - 1])
            continue;
        int l = i + 1, r = n - 1;
        while (l < r) {
            ll s = a[i] + a[l] + a[r];
            if (s < 0)
                ++l;
            else if (s > 0)
                --r;
            else {
                ++ans;
                ll x = a[l], y = a[r];
                while (l < r && a[l] == x)
                    ++l;
                while (l < r && a[r] == y)
                    --r;
            }
        }
    }
    cout << ans << '\n';
}
```
