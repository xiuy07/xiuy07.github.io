# p96 状态压缩：访问全部站点：题解

## 从朴素解到目标解

dp[mask][u] 表示已访问集合为 mask、终点为 u 的最小费用。初始只含站点 1，向未访问站点转移，最后补回站点 1 的费用。

## 为什么正确

路径按访问集合与终点划分；从最后一次移动移除终点得到更小集合的最优子问题，所有合法前驱都会被枚举。

## 复杂度

O(2^n·n²) 时间、O(2^n·n) 空间。

## 易错点与手动复盘

不要只做普通最短路，那会重复站点或漏站；必须补回起点费用；不对称矩阵不能当无向图。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    vector<vector<ll>> a(n, vector<ll>(n));
    for (auto &r : a)
        for (auto &x : r)
            cin >> x;
    if (n == 1) {
        cout << 0 << '\n';
        return 0;
    }
    const ll INF = LLONG_MAX / 4;
    int all = 1 << n;
    vector<ll> d((size_t)all * n, INF);
    d[n] = 0;
    for (int mask = 1; mask < all; mask += 2)
        for (int u = 0; u < n; ++u) {
            ll cur = d[(size_t)mask * n + u];
            if (cur == INF)
                continue;
            for (int v = 1; v < n; ++v)
                if (!(mask >> v & 1)) {
                    auto &to = d[(size_t)(mask | 1 << v) * n + v];
                    to = min(to, cur + a[u][v]);
                }
        }
    ll ans = INF;
    for (int u = 1; u < n; ++u)
        ans = min(ans, d[(size_t)(all - 1) * n + u] + a[u][0]);
    cout << ans << '\n';
}
```
