# p77 N 皇后方案计数：题解

## 从朴素解到目标解

每行只放一个皇后，用列、主对角线、次对角线标记占用。尝试一列前检查，递归后恢复标记。

## 为什么正确

递归深度决定当前行，每层遍历所有合法列，不会漏掉合法棋盘；冲突分支无法完成合法解，立即剪去安全。

## 复杂度

O(N·N!) 上界时间、O(N) 空间。

## 易错点与手动复盘

回溯必须恢复三种标记；对角线 r-c 需要偏移；镜像方案仍分开计数。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
using namespace std;
using ll = long long;
int n;
ll ans = 0;
bool col[12], d1[25], d2[25];
void dfs(int r) {
    if (r == n) {
        ++ans;
        return;
    }
    for (int c = 0; c < n; ++c) {
        int x = r - c + n, y = r + c;
        if (col[c] || d1[x] || d2[y])
            continue;
        col[c] = d1[x] = d2[y] = true;
        dfs(r + 1);
        col[c] = d1[x] = d2[y] = false;
    }
}
int main() {
    cin >> n;
    dfs(0);
    cout << ans << '\n';
}
```
