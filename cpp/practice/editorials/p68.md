# p68 目标和连续子数组：题解

## 从朴素解到目标解

设前缀和为 s，查找此前有多少前缀和等于 s-K。初始把空前缀 0 记为出现一次。

## 为什么正确

子数组和是两个前缀和之差；每个右端点只配对更早的前缀位置，既不漏计从开头开始的子数组，也不计空子数组。

## 复杂度

期望 O(n) 时间、O(n) 空间。

## 易错点与手动复盘

负数使普通同向窗口失效；先查询后更新；前缀和及计数均用 long long。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    ll k, s = 0, ans = 0, x;
    cin >> n >> k;
    unordered_map<ll, ll> f;
    f.reserve(n * 2 + 1);
    f[0] = 1;
    while (n--) {
        cin >> x;
        s += x;
        auto it = f.find(s - k);
        if (it != f.end())
            ans += it->second;
        ++f[s];
    }
    cout << ans << '\n';
}
```
