# p94 最高同时在线人数：题解

## 从朴素解到目标解

进入记 +1，离开记 -1，按时间排序扫描。相同时间必须先处理离开，再处理进入。

## 为什么正确

两个事件之间人数不变，所有变化只在端点发生；按半开区间规则处理同时间事件后，扫描覆盖每个可能的最大人数区间。

## 复杂度

O(n log n) 时间、O(n) 空间。

## 易错点与手动复盘

同时间若先进入，会制造不存在的瞬时峰值；可把同时间增量合并，避免顺序歧义。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    vector<pair<ll, int>> e;
    while (n--) {
        ll l, r;
        cin >> l >> r;
        e.push_back({l, 1});
        e.push_back({r, -1});
    }
    sort(e.begin(), e.end());
    int cur = 0, ans = 0;
    for (auto [t, d] : e) {
        (void)t;
        cur += d;
        ans = max(ans, cur);
    }
    cout << ans << '\n';
}
```
