# p74 频率最高的 K 个数：题解

## 从朴素解到目标解

先哈希计数，再用容量 K 的堆保留最佳项。把候选写为 (频率,-数值)，最小堆的堆顶就是已保留的最差项。

## 为什么正确

扫描每个候选后，若超过 K 就移除最差项，所以归纳保持当前最优 K 项。最后按候选键降序输出。

## 复杂度

O(n+U log K+K log K) 期望时间、O(U+K) 空间，U 为不同值数。

## 易错点与手动复盘

必须明确频率相同的次序；负号在 long long 中计算，避免最小 int 取反问题。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <queue>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    unordered_map<ll, int> f;
    while (n--) {
        ll x;
        cin >> x;
        ++f[x];
    }
    using P = pair<int, ll>;
    priority_queue<P, vector<P>, greater<P>> q;
    for (auto [x, c] : f) {
        q.push({c, -x});
        if ((int)q.size() > k)
            q.pop();
    }
    vector<P> v;
    while (!q.empty()) {
        v.push_back(q.top());
        q.pop();
    }
    reverse(v.begin(), v.end());
    for (int i = 0; i < k; ++i)
        cout << (i ? " " : "") << -v[i].second;
    cout << '\n';
}
```
