# p79 最长严格递增子序列：题解

## 从朴素解到目标解

先写 O(n²) 的结尾 DP。优化为 tails[len-1] 记录长度为 len 的子序列能有的最小尾值，用 lower_bound 替换第一个不小于 x 的位置。

## 为什么正确

同长度下更小尾值保留更多扩展可能；替换不改变已存在的最大长度。只有 x 大于所有尾值时才能扩展长度。

## 复杂度

O(n log n) 时间、O(n) 空间。

## 易错点与手动复盘

严格递增用 lower_bound；upper_bound 会把相等值当作可扩展；tails 本身不保证是原序列的一条子序列。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<ll> t;
    while (n--) {
        ll x;
        cin >> x;
        auto it = lower_bound(t.begin(), t.end(), x);
        if (it == t.end())
            t.push_back(x);
        else
            *it = x;
    }
    cout << t.size() << '\n';
}
```
