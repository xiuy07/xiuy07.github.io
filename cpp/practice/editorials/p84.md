# p84 正负号表达式计数：题解

## 从朴素解到目标解

把正号元素的和记为 P，总和为 S，则 2P=S+K。检查范围与奇偶性后，转化为子集和计数的 0/1 背包。

## 为什么正确

每个符号分配唯一对应正号下标集合，且满足 P-(S-P)=K。倒序计数让每个下标使用一次。

## 复杂度

O(n·sum(a)) 时间、O(sum(a)) 空间。

## 易错点与手动复盘

零使每个计数翻倍；空集合且 K=0 有一种方案；S+K 为负或奇数时无解。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <cstdlib>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    int s = 0;
    for (auto &x : a) {
        cin >> x;
        s += x;
    }
    if (abs(k) > s || (s + k) % 2) {
        cout << 0 << '\n';
        return 0;
    }
    int t = (s + k) / 2;
    vector<ll> d(t + 1);
    d[0] = 1;
    for (int x : a)
        for (int j = t; j >= x; --j)
            d[j] += d[j - x];
    cout << d[t] << '\n';
}
```
