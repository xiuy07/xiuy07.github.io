# p71 顺序装运的最小容量：题解

## 从朴素解到目标解

容量固定时，每天尽量多装可最小化天数。容量越大越容易可行；在最大单件重量与总重量之间找第一个可行容量。

## 为什么正确

固定容量的贪心每天结束位置不会比任何可行装法更早。可行性对容量单调，所以二分保留第一个可行答案。

## 复杂度

O(n log(sum(a))) 时间、O(n) 空间。

## 易错点与手动复盘

不能重排货物；D 可以大于 n；二分上界与当前载荷用 long long。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, d;
    cin >> n >> d;
    vector<ll> a(n);
    ll l = 0, r = 0;
    for (auto &x : a) {
        cin >> x;
        l = max(l, x);
        r += x;
    }
    auto ok = [&](ll c) {
        int days = 1;
        ll s = 0;
        for (ll x : a) {
            if (s + x > c) {
                ++days;
                s = 0;
            }
            s += x;
        }
        return days <= d;
    };
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (ok(m))
            r = m;
        else
            l = m + 1;
    }
    cout << l << '\n';
}
```
