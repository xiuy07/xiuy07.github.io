# p90 最少移除障碍：0–1 BFS：题解

## 从朴素解到目标解

把进入格子的代价看作 0/1 边权。双端队列中，0 权更新放队首，1 权更新放队尾，并忽略已过期距离项。

## 为什么正确

队列按待处理距离分为当前层与下一层，0 边不会推迟更小距离。该顺序等价于对 0/1 权的 Dijkstra 优先处理最小距离。

## 复杂度

O(HW) 时间、O(HW) 空间。

## 易错点与手动复盘

不能像无权 BFS 一样首次入队就永久锁定距离；更新进入格子的代价，不是离开格子代价。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <deque>
#include <iostream>
#include <string>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int h, w;
    cin >> h >> w;
    vector<string> g(h);
    for (auto &s : g)
        cin >> s;
    const int INF = 1000000000;
    vector<int> d(h * w, INF);
    deque<pair<int, int>> q;
    d[0] = 0;
    q.push_back({0, 0});
    int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
    while (!q.empty()) {
        auto [u, z] = q.front();
        q.pop_front();
        if (z != d[u])
            continue;
        int x = u / w, y = u % w;
        for (int k = 0; k < 4; ++k) {
            int a = x + dx[k], b = y + dy[k];
            if (a < 0 || a >= h || b < 0 || b >= w)
                continue;
            int v = a * w + b, c = g[a][b] - '0';
            if (d[v] > z + c) {
                d[v] = z + c;
                if (c)
                    q.push_back({v, d[v]});
                else
                    q.push_front({v, d[v]});
            }
        }
    }
    cout << d.back() << '\n';
}
```
