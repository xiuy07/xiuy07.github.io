# p78 网格中的单词路径：题解

## 从朴素解到目标解

从每个起点回溯，状态含位置、已匹配长度和当前路径访问集。字母不匹配或访问过立即返回。

## 为什么正确

对合法路径的每一步都枚举四邻居，确保完备；同一路径标记保证不重用，回退恢复让不同路径互不干扰。

## 复杂度

O(HW·4^L) 上界时间、O(HW+L) 空间。

## 易错点与手动复盘

不能只维护全局 visited 一次不恢复；单词比格子数长时可以直接拒绝。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int h, w;
vector<string> g;
string s;
bool used[6][6];
int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
bool dfs(int x, int y, int i) {
    if (x < 0 || x >= h || y < 0 || y >= w || used[x][y] || g[x][y] != s[i])
        return false;
    if (i + 1 == (int)s.size())
        return true;
    used[x][y] = true;
    bool ok = false;
    for (int k = 0; k < 4; ++k)
        if (dfs(x + dx[k], y + dy[k], i + 1)) {
            ok = true;
            break;
        }
    used[x][y] = false;
    return ok;
}
int main() {
    cin >> h >> w;
    g.resize(h);
    for (auto &r : g)
        cin >> r;
    cin >> s;
    bool ok = false;
    if ((int)s.size() <= h * w)
        for (int i = 0; i < h; ++i)
            for (int j = 0; j < w; ++j)
                ok = ok || dfs(i, j, 0);
    cout << (ok ? "YES" : "NO") << '\n';
}
```
