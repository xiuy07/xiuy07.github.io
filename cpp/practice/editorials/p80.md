# p80 编辑距离：题解

## 从朴素解到目标解

设 dp[i][j] 是两个前缀的编辑距离，最后一步分插入、删除、替换或匹配。保存上一行和当前行即可压缩空间。

## 为什么正确

任一最优编辑序列按最后一步划分，转到更短前缀；反过来每个候选前缀最优解都能补一次合法操作。取最小值即最优。

## 复杂度

O(nm) 时间、O(m) 空间。

## 易错点与手动复盘

用 getline 读取空字符串；dp[i][0]=i、dp[0][j]=j；替换代价相同字符为 0。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    string a, b;
    getline(cin, a);
    getline(cin, b);
    int m = b.size();
    vector<int> prev(m + 1), cur(m + 1);
    iota(prev.begin(), prev.end(), 0);
    for (int i = 1; i <= (int)a.size(); ++i) {
        cur[0] = i;
        for (int j = 1; j <= m; ++j)
            cur[j] = min(
                {prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + (a[i - 1] != b[j - 1])});
        swap(cur, prev);
    }
    cout << prev[m] << '\n';
}
```
