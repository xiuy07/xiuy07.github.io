# p75 数据流的下中位数：题解

## 从朴素解到目标解

用最大堆存较小一半，最小堆存较大一半。保持左堆数量等于右堆或多 1，且左侧任意值不大于右侧。

## 为什么正确

插入时按左堆顶分流，再把多余堆顶移动到另一边，两个不变式都保持。左堆顶因此正是下中位数。

## 复杂度

O(n log n) 时间、O(n) 空间。

## 易错点与手动复盘

偶数长度不是平均值；每次插入后都要重新平衡；重复值是独立元素。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    priority_queue<ll> lo;
    priority_queue<ll, vector<ll>, greater<ll>> hi;
    while (n--) {
        ll x;
        cin >> x;
        if (lo.empty() || x <= lo.top())
            lo.push(x);
        else
            hi.push(x);
        if (lo.size() > hi.size() + 1) {
            hi.push(lo.top());
            lo.pop();
        }
        if (lo.size() < hi.size()) {
            lo.push(hi.top());
            hi.pop();
        }
        cout << lo.top() << '\n';
    }
}
```
