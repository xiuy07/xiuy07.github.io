# p89 二叉树最大路径和：题解

## 从朴素解到目标解

按后序处理：向父亲返回的贡献只能选一条向下分支；在当前结点更新全局答案时可以同时连接左右正贡献。用遍历序的逆序替代递归。

## 为什么正确

任何非空路径都有深度最小的拐点，分成左分支、拐点、右分支。枚举每个拐点覆盖所有路径；向父返回单分支保证不分叉。

## 复杂度

O(n) 时间、O(n) 空间。

## 易错点与手动复盘

全部为负时答案是最大单个权值而非 0；返回值不能同时携带两条分支；总和用 long long。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<ll> a(n + 1), down(n + 1);
    vector<int> l(n + 1), r(n + 1);
    for (int i = 1; i <= n; ++i)
        cin >> a[i] >> l[i] >> r[i];
    vector<int> order{1};
    for (size_t i = 0; i < order.size(); ++i) {
        int u = order[i];
        if (l[u])
            order.push_back(l[u]);
        if (r[u])
            order.push_back(r[u]);
    }
    ll ans = LLONG_MIN;
    for (auto it = order.rbegin(); it != order.rend(); ++it) {
        int u = *it;
        ll x = max(0LL, down[l[u]]), y = max(0LL, down[r[u]]);
        ans = max(ans, a[u] + x + y);
        down[u] = a[u] + max(x, y);
    }
    cout << ans << '\n';
}
```
