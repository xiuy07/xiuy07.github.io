# p92 有向图强连通分量数量：题解

## 从朴素解到目标解

使用 Kosaraju：第一遍在原图记录真正的 DFS 退出顺序，第二遍按逆退出序在反图中遍历，每次新起点形成一个分量。用显式栈保存下一条待处理边。

## 为什么正确

把强连通分量缩成 DAG 后，第一遍的最大退出顺序落在尚未处理缩点图的源分量；反图遍历不能跨向其他尚未处理分量，因此恰好收集一个 SCC。

## 复杂度

O(n+m) 时间、O(n+m) 空间。

## 易错点与手动复盘

普通入栈顺序不等于退出顺序；第二遍必须反图；无向连通性不能替代相互可达。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <cstddef>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1), r(n + 1);
    while (m--) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        r[v].push_back(u);
    }
    vector<char> seen(n + 1);
    vector<int> order;
    for (int s = 1; s <= n; ++s)
        if (!seen[s]) {
            vector<pair<int, size_t>> st{{s, 0}};
            seen[s] = 1;
            while (!st.empty()) {
                int u = st.back().first;
                auto &i = st.back().second;
                if (i < g[u].size()) {
                    int v = g[u][i++];
                    if (!seen[v]) {
                        seen[v] = 1;
                        st.push_back({v, 0});
                    }
                } else {
                    order.push_back(u);
                    st.pop_back();
                }
            }
        }
    fill(seen.begin(), seen.end(), 0);
    int ans = 0;
    for (auto it = order.rbegin(); it != order.rend(); ++it)
        if (!seen[*it]) {
            ++ans;
            vector<int> st{*it};
            seen[*it] = 1;
            while (!st.empty()) {
                int u = st.back();
                st.pop_back();
                for (int v : r[u])
                    if (!seen[v]) {
                        seen[v] = 1;
                        st.push_back(v);
                    }
            }
        }
    cout << ans << '\n';
}
```
