# p72 等长切割的最大长度：题解

## 从朴素解到目标解

判断长度 x 是否可行，累计 floor(a[i]/x)。长度越大，段数不增；二分找最后一个可行长度。

## 为什么正确

每根材料最多提供 floor(a[i]/x) 段，且能实际切出。因此计数充要；单调性允许用偏右中点，避免区间停滞。

## 复杂度

O(n log(max(a)+1)) 时间、O(n) 空间。

## 易错点与手动复盘

不要对 0 求除法；段数使用 long long；中点取偏右防止死循环。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    ll k;
    cin >> n >> k;
    vector<ll> a(n);
    ll l = 0, r = 0;
    for (auto &x : a) {
        cin >> x;
        r = max(r, x);
    }
    auto ok = [&](ll x) {
        ll c = 0;
        for (ll y : a) {
            c += y / x;
            if (c >= k)
                return true;
        }
        return false;
    };
    while (l < r) {
        ll m = l + (r - l + 1) / 2;
        if (ok(m))
            l = m;
        else
            r = m - 1;
    }
    cout << l << '\n';
}
```
