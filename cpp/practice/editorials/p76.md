# p76 折半搜索：子集目标和：题解

## 从朴素解到目标解

直接枚举 2^n 太大。把数组分两半，各自枚举子集和；排序一半，对另一半的 s 二分统计 K-s 出现次数。

## 为什么正确

任一完整子集唯一分解为左子集与右子集，配对计数一一对应。相同子集和值仍保留多次，避免丢掉不同下标方案。

## 复杂度

O(n·2^(n/2)) 时间、O(2^(n/2)) 空间。

## 易错点与手动复盘

空集必须包含；不能把和集合去重；36 个零有 2^36 种方案。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
vector<ll> sums(const vector<ll> &a, int l, int r) {
    vector<ll> v{0};
    for (int i = l; i < r; ++i) {
        int z = v.size();
        for (int j = 0; j < z; ++j)
            v.push_back(v[j] + a[i]);
    }
    return v;
}
int main() {
    int n;
    ll k;
    cin >> n >> k;
    vector<ll> a(n);
    for (auto &x : a)
        cin >> x;
    auto l = sums(a, 0, n / 2), r = sums(a, n / 2, n);
    sort(r.begin(), r.end());
    ll ans = 0;
    for (ll s : l) {
        auto it = equal_range(r.begin(), r.end(), k - s);
        ans += it.second - it.first;
    }
    cout << ans << '\n';
}
```
