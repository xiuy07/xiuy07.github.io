# p73 滑动窗口最大值：题解

## 从朴素解到目标解

双端队列存下标，值从队首到队尾递减。队首移除过期位置，队尾移除不优于新值的位置。

## 为什么正确

更晚且不小的元素会比旧元素更晚过期，所以旧元素不再可能成为唯一最优。每个下标只进出队一次。

## 复杂度

O(n) 时间、O(K) 空间。

## 易错点与手动复盘

队列存下标才能判断过期；过期条件为下标≤i-K；重复值需要一致处理。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <deque>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<ll> a(n);
    deque<int> q;
    bool first = true;
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        while (!q.empty() && a[q.back()] <= a[i])
            q.pop_back();
        q.push_back(i);
        if (i >= k - 1) {
            if (!first)
                cout << ' ';
            first = false;
            cout << a[q.front()];
        }
    }
    cout << '\n';
}
```
