# p95 快速幂与大指数：题解

## 从朴素解到目标解

按指数二进制位处理：当前位为 1 就乘入结果，每轮底数平方、指数右移一位。所有乘法立刻取模。

## 为什么正确

循环保持 result·base^remaining 与原始幂同余；处理最低位并平方后不变式保持，剩余指数为 0 时 result 即答案。

## 复杂度

O(q log(b+1)) 时间、O(1) 额外空间。

## 易错点与手动复盘

指数用 long long；初始结果为 1；模数约 10^9 时两个模内数乘积仍在有符号 64 位范围内。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    const ll M = 1000000007;
    while (q--) {
        ll a, b, r = 1;
        cin >> a >> b;
        a %= M;
        while (b) {
            if (b & 1)
                r = r * a % M;
            a = a * a % M;
            b >>= 1;
        }
        cout << r << '\n';
    }
}
```
