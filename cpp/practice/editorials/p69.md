# p69 二维区域标记计数：题解

## 从朴素解到目标解

构造带零行零列的二维前缀和。矩形查询用右下前缀，减去上方和左方，再补回左上重叠部分。

## 为什么正确

每个目标格子被保留一次；区域外的上下/左右条带抵消，左上重叠被减两次因此加回。

## 复杂度

O(HW+Q) 时间、O(HW) 空间。

## 易错点与手动复盘

输入坐标从 1 开始且闭区间；r1-1 和 c1-1 可为 0，不要访问负下标。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int h, w, q;
    cin >> h >> w >> q;
    vector<vector<int>> s(h + 1, vector<int>(w + 1));
    for (int i = 1; i <= h; ++i) {
        string row;
        cin >> row;
        for (int j = 1; j <= w; ++j)
            s[i][j] = (row[j - 1] == '*') + s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];
    }
    while (q--) {
        int a, b, c, d;
        cin >> a >> b >> c >> d;
        cout << s[c][d] - s[a - 1][d] - s[c][b - 1] + s[a - 1][b - 1] << '\n';
    }
}
```
