# p87 树上最长距离：题解

## 从朴素解到目标解

从任意点 BFS 找最远点 A，再从 A BFS 找最远点 B。两次 BFS 都用队列，避免深链递归栈溢出。

## 为什么正确

在无权树中，从任意起点找到的最远结点可作为某条直径的端点；再求该端点最大距离得到直径。这依赖树的唯一路径性质，不能直接推广到一般图。

## 复杂度

O(n) 时间、O(n) 空间。

## 易错点与手动复盘

单结点答案为 0；距离是边数，不是结点数；20 万链不能依赖默认递归栈。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> g(n + 1);
    for (int i = 1, u, v; i < n; ++i) {
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    auto bfs = [&](int s) {
        vector<int> d(n + 1, -1);
        queue<int> q;
        q.push(s);
        d[s] = 0;
        int best = s;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            if (d[u] > d[best])
                best = u;
            for (int v : g[u])
                if (d[v] < 0) {
                    d[v] = d[u] + 1;
                    q.push(v);
                }
        }
        return pair<int, int>{best, d[best]};
    };
    auto a = bfs(1);
    cout << bfs(a.first).second << '\n';
}
```
