# p93 最多不冲突活动：题解

## 从朴素解到目标解

按结束时刻排序，扫描时选取开始不早于上次结束的活动。不要按开始时间或活动持续时间贪心。

## 为什么正确

任一最优方案第一项可换成全局最早结束项，不会挤占后续空间。对剩余活动重复这个交换论证。

## 复杂度

O(n log n) 时间、O(n) 存储空间。

## 易错点与手动复盘

相邻区间允许端点相等；初始结束不能设为 0，因为活动可以在负时间开始。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    vector<pair<ll, ll>> v;
    while (n--) {
        ll s, e;
        cin >> s >> e;
        v.push_back({e, s});
    }
    sort(v.begin(), v.end());
    ll last = LLONG_MIN;
    int ans = 0;
    for (auto [e, s] : v)
        if (s >= last) {
            ++ans;
            last = e;
        }
    cout << ans << '\n';
}
```
