# p65 和为目标的配对数量：题解

## 从朴素解到目标解

枚举两层循环需要 O(n²)。从左向右扫描，用哈希表记录已经出现的数及次数，先查询 K-x，再把 x 加入表。

## 为什么正确

处理 x 前，表中恰好是左侧元素。因此新增计数恰好对应右端点为当前位置的合法对，每一对只计算一次。

## 复杂度

期望 O(n) 时间、O(n) 空间。

## 易错点与手动复盘

先插入再查询会把自己配给自己；答案必须用 long long。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    ll k, x, ans = 0;
    cin >> n >> k;
    unordered_map<ll, ll> f;
    f.reserve(n * 2 + 1);
    while (n--) {
        cin >> x;
        auto it = f.find(k - x);
        if (it != f.end())
            ans += it->second;
        ++f[x];
    }
    cout << ans << '\n';
}
```
