# p70 批量区间加后的最小值：题解

## 从朴素解到目标解

操作全部结束后才询问，使用差分。每次修改只在 l 加 delta，在 r+1 减 delta，最后求前缀和还原增量。

## 为什么正确

对任一位置，覆盖它的修改在到达 l 时生效，在经过 r 时结束；累计差分恰是所有覆盖增量之和。

## 复杂度

O(n+q) 时间、O(n) 空间。

## 易错点与手动复盘

r=n 时需要 n+1 哨兵；修改量累计可能超过 int；不必使用线段树。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    vector<ll> a(n + 1), d(n + 2);
    for (int i = 1; i <= n; ++i)
        cin >> a[i];
    while (q--) {
        int l, r;
        ll x;
        cin >> l >> r >> x;
        d[l] += x;
        d[r + 1] -= x;
    }
    ll cur = 0, ans = LLONG_MAX;
    for (int i = 1; i <= n; ++i) {
        cur += d[i];
        ans = min(ans, a[i] + cur);
    }
    cout << ans << '\n';
}
```
