# p88 倍增最近公共祖先：题解

## 从朴素解到目标解

预处理 up[k][v] 为向上 2^k 步祖先。先把两点深度拉齐，再从高位往低位同时跳到祖先不同的位置，最后返回父亲。

## 为什么正确

拉齐保留共同祖先；祖先相同的高跳会越过答案，祖先不同的跳仍在 LCA 下方。处理所有位后两点父亲恰好是 LCA。

## 复杂度

O((n+q) log n) 时间、O(n log n) 空间。

## 易错点与手动复盘

先处理相同结点；根父亲设为根；构建深度使用迭代遍历；不要把 2^k 和 k 混淆。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    int L = 1;
    while ((1LL << L) <= n)
        ++L;
    vector<vector<int>> g(n + 1), up(L, vector<int>(n + 1, 1));
    for (int i = 1, u, v; i < n; ++i) {
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> d(n + 1), order{1};
    for (size_t i = 0; i < order.size(); ++i) {
        int u = order[i];
        for (int v : g[u])
            if (v != up[0][u]) {
                up[0][v] = u;
                d[v] = d[u] + 1;
                order.push_back(v);
            }
    }
    for (int k = 1; k < L; ++k)
        for (int v = 1; v <= n; ++v)
            up[k][v] = up[k - 1][up[k - 1][v]];
    while (q--) {
        int u, v;
        cin >> u >> v;
        if (d[u] < d[v])
            swap(u, v);
        int delta = d[u] - d[v];
        for (int k = 0; k < L; ++k)
            if (delta >> k & 1)
                u = up[k][u];
        if (u != v) {
            for (int k = L - 1; k >= 0; --k)
                if (up[k][u] != up[k][v]) {
                    u = up[k][u];
                    v = up[k][v];
                }
            u = up[0][u];
        }
        cout << u << '\n';
    }
}
```
