# p66 最长无重复窗口：题解

## 从朴素解到目标解

对每个字符记录最后出现位置。右端点右移时，把左端点提升到 max(原左端点,上次位置+1)，然后统计长度。

## 为什么正确

窗口原本无重复，新加入字符只可能与上次的同字符冲突。移过该位置即可恢复性质，且左端点不能回退。

## 复杂度

O(n) 时间、O(字符集大小) 空间。

## 易错点与手动复盘

abba 能发现左边界回退错误；数组下标应转 unsigned char。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    string s;
    cin >> s;
    vector<int> last(256, -1);
    int l = 0, ans = 0;
    for (int r = 0; r < (int)s.size(); ++r) {
        unsigned char c = s[r];
        l = max(l, last[c] + 1);
        last[c] = r;
        ans = max(ans, r - l + 1);
    }
    cout << ans << '\n';
}
```
