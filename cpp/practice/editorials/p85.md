# p85 有障碍网格的路径计数：题解

## 从朴素解到目标解

当前格路径数等于上方与左方之和。用一维数组保留上一行，遇到障碍把当前列清零。

## 为什么正确

每条到达当前格的路径最后一步只能来自上方或左方，两类不相交；障碍无合法到达路径。

## 复杂度

O(HW) 时间、O(W) 空间。

## 易错点与手动复盘

dp[j] 仍是上方而 dp[j-1] 已是当前行左方；障碍必须清零；单格可通行时有一条空移动路径。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int h, w;
    cin >> h >> w;
    const ll M = 1000000007;
    vector<ll> d(w + 1);
    d[1] = 1;
    for (int i = 1; i <= h; ++i) {
        string s;
        cin >> s;
        for (int j = 1; j <= w; ++j) {
            if (s[j - 1] == '*')
                d[j] = 0;
            else
                d[j] = (d[j] + d[j - 1]) % M;
        }
    }
    cout << d[w] << '\n';
}
```
