# p81 不取相邻元素的最大和：题解

## 从朴素解到目标解

考虑最后一项：不选它继承前一前缀最优，选它则加上前两个位置之前的最优。仅保留前两个状态。

## 为什么正确

所有可行方案按是否选最后一项互斥划分，两个分支都由更短前缀的最优方案构成，所以转移最优。

## 复杂度

O(n) 时间、O(1) 额外空间。

## 易错点与手动复盘

更新变量时不要先覆盖旧状态；答案可能超过 int；空数组为 0。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    ll prev2 = 0, prev1 = 0;
    while (n--) {
        ll x;
        cin >> x;
        ll cur = max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }
    cout << prev1 << '\n';
}
```
