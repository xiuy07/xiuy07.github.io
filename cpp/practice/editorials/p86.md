# p86 最长公共子序列：题解

## 从朴素解到目标解

状态为两个前缀的 LCS 长度。末字符相等时可在更短前缀答案后追加；不等时至少舍弃一边末字符。

## 为什么正确

公共子序列若使用两个相等末字符，去掉它们得到更短前缀公共子序列；末字符不同不能同时使用，取舍弃任一端的最优。

## 复杂度

O(nm) 时间、O(m) 空间。

## 易错点与手动复盘

子序列不同于子串；使用 getline 支持空行；滚动数组每行第 0 列应为 0。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    string a, b;
    getline(cin, a);
    getline(cin, b);
    int m = b.size();
    vector<int> p(m + 1), c(m + 1);
    for (char x : a) {
        c[0] = 0;
        for (int j = 1; j <= m; ++j)
            c[j] = x == b[j - 1] ? p[j - 1] + 1 : max(p[j], c[j - 1]);
        swap(p, c);
    }
    cout << p[m] << '\n';
}
```
