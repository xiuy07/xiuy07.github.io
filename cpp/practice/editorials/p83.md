# p83 无限硬币的最少枚数：题解

## 从朴素解到目标解

dp[x] 表示凑出金额 x 的最少枚数，dp[0]=0，其余不可达。按金额递增，从 dp[x-coin]+1 转移。

## 为什么正确

任何非空最优方案都有最后一枚硬币；枚举其面值后，前面的金额必须使用最优解，否则可替换得到更优方案。

## 复杂度

O(nX) 时间、O(X) 空间。

## 易错点与手动复盘

不可达不能初始化为 0；不要贪心选最大面值，1、3、4 凑 6 就是反例。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n, x;
    cin >> n >> x;
    vector<int> a(n);
    for (auto &c : a)
        cin >> c;
    const int INF = 1000000000;
    vector<int> d(x + 1, INF);
    d[0] = 0;
    for (int s = 1; s <= x; ++s)
        for (int c : a)
            if (c <= s)
                d[s] = min(d[s], d[s - c] + 1);
    cout << (d[x] == INF ? -1 : d[x]) << '\n';
}
```
