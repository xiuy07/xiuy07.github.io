# p91 无向图二分染色：题解

## 从朴素解到目标解

对每个未染色连通块做 BFS，相邻结点染相反颜色。若发现同色邻接则拒绝。

## 为什么正确

每条边要求颜色异或为 1，BFS 传播所有必要约束；出现冲突说明沿两种路径得出矛盾。没有冲突时最终颜色直接给出合法划分。

## 复杂度

O(n+m) 时间、O(n+m) 空间。

## 易错点与手动复盘

只从 1 号出发会漏掉其他分量；自环必然不可行；重复边不影响结论。

用样例逐步写下每轮状态，再构造一个违反错误写法的最小反例。

## 完整 C++17 实现

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    while (m--) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> c(n + 1, -1);
    bool ok = true;
    for (int s = 1; s <= n; ++s)
        if (c[s] < 0) {
            queue<int> q;
            q.push(s);
            c[s] = 0;
            while (!q.empty()) {
                int u = q.front();
                q.pop();
                for (int v : g[u]) {
                    if (c[v] < 0) {
                        c[v] = c[u] ^ 1;
                        q.push(v);
                    } else if (c[v] == c[u])
                        ok = false;
                }
            }
        }
    cout << (ok ? "YES" : "NO") << '\n';
}
```
