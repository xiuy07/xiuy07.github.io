# 单调队列、Top K 与双堆

## 读题与方法选择

单调队列比普通队列多一个支配淘汰规则：如果新位置更晚且值不小，旧位置在今后所有包含它的窗口里都不再优于新位置。这个条件同时依赖值与生命周期，单纯看到最大值不能直接套用。

Top K 没有滑动过期要求，用容量 K 的堆保留最佳项。堆顶应是保留集合里最差的项，这样新候选到来后可以快速淘汰。相同频率如何排序属于题意的一部分，必须写进比较关系。

## 状态与不变式

双堆中位数的两个不变式：左堆所有值不大于右堆；左堆元素数等于右堆或多 1。前者决定有序分割，后者决定中间秩。本指南 p75 的偶数长度取下中位数，与求两数平均值的接口题约定不同。

## 手推一遍

对 [1,3,-1,-3,5]、K=3 手推下标队列：加入 1 后 [0]；加入 3 淘汰下标 0，得 [1]；加入 -1 得 [1,2]，首窗口最大 3；加入 -3 得 [1,2,3]；加入 5 时先排除过期下标 1，再淘汰 3、2，得 [4]。

每个元素最多入队一次、从两端弹出一次，总 O(n)。单次 while 可能执行很多次，不意味着总计 O(n²)，这就是摊还分析。

## 从实现到证明

以 [p73 滑动窗口最大值](#problem/p73) 为例：

双端队列存下标，值从队首到队尾递减。队首移除过期位置，队尾移除不优于新值的位置。

正确性：更晚且不小的元素会比旧元素更晚过期，所以旧元素不再可能成为唯一最优。每个下标只进出队一次。

复杂度：O(n) 时间、O(K) 空间。

易错点：队列存下标才能判断过期；过期条件为下标≤i-K；重复值需要一致处理。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <deque>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<ll> a(n);
    deque<int> q;
    bool first = true;
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        while (!q.empty() && a[q.back()] <= a[i])
            q.pop_back();
        q.push_back(i);
        if (i >= k - 1) {
            if (!first)
                cout << ' ';
            first = false;
            cout << a[q.front()];
        }
    }
    cout << '\n';
}
```

</details>

## 升学与面试追问

若要支持滑动中位数，两个堆为什么还不够？离开窗口的元素可能在堆内部，需要延迟删除及计数，或使用可删除的有序容器。区分“数据流插入”与“窗口插入删除”两个接口。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
