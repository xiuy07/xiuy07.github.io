# 指针、引用、const 与二维数组

## 指针保存地址，引用建立别名

`int* p = &x` 中，p 是一个独立指针对象，保存 x 的地址；`*p` 表示被指向的 int 对象。`int& r = x` 中，r 是 x 的别名，之后 `r = y` 是给 x 赋值，不是把 r 改绑到 y。

空指针可以表示“没有对象”，解引用前要检查。引用在正常接口约定中必须绑定有效对象，但引用也可能因原对象销毁而悬空。两者都不能自动延长任意对象的生命期。

## 把 const 放到对应对象上

| 声明 | 允许改变什么 |
|---|---|
| `const int* p` | 可以改 p 的指向，不能通过 p 改所指 int |
| `int* const p` | 不能改指向，可以改所指 int |
| `const int* const p` | 两者都不能通过此声明修改 |

`const int*` 并不保证那个 int 在其他路径下绝不会改变；它限制的是通过当前指针的访问。使用 const_cast 去修改本来就声明为 const 的对象会产生未定义行为。

## 数组经常转换成指针，但两者不是同一类型

`int a[3]` 在许多表达式中转成指向首元素的 `int*`。`sizeof(a)` 测量整个数组；函数参数 `int a[]` 实际调整成 `int*`，函数内部无法再用 sizeof 得到原数组长度。长度应作为参数传入，或使用 vector/array。

二维数组 `int a[2][3]` 的每个元素是一整行 `int[3]`。`a` 通常转换成 `int (*)[3]`，因此 `a+1` 跨过一整行；它不能当作 `int**` 使用。表达式 `a[i][j]` 可以理解为 `*(*(a+i)+j)`，逐层保持类型与边界。

C++20 的 span 可表达不拥有数据的连续视图；本指南 C++17 练习用指针+长度或容器引用。不要把某次实验中“跨过子数组边界的平坦指针运算能跑”当成可移植规则。

## 代码实验：让编译器检查二维数组类型

```cpp
#include <iostream>
#include <type_traits>
int main() {
    int a[2][3]={{1,2,3},{4,5,6}};
    static_assert(std::is_same_v<decltype(a+0), int (*)[3]>);
    int (*row)[3]=a;
    std::cout << (*(row+1))[2] << '\n';
    int& alias=a[0][1];
    alias=20;
    const int* p=&a[0][1];
    std::cout << *p << '\n';
}
```

## 自查

- `int* a[3]` 是三个指针组成的数组；`int (*p)[3]` 是指向三个 int 组成的数组的指针。
- 指针运算只应在同一数组对象及其尾后位置范围内进行；尾后指针不能解引用。
- 字符串字面量应由 `const char*` 或 string 接收，不要尝试修改字面量内容。
