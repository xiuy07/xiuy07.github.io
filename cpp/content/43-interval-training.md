# 区间贪心、扫描线与交换论证

## 读题与方法选择

最多不重叠区间适合按结束时间贪心；最高同时在线人数适合按时间扫描端点；为所有会议分配最少房间可以按开始排序配最小堆。它们输入相似，目标却不同，不能按“区间题”统一套一个排序键。

贪心需要可重复的交换论证：取最早结束项替换最优方案第一项，后续仍有足够空间，再归纳。按最短持续时间选活动，可能阻断两个原本可以并排的活动，不能没有证明就当成最优。

## 状态与不变式

扫描线处理的是事件，不是每个实际时刻。时间坐标可高达 10^9，仍只需排序 2n 个端点。半开区间 [l,r) 下，同时间先离开再进入；也可以合并同时间增量后统一更新，避免制造不存在的瞬时重叠。

## 手推一遍

活动 [0,5)、[1,2)、[2,3)、[3,4) 中，按最早开始会只选第一项，而按最早结束可选后三项，共 3 个。

在线区间 [1,2)、[2,3) 的峰值是 1；若同时间先加进入再减离开，会错误看到 2。写下时间 2 前后谁在线，就能确认边界规则。

## 从实现到证明

以 [p93 最多不冲突活动](#problem/p93) 为例：

按结束时刻排序，扫描时选取开始不早于上次结束的活动。不要按开始时间或活动持续时间贪心。

正确性：任一最优方案第一项可换成全局最早结束项，不会挤占后续空间。对剩余活动重复这个交换论证。

复杂度：O(n log n) 时间、O(n) 存储空间。

易错点：相邻区间允许端点相等；初始结束不能设为 0，因为活动可以在负时间开始。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    vector<pair<ll, ll>> v;
    while (n--) {
        ll s, e;
        cin >> s >> e;
        v.push_back({e, s});
    }
    sort(v.begin(), v.end());
    ll last = LLONG_MIN;
    int ans = 0;
    for (auto [e, s] : v)
        if (s >= last) {
            ++ans;
            last = e;
        }
    cout << ans << '\n';
}
```

</details>

## 升学与面试追问

若活动带有不同价值，最多数量的贪心还能求最大价值吗？一般需要按结束时间排序、二分前驱，再做带权区间调度 DP。要分清目标改变后原交换论证在哪里失效。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
