# 背包、可达性与方案计数

## 读题与方法选择

背包问题至少要区分三个维度：每个物品可用几次；求最大价值、最小数量还是方案数；容量“不超过”还是“恰好”。这三个问题决定初始化、遍历顺序和聚合运算，不能只记一段双重循环。

0/1 背包倒序容量，让右侧仍来自上一物品层；完全背包允许重复使用，正序容量才能复用本轮结果。不可达的最小值状态用正无穷；恰好达到的最大值状态一般用负无穷；计数从 dp[0]=1 开始。

## 状态与不变式

“方案数”还要区分顺序。先枚举硬币再枚举金额，通常按硬币集合计组合；先枚举金额再选择最后硬币，通常会区分排列。p83 只求最少数量，两种顺序在适当状态下都可推导；计数题不能随意交换。

## 手推一遍

仅一个重量 2、价值 3 的物品，容量 4。正序先把 dp[2] 更新为 3，再让 dp[4] 读到新值得到 6，物品被重复使用；倒序正确结果为 3。

正负号 [0,0,1]、目标 1，两个零各有正负两种标记，总计 4。把零简单跳过会漏计，0/1 计数在 x=0 时应将每个状态翻倍。

## 从实现到证明

以 [p82 每件最多一次的背包](#problem/p82) 为例：

以容量为状态，一维压缩后每件物品倒序枚举容量。价值用 long long。

正确性：倒序让 dp[c-weight] 仍属于上一物品层，确保当前物品不重复使用；不选与选择覆盖全部方案。

复杂度：O(nC) 时间、O(C) 空间。

易错点：正序会变成完全背包；本题不要求恰好装满，所以初值可以全 0。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n, c;
    cin >> n >> c;
    vector<ll> d(c + 1);
    while (n--) {
        int w;
        ll v;
        cin >> w >> v;
        for (int j = c; j >= w; --j)
            d[j] = max(d[j], d[j - w] + v);
    }
    cout << d[c] << '\n';
}
```

</details>

## 升学与面试追问

n 很小而容量高达 10^12 时 O(nC) 是否可行？可考虑按价值 DP、折半搜索或稀疏状态。还要说明 O(nC) 是伪多项式复杂度，不能仅看到 n=100 就认定运行很快。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
