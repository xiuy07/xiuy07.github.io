# 回溯、剪枝与折半搜索

## 读题与方法选择

回溯不是一段固定的 dfs 模板，而是对决策树的系统遍历。状态必须包含影响后续合法性的全部信息；每一层枚举一个决策，进入下一层前修改状态，返回后恢复。恢复的是当前路径状态，不是已经输出的答案。

剪枝必须说明“这条分支不可能产生合法解”或“再好也不能优于当前答案”。不能只因为现在较差就放弃，除非有可证明的界。N 皇后按行处理隐含了一行一个，列和两种对角线则需要显式标记。

## 状态与不变式

指数算法要先算状态数。n=36 的完整子集枚举约 687 亿，无法接受；分两半各 18 个，约 26 万子集和，可排序配对。折半搜索减少指数而非简单优化常数；它需要左右决策可以独立枚举并通过一个条件合并。

## 手推一遍

N=4 时第一行放第 2 列，依次尝试可得到列序 [2,4,1,3]。撤销第 4 行后不能遗留占用标记，否则后续分支会被错误剪掉。

在 ['AA'] 网格搜索 AAA：只比较字符会重复走回第一个格子得到假答案，路径访问标记才能禁止重复用格。该标记退出分支后必须清除，因为另一个起点可能合法使用该格。

## 从实现到证明

以 [p77 N 皇后方案计数](#problem/p77) 为例：

每行只放一个皇后，用列、主对角线、次对角线标记占用。尝试一列前检查，递归后恢复标记。

正确性：递归深度决定当前行，每层遍历所有合法列，不会漏掉合法棋盘；冲突分支无法完成合法解，立即剪去安全。

复杂度：O(N·N!) 上界时间、O(N) 空间。

易错点：回溯必须恢复三种标记；对角线 r-c 需要偏移；镜像方案仍分开计数。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <iostream>
using namespace std;
using ll = long long;
int n;
ll ans = 0;
bool col[12], d1[25], d2[25];
void dfs(int r) {
    if (r == n) {
        ++ans;
        return;
    }
    for (int c = 0; c < n; ++c) {
        int x = r - c + n, y = r + c;
        if (col[c] || d1[x] || d2[y])
            continue;
        col[c] = d1[x] = d2[y] = true;
        dfs(r + 1);
        col[c] = d1[x] = d2[y] = false;
    }
}
int main() {
    cin >> n;
    dfs(0);
    cout << ans << '\n';
}
```

</details>

## 升学与面试追问

如果只要求是否存在，找到一个解可以提前返回；如果要求所有方案，就必须继续遍历。若输入包含重复值，按下标区分还是按数值去重会改变搜索树；p76 必须保留重复的子集和。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。

## 手动练习与验收

1. 不看代码，给本章样例写出每一轮的关键状态。
2. 用最直观的暴力解先验证 5–10 个小输入，再与目标解交叉检查。
3. 构造最小规模、重复值、极端数值及边界条件；不适用的条件说明原因。
4. 限时独立完成下方练习。做错后记录“错误假设、反例、修复理由”，隔 2 天和 7 天再写。
