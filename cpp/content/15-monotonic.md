# 单调栈与最大空白矩形

## 从二维网格转成每行柱状图

处理第 i 行时，height[j] 记录第 j 列向上连续的可用格子数。可用则加一，障碍则清零。所有柱子都以当前行为共同底边，因此连续一段柱子只要高度都不小于 h，就覆盖同样的最后 h 行。上边是 i-h+1，下边是 i，不会发生边界错位。

例如高度 `[3,2,4]`，三列共同可用的高度为 2，取最下面两行就是 2×3 的矩形。较高柱子的多余部分可以截掉。任意合法矩形都有一条底边，所以枚举每行不会遗漏答案。

## 栈存下标，高度严格递增

栈内下标从左向右增加，对应高度严格递增。遇到当前高度不高于栈顶时，弹出栈顶柱子，暂以其高度 h 作为矩形高度。弹出后，栈顶 left 指向左侧更矮柱子；若栈空，则记 left=-1。

当前下标为 j，此次矩形覆盖 `[left+1,j-1]`，所以宽度是 `j-left-1`。两侧阻挡位置本身不参与面积。遇到等高柱子也弹出，让右边那根等高柱子继续承担以后更宽的矩形，不会漏解。

| 高度 `[2,3,1]`，扫描 j=2 | left | 宽 | 面积 |
|---|---|---|---|
| 弹出下标 1，高 3 | 0 | 2-0-1=1 | 3 |
| 弹出下标 0，高 2 | -1 | 2-(-1)-1=2 | 4 |

## clear 与哨兵分别解决什么

每行更新 height 后，是一张新的柱状图，`st.clear()` 丢弃上一张图的边界计算状态。height 不能清空，否则失去向上累加的信息；全局答案也不能清空。

在末尾补高度为 0 的柱子，保证扫描结束前剩下的正高度都会弹出计算。真实宽度为 W 时，数组分配 W+1，最后循环到 j=W；这个位置只是哨兵，不是真实格子。

## 代码实验：边界从栈中得到

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
int main() {
    std::vector<int> h={2,3,1,0}, st;
    int ans=0;
    for(int j=0;j<static_cast<int>(h.size());++j) {
        while(!st.empty() && h[st.back()]>=h[j]) {
            int value=h[st.back()]; st.pop_back();
            int left=st.empty()?-1:st.back();
            int width=j-left-1;
            std::cout << value << ' ' << left << ' ' << width << '\n';
            ans=std::max(ans,value*width);
        }
        st.push_back(j);
    }
    std::cout << "area " << ans << '\n';
}
```

本机运行：`python practice/judge.py demo d15`。源码位于 `demos/d15.cpp`。

手算每次弹出的 h、left、width，再运行比对。每个下标最多入栈和出栈一次，单行 O(W)，网格总计 O(HW)。嵌套 while 不等于 O(W²)，要数总的弹栈次数。

## 自查

- 为什么栈保存下标而不是只存高度？需要用位置计算宽度。
- 为什么 width 不等于 j-弹出的下标？被弹柱子也可以向左覆盖多根柱子。
- 全障碍网格答案为何为 0？所有高度为 0，面积自然为 0。
