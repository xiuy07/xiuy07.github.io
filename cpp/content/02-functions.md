# 控制流程、函数与程序组织

## 循环先写清楚区间

遍历长度为 `n` 的序列，优先使用 `[0, n)`：`for (int i = 0; i < n; ++i)`。这个区间包含 n 个元素，空序列 n=0 时一次也不执行。写二重循环前先算复杂度；n=10⁵ 时枚举所有二元组通常不可行。

先写一个能说明正确性的循环不变式。例如求前缀和时，在每轮开始前，`sum` 等于已经处理部分的总和。然后检查初始化、每轮更新以及退出时是否得到完整答案。不要只用样例判断循环边界。

## 参数传递是在选择数据关系

`void f(int x)` 得到副本，修改 x 不影响调用者；`void f(int& x)` 操作调用者的对象；`void f(const std::string& s)` 只读借用字符串，避免按值复制。简单整数通常按值传递，大对象只读时通常用 const 引用。

返回值可以直接表达结果；只有需要返回多个独立结果或明确修改输入时，再考虑引用参数。不要返回局部变量的引用或指针：函数结束后，原对象已经销毁，地址即使看起来未变也已失效。

## 重载、默认参数与声明

重载要求参数列表不同；不能只靠返回类型区分。调用时会进行匹配与转换，不确定时写清类型，例如 `3.0`。默认参数由调用处可见的声明决定，不要在声明和定义中重复给出默认值。

头文件放声明与必要的类型定义，`.cpp` 放普通函数实现；头文件使用 include guard 或 `#pragma once` 避免同一翻译单元重复包含。模板通常需要让定义在实例化处可见，后面单独讲。

## 代码实验：同一个交换函数的两种参数

```cpp
#include <iostream>
void swap_value(int a, int b) { int t=a; a=b; b=t; }
void swap_ref(int& a, int& b) { int t=a; a=b; b=t; }
int main() {
    int x=2, y=9;
    swap_value(x,y);
    std::cout << x << ' ' << y << '\n';
    swap_ref(x,y);
    std::cout << x << ' ' << y << '\n';
}
```

```text

9 2
```

</details>

本机运行：`python practice/judge.py demo d02`。源码位于 `demos/d02.cpp`。

`swap_value` 交换的是自己的副本；`swap_ref` 中 a、b 分别成为原变量的别名。调用形式相同不意味着数据关系相同，必须看函数声明。

## 递归先考虑终止与深度

辗转相除算法不断把 `(a,b)` 替换成 `(b,a%b)`，直到 b=0。每步缩小问题，同时保留最大公因数。链表很长时，递归反转可能耗尽调用栈，可以改用循环；本指南链表测试使用迭代版本。
