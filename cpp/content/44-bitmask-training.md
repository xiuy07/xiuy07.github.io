# 位运算、快速幂与状态压缩

## 读题与方法选择

按位运算的优先级容易出错，包含判断写成 (mask & (1<<v)) != 0 更清楚。1 是 int，位数较大时用 1LL<<v；移位不能超过类型有效位数。掩码可表示小规模集合，但不会自动降低所有集合问题的复杂度。

快速幂每轮处理指数一个二进制位，状态压缩则把访问集合当成 DP 的一部分。旅行路线只记当前位置不够，因为不同已访问集合的后续选择不同。

## 状态与不变式

n=16 时 2^n×n 约 105 万个状态，64 位数组约 8 MiB，O(2^n n²) 约千万级转移可考虑。n=30 时就不能照搬；做题前同时估计状态数、每次转移数、字节大小。

最短路可能重复结点，而恰好访问一次要求保留访问集。即使输入是完整费用矩阵，也不能只跑 Dijkstra 然后把距离相加。

## 手推一遍

3 个站点时，从 1 出发只需比较 1→2→3→1 与 1→3→2→1。状态 dp[011][2] 与 dp[101][3] 表示不同终点和不同已访问集，不能合并成单一 best[位置]。

2^13 的指数二进制为 1101：按最低位处理结果依次乘入 2、跳过 4、乘入 16、乘入 256，最终得到 8192。每次乘法后取模，指数最终归零。

## 从实现到证明

以 [p96 状态压缩：访问全部站点](#problem/p96) 为例：

dp[mask][u] 表示已访问集合为 mask、终点为 u 的最小费用。初始只含站点 1，向未访问站点转移，最后补回站点 1 的费用。

正确性：路径按访问集合与终点划分；从最后一次移动移除终点得到更小集合的最优子问题，所有合法前驱都会被枚举。

复杂度：O(2^n·n²) 时间、O(2^n·n) 空间。

易错点：不要只做普通最短路，那会重复站点或漏站；必须补回起点费用；不对称矩阵不能当无向图。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int n;
    cin >> n;
    vector<vector<ll>> a(n, vector<ll>(n));
    for (auto &r : a)
        for (auto &x : r)
            cin >> x;
    if (n == 1) {
        cout << 0 << '\n';
        return 0;
    }
    const ll INF = LLONG_MAX / 4;
    int all = 1 << n;
    vector<ll> d((size_t)all * n, INF);
    d[n] = 0;
    for (int mask = 1; mask < all; mask += 2)
        for (int u = 0; u < n; ++u) {
            ll cur = d[(size_t)mask * n + u];
            if (cur == INF)
                continue;
            for (int v = 1; v < n; ++v)
                if (!(mask >> v & 1)) {
                    auto &to = d[(size_t)(mask | 1 << v) * n + v];
                    to = min(to, cur + a[u][v]);
                }
        }
    ll ans = INF;
    for (int u = 1; u < n; ++u)
        ans = min(ans, d[(size_t)(all - 1) * n + u] + a[u][0]);
    cout << ans << '\n';
}
```

</details>

## 升学与面试追问

若要输出最优路线，需要给每个状态保存前驱并倒序回溯；若只求方案数，把 min 转成加法仍需重新确认状态转移与是否重复计数。状态相同不意味着聚合方式可以随意替换。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
