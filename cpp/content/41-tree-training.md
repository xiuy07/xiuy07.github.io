# 树的综合题：直径、LCA 与路径贡献

## 读题与方法选择

树没有环，两点间路径唯一，所以很多看似全局的问题可拆成子树贡献。处理树题时先确定有根或无根、边权或点权、路径是否必须经过根、答案能否为空。p89 的非空路径在全负输入时尤其重要。

向父亲返回的贡献必须能和父结点连成一条路径，所以只能选一侧。当前结点作为路径最高点时可以同时连接两边，由此分别定义 down[u] 与全局 best。把这两个值混成一个返回值是常见错误。

## 状态与不变式

倍增 LCA 将重复向父跳跃压缩为二进制跳跃。先迭代建立 parent 和 depth，再填 up[k][u]=up[k-1][up[k-1][u]]。根的父亲设为根可使边界一致。数据可能是一条 20 万长链，递归深度必须纳入实现风险。

## 手推一遍

根 -10，左子树 9，右子树 20 的孩子为 15 和 7：结点 20 向上只返回 20+15=35，但局部答案可以取 15+20+7=42。根处取值 -10+9+35=34，所以全局答案仍为 42。

链 1–2–3–4–5 中 LCA(4,5)=4，LCA(3,3)=3。把相同结点作为单独测试，能查出提升深度之后忘记提前判断的错误。

## 从实现到证明

以 [p89 二叉树最大路径和](#problem/p89) 为例：

按后序处理：向父亲返回的贡献只能选一条向下分支；在当前结点更新全局答案时可以同时连接左右正贡献。用遍历序的逆序替代递归。

正确性：任何非空路径都有深度最小的拐点，分成左分支、拐点、右分支。枚举每个拐点覆盖所有路径；向父返回单分支保证不分叉。

复杂度：O(n) 时间、O(n) 空间。

易错点：全部为负时答案是最大单个权值而非 0；返回值不能同时携带两条分支；总和用 long long。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<ll> a(n + 1), down(n + 1);
    vector<int> l(n + 1), r(n + 1);
    for (int i = 1; i <= n; ++i)
        cin >> a[i] >> l[i] >> r[i];
    vector<int> order{1};
    for (size_t i = 0; i < order.size(); ++i) {
        int u = order[i];
        if (l[u])
            order.push_back(l[u]);
        if (r[u])
            order.push_back(r[u]);
    }
    ll ans = LLONG_MIN;
    for (auto it = order.rbegin(); it != order.rend(); ++it) {
        int u = *it;
        ll x = max(0LL, down[l[u]]), y = max(0LL, down[r[u]]);
        ans = max(ans, a[u] + x + y);
        down[u] = a[u] + max(x, y);
    }
    cout << ans << '\n';
}
```

</details>

## 升学与面试追问

有负权边时“两次最远点搜索”是否仍可直接求最长非空路径？本章 p87 明确是无权树，不把结论推广到任意负权情况。若改成支持在线修改与路径和，需要树链剖分等进一步结构。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
