# 二分答案与可行性证明

## 读题与方法选择

二分答案适合“最小化最大值”或“最大化最小值”等优化题，但关键词只是线索。必须能对一个候选答案快速回答可不可行，并证明答案轴上的真假分布只有一次转折。

装运容量越大，能完成的方案只会更多，判定形如 假假假真真真，求第一个真。切割长度越大，能切出的数量只会更少，形如 真真真假假假，求最后一个真。

## 状态与不变式

第一真写法：闭区间 [l,r]，若 check(mid) 为真，令 r=mid，否则 l=mid+1。最后真写法：mid=l+(r-l+1)/2，若为真令 l=mid，否则 r=mid-1。要说明上下界一定覆盖答案，以及每一步如何严格缩小区间。

## 手推一遍

货物 [3,2,2,4,1,4]，至多 3 天。容量 5 分为 [3,2]、[2]、[4,1]、[4]，要 4 天不可行；容量 6 分为 [3,2]、[2,4]、[1,4]，要 3 天可行。最终答案为 6。

切割用 [9,7,5]、K=5：长度 3 能取 3+2+1=6 段，长度 4 只能取 2+1+1=4 段，所以最大长度 3。不能将剩余材料拼接。

## 从实现到证明

以 [p71 顺序装运的最小容量](#problem/p71) 为例：

容量固定时，每天尽量多装可最小化天数。容量越大越容易可行；在最大单件重量与总重量之间找第一个可行容量。

正确性：固定容量的贪心每天结束位置不会比任何可行装法更早。可行性对容量单调，所以二分保留第一个可行答案。

复杂度：O(n log(sum(a))) 时间、O(n) 空间。

易错点：不能重排货物；D 可以大于 n；二分上界与当前载荷用 long long。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, d;
    cin >> n >> d;
    vector<ll> a(n);
    ll l = 0, r = 0;
    for (auto &x : a) {
        cin >> x;
        l = max(l, x);
        r += x;
    }
    auto ok = [&](ll c) {
        int days = 1;
        ll s = 0;
        for (ll x : a) {
            if (s + x > c) {
                ++days;
                s = 0;
            }
            s += x;
        }
        return days <= d;
    };
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (ok(m))
            r = m;
        else
            l = m + 1;
    }
    cout << l << '\n';
}
```

</details>

## 升学与面试追问

若货物可以自由重排，当前贪心 check 还是正确的吗？这是另一个装箱问题，不能沿用顺序装运的证明。请给出导致装运总重溢出 int 的输入，并解释为何判定中的天数可以提前超过 D 时立即返回。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
