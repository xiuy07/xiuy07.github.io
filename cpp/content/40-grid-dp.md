# 二维 DP：网格与公共子序列

## 读题与方法选择

网格路径和两个字符串前缀都能画成二维表。网格状态表示抵达位置的方案数；LCS 状态表示两个前缀的最长公共子序列长度。横轴纵轴名字必须清楚，不能凭图像相似混用转移。

有障碍网格在读到障碍时把该状态置零，否则旧的上方路径数会穿过障碍。LCS 若末字符不同，应取删去任意一边末字符的最大值，而不是把状态清零；清零是另一道“最长公共子串”问题的结构。

## 状态与不变式

一维网格 DP 中，dp[j] 更新前代表上方，dp[j-1] 代表当前行左方，因此从左到右枚举。LCS 两行滚动则更直观，若需要输出一个公共子序列，保存二维表从右下角回溯最容易解释。

## 手推一遍

3×3 网格中心有障碍：第一行状态 [1,1,1]，第二行 [1,0,1]，第三行 [1,1,2]，最终有 2 条路径。起点有障碍时第一步就把初始 dp[1]=1 清零。

字符串 abcde 与 ace 的公共子序列是 ace，长度 3；它不是连续片段。用这一组输入检查你的状态究竟求子序列还是子串。

## 从实现到证明

以 [p85 有障碍网格的路径计数](#problem/p85) 为例：

当前格路径数等于上方与左方之和。用一维数组保留上一行，遇到障碍把当前列清零。

正确性：每条到达当前格的路径最后一步只能来自上方或左方，两类不相交；障碍无合法到达路径。

复杂度：O(HW) 时间、O(W) 空间。

易错点：dp[j] 仍是上方而 dp[j-1] 已是当前行左方；障碍必须清零；单格可通行时有一条空移动路径。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    int h, w;
    cin >> h >> w;
    const ll M = 1000000007;
    vector<ll> d(w + 1);
    d[1] = 1;
    for (int i = 1; i <= h; ++i) {
        string s;
        cin >> s;
        for (int j = 1; j <= w; ++j) {
            if (s[j - 1] == '*')
                d[j] = 0;
            else
                d[j] = (d[j] + d[j - 1]) % M;
        }
    }
    cout << d[w] << '\n';
}
```

</details>

## 升学与面试追问

为什么网格允许四方向任意移动后不能直接按行 DP？依赖不再是 DAG，还可能产生重复绕行。最短移动通常应考虑 BFS 或最短路，不能只把左、上改成四个方向相加。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
