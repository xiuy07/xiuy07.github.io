# 前缀和、差分与离线处理

## 读题与方法选择

前缀和适合原数组不变、反复询问区间聚合。采用 P[0]=0，P[i] 表示前 i 个数之和，闭区间 [l,r] 的和就是 P[r]-P[l-1]。不要同时混用 0 下标半开区间公式与题面的 1 下标闭区间。

差分是前缀和的逆操作。区间加 x 只改变两个边界：D[l]+=x、D[r+1]-=x。全部修改结束后还原数组，需要 O(n+q)，比为每次修改遍历区间快。

## 状态与不变式

“离线”指知道全部操作后可以统一处理，并不表示不能读取多行输入。若每次修改后立刻要查区间和，简单差分无法快速回答，应回看第 32 章的树状数组或线段树。选择结构前先确认操作顺序与查询时机。

## 手推一遍

数组 [1,-1,1]，K=1。初始前缀频率 {0:1}：读 1 查询 0，新增 1；读 -1 查询 -1，新增 0；读 1 再查询 0，新增 2，答案为 3。负数使“和大就缩窗口”的推理失效。

二维前缀矩形需要容斥：总前缀减上方、减左方，再加左上角。画一个 3×4 网格，用四种颜色标出四个前缀，可以看到目标区域每格最后系数为 1。

## 从实现到证明

以 [p68 目标和连续子数组](#problem/p68) 为例：

设前缀和为 s，查找此前有多少前缀和等于 s-K。初始把空前缀 0 记为出现一次。

正确性：子数组和是两个前缀和之差；每个右端点只配对更早的前缀位置，既不漏计从开头开始的子数组，也不计空子数组。

复杂度：期望 O(n) 时间、O(n) 空间。

易错点：负数使普通同向窗口失效；先查询后更新；前缀和及计数均用 long long。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    ll k, s = 0, ans = 0, x;
    cin >> n >> k;
    unordered_map<ll, ll> f;
    f.reserve(n * 2 + 1);
    f[0] = 1;
    while (n--) {
        cin >> x;
        s += x;
        auto it = f.find(s - k);
        if (it != f.end())
            ans += it->second;
        ++f[s];
    }
    cout << ans << '\n';
}
```

</details>

## 升学与面试追问

如果改成区间乘法或区间最大值，前缀减法是否仍可用？区间和有可逆性，最大值没有同样的相减操作。再解释：为什么只求最终数组时差分足够，而在线区间查询需要新的结构。

回答时按“前置条件 → 状态含义 → 转移或维护规则 → 为什么不漏不重 → 时间空间 → 边界反例”展开，不需要背诵固定话术。面试中也要解释标准库容器的代价，而不是只说调用了某个函数。
