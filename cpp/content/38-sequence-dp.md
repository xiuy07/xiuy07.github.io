# 线性与序列 DP：状态、转移和优化

## 读题与方法选择

写 DP 前先用一句话定义每个状态。打家劫舍类问题可用“前 i 项中不选相邻项的最大和”；LIS 朴素状态是“以 i 结尾的严格递增子序列最大长度”；编辑距离则必须同时描述两个字符串前缀。

状态相似不代表含义相同。LIS 的 tails[k] 是固定长度的最小尾值，并不是某个位置结尾的最优长度，更不是输出的一条真实 LIS。只有理解支配关系后才适合做 O(n log n) 优化。

## 状态与不变式

滚动数组必须按依赖图安排更新顺序。编辑距离当前行 j 依赖上一行 j、上一行 j-1、当前行 j-1，保留两行最清楚；硬压一行还要保存左上角旧值。为了少一行空间而丢失语义，往往得不偿失。

## 手推一遍

序列 [3,1,2,2,4] 的 tails 依次为 [3]、[1]、[1,2]、[1,2]、[1,2,4]，长度 3。重复的 2 不增长，因为这里要求严格递增。

非相邻最大和 [2,7,9,3,1]：前缀最优为 0、2、7、11、11、12。每次把“选当前项”与“不选当前项”的两种方案并列，便于检查转移是否漏掉。

## 从实现到证明

以 [p79 最长严格递增子序列](#problem/p79) 为例：

先写 O(n²) 的结尾 DP。优化为 tails[len-1] 记录长度为 len 的子序列能有的最小尾值，用 lower_bound 替换第一个不小于 x 的位置。

正确性：同长度下更小尾值保留更多扩展可能；替换不改变已存在的最大长度。只有 x 大于所有尾值时才能扩展长度。

复杂度：O(n log n) 时间、O(n) 空间。

易错点：严格递增用 lower_bound；upper_bound 会把相等值当作可扩展；tails 本身不保证是原序列的一条子序列。

<details><summary>完整 C++17 参考实现</summary>

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<ll> t;
    while (n--) {
        ll x;
        cin >> x;
        auto it = lower_bound(t.begin(), t.end(), x);
        if (it == t.end())
            t.push_back(x);
        else
            *it = x;
    }
    cout << t.size() << '\n';
}
```

</details>

## 升学与面试追问
