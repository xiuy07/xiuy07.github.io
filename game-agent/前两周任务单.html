第一周核心练习：教学轨迹统计器

下面是自建教学记录，不是 MiniGrid 实验、真实模型输出或科研性能数据。成功字段与结束原因由记录显式提供，不从奖励正负猜测成功。

json
[
  {"episode_id": "demo-a", "seed": 1, "success": true, "steps": 8, "end_reason": "goal"},
  {"episode_id": "demo-b", "seed": 2, "success": false, "steps": 20, "end_reason": "time_limit"},
  {"episode_id": "demo-c", "seed": 3, "success": true, "steps": 12, "end_reason": "goal"}
]

要求：读取 JSON；统计记录数、成功率、全部记录平均步数、成功记录平均步数、各结束原因计数；保存摘要 JSON。将文件读取、记录验证、统计、保存分成短函数，不用复杂类继承。

先手算再运行，期望：3 条，成功率 2/3，全部平均步数 40/3，成功平均步数 10；goal 为 2、time_limit 为 1。输出小数时注明显示精度，不将 66.7% 当精确值。

再独立处理：空输入；全部失败；steps 缺失；steps 为负数；success 是字符串而非布尔值。你需要先写下规则：哪些输入应拒绝并报告错误，哪些指标应输出 null。建议空样本的比率/均值和无成功时的成功均值为 null，计数仍为 0；非法数据明确报错，不悄悄丢弃。布尔值不能当作合法步数。

达标：不依赖 AI 生成整份脚本，能独立完成核心函数并解释每个统计量分母；改变一条记录后，先预测结果再核对。卡住可以先要提示，最后看完整解答再独立重做。

第二周核心练习：批量线性预测

text
X = [[1, 2], [3, 4], [-1, 1]]    # N=3, d=2
w = [2, -1]                      # d=2
b = 0.5                          # 标量
y_hat = X @ w + b

先画出 (3,2) @ (2,) → (3,) 的形状，再算期望输出 [0.5, 2.5, -2.5]。禁止用“广播后没报错”判断实现正确。

比较：w 改为 (2,1) 时，预测变成 (3,1)；如果 y 是 (3,)，直接相减会广播成 (3,3)，即使损失能算出数值也可能错。先用纸写出这一现象，再运行验证，最后在约定的位置统一形状。

扩展练习：按列计算均值；比较总体方差与样本方差的分母；解释训练集统计量与验证集统计量的区别。标准化参数应来自训练数据，下一阶段会具体练习划分与泄漏。
