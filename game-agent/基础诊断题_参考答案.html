基础诊断题：参考答案与判分要点

日期：2026-10-25。先完成 题目 再查看。答案为学习要点；能独立换例子解释，才记 2 分。下列数值为手算参考，不是模型实验结果。

A. Python

  1. 三个列表最终显示均为 [[9],[1]]。b 与 a 是同一个外层列表；c 是新的外层列表，但其中嵌套列表仍共享。修改 c 的外层元素与修改 c[0][0] 不是同一种操作。
  2. 第一次调用返回 [1]，第二次返回 [1,2]，两次返回的是同一列表；若保存第一次返回的引用，第二次后再查看也会看到 [1,2]。默认参数在函数定义时创建。通常用 buf=None，在函数内为 None 时新建列表。
  3. 成功率 2/3，全部均值 40/3，成功均值 10。空样本的比率与均值没有定义，可输出 null；无成功时成功均值为 null。不能默默将无定义指标填成 0。
  4. 相对路径通常基于当前工作目录，不自动基于脚本所在目录。文件不存在是文件系统错误，坏 JSON 是解析错误；定位时先查 cwd、路径和 traceback，再决定怎样向用户报告。

B. 数学

  1. 第一种预测为 (5,)；第二种预测为 (5,1)，减 (5,) 会广播为 (5,5)，不是期望的逐样本误差。应先约定预测和标签均用 (N,) 或均用 (N,1)。
  2. 预测为 [0.5,2.5]。NumPy 数组的 * 是逐元素乘法，@ 是矩阵/向量乘法；维度不同会有各自的兼容规则，不能互换。
  3. 预测 2，误差 -1，L=0.5；dL/dw=-2，dL/db=-1。用旧参数处的两个梯度同步更新，w=1.2、b=0.1；新预测 2.5，新损失 0.125。
  4. 用 [L(3+h)-L(3-h)]/(2h)，解析值为 6。h 太大可能有截断误差，太小可能出现浮点抵消/舍入问题；二次函数在精确算术下中心差分恰好给出导数，但计算机仍有浮点误差。

C. 概率与 ML

  1. 联合概率 10/100=0.1，条件概率 10/40=0.25，分母对应不同事件空间。不能从这些数据计算没有给出的无门任务失败率。
  2. 均值 0.5，总体方差 0.25；若求无偏样本方差则为 1/3，要注明分母。样本很少、任务可能相关，种子和任务覆盖也有限；需报告样本量、原始记录与不确定性，不能只挑成功案例。
  3. 测试分布的信息进入了预处理，造成泄漏。先划分，预处理只在训练数据拟合；验证数据用于调参，测试数据用于冻结方案后的最终报告。交叉验证的每折也应仅在该折训练部分拟合。
  4. 总预测负类准确率 95%，但正类召回率为 0。补混淆矩阵、各类召回率、精确率及适合目标的指标；无正类预测时精确率须说明分母为零时的约定。若使用概率分数，还应评估排序、阈值和实际错误代价。

D. PyTorch

  1. backward 计算并通常累积梯度，step 根据优化器规则更新参数，前者本身不会完成优化更新。训练循环通常每个待更新批次清零，否则可能无意积累；主动做梯度累积是另一种明确设计。
  2. eval 切换受训练/评估模式影响的层，例如 Dropout、BatchNorm；no_grad 禁用该作用域内的梯度记录。两者互不替代；仅 eval 不会自动关闭 autograd。
  3. 可能过拟合，也可能是分布差异、验证预处理或标签错误、忘了 eval 等。先审查数据划分与评估流程，再尝试控制容量、正则化或早停；不能用测试集选择方案。
  4. 简单逐元素残差加法应让两路形状一致。可以给捷径分支加可学习投影从 8 到 16，或修改 f 保持 8。不要依赖意外广播掩盖设计问题。

E. 决策

  1. 0+0.5×1+0.5²×2=1。即时奖励只是一时刻的反馈，回报聚合后续奖励。说明自己从哪个时刻计数。
  2. 目标 1+0.9×4=4.6；更新为 2+0.1×(4.6-2)=2.26。真正终止时目标为 1，更新为 1.9，不再从终止状态自举。
  3. 完整状态可能含未见房间、钥匙位置或隐藏变量；局部观察只显示传感器/接口允许的信息。例如先看到路标、之后进入相同走廊，要用过去路标选择方向。记忆必须来自合法历史，不能直接读取隐藏状态。
  4. 真正终止来自任务 MDP 的终止条件，外部截断可能只是采样时间限制，通常仍要用最终后继观察自举。有限时域任务内在的截止可能是真正终止，此时应正确表示剩余时间。自动 reset 时还要避免误用下一回合初始观察作为后继。规划利用已知/学得的转移模型推演，学习从数据更新策略/价值等；两者可以组合。

关于结束和自举，参见 Gymnasium 官方说明。

F. Attention 与 Agent

  1. QKᵀ 得到 (B,T,T)，乘 V 后为 (B,T,d_v)；softmax 对每个 query 沿 key 位置轴归一化。注意转置最后两个轴，而不是把 batch 也转置；标准缩放为除以 sqrt(d_k)。
  2. 输入 [a,b,c]、标签 [b,c,d]。并行训练时因果 mask 阻断未来 key，否则模型可利用目标信息作弊；自回归生成时实际输入只含已有前缀。不能把 mask 和标签移位混为一件事。
  3. Agent 的执行层/工具接口执行程序，环境返回新的合法观察或错误，独立评测按任务条件判断成功。Memory 存历史，Skill 封装可复用能力，Harness 管理执行、工具、上下文、约束与记录，具体边界取决于系统设计。代码生成与环境执行都应可追溯。
  4. 不可以直接归因于技能机制。统一观察、模型与调用/步数预算，用同一批任务做配对比较；需要时分别消融完整地图、技能和额外调用。不同抽象接口也要展开计入底层环境步数，学习/发现技能的开销单独报告。
