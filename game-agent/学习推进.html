Game Agent 讲义

从第1课开始

先把第一课学到能独立解释和实现，再进入第二课。以每周8–10小时为主线，不要求一次看完全部讲义或同时学习多套教程。

第一次学习：90分钟

用时 做什么 留下什么
20分钟 独立尝试诊断题1—4，不查答案；每题标会、不确定或不会 原始作答和一个最不清楚的问题
25分钟 读第1课1.2—1.4，追踪名称绑定、浅拷贝和默认参数 自己画的一张对象关系图
15分钟 闭卷做第1课A1、B1，标清每项统计的分母 解释与手算过程
25分钟 初始化第1课空白代码，尝试实现B2；未完成也保留当前版本 work/task_01.py及第一次检查输出
5分钟 写下错因、提示使用情况和下次首先要解决的问题 一条学习记录

讲义：第1课。诊断题与反馈分别见基础诊断题、学习记录模板。第一次只做诊断1—4，5—12题可在本周余下时间分次尝试。

第一周的其余四次学习

次数 时间 主要任务 完成依据
第2次 2小时 补读1.5—1.7，继续B2，处理空输入和合法失败 说得清None与0的区别
第3次 2小时 JSON、路径、异常；围绕教学记录增加文件读写 有输入文件、运行命令与实际输出
第4次 2小时 修正边界，自己制造一个类型错误，完成C1中的反例 解释为何报错，如何定位与修正
第5次 1.5小时 关闭旧代码重写核心函数，换数据复测，整理反馈 独立实现、分母解释与复测证据

连同第一次共9小时，具体哪天安排由课程情况决定。扩展项目的结束原因计数与B2核心函数分开，避免为了做扩展而改变B2约定的返回字典。

开始写作业

打开编程练习说明，或直接下载前四课练习包。先只运行第1课：

powershell
python start.py 01

编辑work/task_01.py，再运行：

powershell
python check.py 01

先独立写，再用检查输出定位问题。卡住时回到本题提示；看过参考解答后，隔一段时间关闭答案重写。第1题只使用标准库，当前不需要安装PyTorch、MiniGrid或调用模型API。

第一课学完后交什么

交回三样即可：work/task_01.py、实际检查输出，以及一份简短反馈。反馈中附A1/B1自己的解答，写明哪里用了提示、哪里仍不懂，不必整理成长报告。

测试全过只是功能检查。还应能解释每项指标的分母，说明合法失败为什么保留、非法记录为什么拒绝，并在换一条记录后先预测再核对输出。尚不能做到就继续补练，不按日历自动进入下一课。

你交回作业后，后续反馈将先检查概念和边界，再给最少量提示；需要时补一题，最后再决定是否进入第2课。没有交回的学习结果保持待完成，不用示例自检代替你的学习记录。
