Game Agent 讲义

基础诊断题

2026-10-25；用途是决定学习起点与复测，不是入组考试。先独立作答，再读 参考答案。首次只集中做 1–12 题；不会 RL、PyTorch 或注意力属于正常待学内容。

每题记 0／1／2：0 为不会；1 为提示后可解释；2 为独立回答并能举例或改条件。每组 8 分分别记录，不能靠总分跳过明显薄弱项。分数只辅助判断，编程和解释证据优先。

A. Python（第 1–2 周）

  1. a=[[0],[1]]; b=a; c=a.copy(); c[0][0]=9 后 a、b、c 分别是什么？三者哪里共享对象？
  2. def add(x, buf=[]): buf.append(x); return buf 连续调用 add(1)、add(2) 会得到什么？如何避免意外共享？
  3. 3 条记录中 2 条成功，步数为 8、20、12，成功的是第一和第三条。写成功率、全部平均步数和成功平均步数；空记录或无成功时怎么办？
  4. 为什么命令行运行时读取相对路径的结果可能与 IDE 中不同？文件不存在和 JSON 格式错误应如何区分？

B. 向量与梯度（第 2–4 周）

  1. X 是 (5,3)，w 是 (3,)，b 是标量。X@w+b 的形状是什么？若 w 是 (3,1)，再减 (5,) 的 y，结果形状会怎样？
  2. X=[[1,2],[3,4]]，w=[2,-1]，b=0.5，求预测值，并说明 * 与 @ 的区别。
  3. 只有一个样本 x=2、y=3，预测 wx+b，损失 L=(wx+b-y)²/2，当前 w=1、b=0。求 L、两个梯度，并用学习率 0.1 做一步更新。
  4. 对 L(w)=w²，如何用中心差分检查 w=3 时的梯度？为何差分步长并非越小越好？

C. 概率与机器学习（第 3–6 周）

  1. 100 个任务中 40 个有门；这 40 个中 10 个失败。P(失败且有门) 和 P(失败|有门) 各是多少？
  2. 回报样本是 0、0、1、1，求均值和以 n 为分母的方差。为什么 4 次成功率不足以支持方法稳定有效？
  3. 对全部数据先算标准化参数，再划分训练/测试，有什么问题？分别在哪些数据上拟合预处理、选超参数、做最终报告？
  4. 100 个样本只有 5 个正类，总预测负类也有很高准确率。它说明了什么？至少补充哪些观察？

D. PyTorch 与神经网络（第 5–7 周）

  1. loss.backward() 与 optimizer.step() 分别做什么？为什么通常需要清零梯度？
  2. model.eval() 和 torch.no_grad() 分别影响什么？为何评估时常同时使用？
  3. 训练损失下降、验证损失上升，至少提出两类可能原因及排查方法。为什么只看训练准确率不够？
  4. 残差连接 y=x+f(x) 对形状有什么要求？若一个分支从 (B,8) 变成 (B,16)，可以怎样处理？

E. 序列决策（第 8–10 周）

  1. 给定奖励序列 0、1、2，折扣率 0.5，从第一个奖励起的折扣回报是多少？即时奖励与回报有什么不同？
  2. 当前 Q(s,a)=2，r=1，gamma=0.9，下一状态最大 Q 为 4，alpha=0.1。算一次非终止转移的 Q-learning 更新。若真正终止又如何？
  3. 环境完整状态与智能体局部观察有什么不同？给一个必须依靠历史而不能只看当前画面的例子。
  4. 真实终止和外部时间截断有什么区别？为什么不能一概把自举项设为 0？已知转移模型的规划与从交互中学习又有什么区别？

F. 注意力与 Agent（第 11–16 周）

  1. Q 是 (B,T,d_k)，K 是 (B,T,d_k)，V 是 (B,T,d_v)。单头注意力的分数与输出形状分别是什么？softmax 沿哪个轴？
  2. 用 token 序列 a,b,c,d 构造下一 token 预测输入和标签。为何训练时要防止当前位置看到未来 token？
  3. 大模型输出一段开门程序后，谁执行、谁返回反馈、谁判断任务成功？Memory、Skill、Harness 各起什么作用？
  4. 技能 Agent 成功率更高，但拿到了完整地图且使用两倍模型调用，可以直接说明技能机制更好吗？怎样补对照？
