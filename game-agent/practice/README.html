01只要求success与steps字段，其余字段忽略。先实现这个核心函数；第一周有余力再围绕data/episodes.json增加JSON读写和结束原因计数，不把扩展要求混进B2的返回字典。

检查与复测

每项公开检查的输入和期望位于cases目录。标签$float表示NaN或无穷，$array表示按指定shape建立数组；这些只用于描述测试数据，不属于你函数的输入协议。

失败输出会给出用例名和具体原因。先看是类型、形状、数值还是异常约定不符，再缩小到一个用例复查。不要只反复修改代码直到输出全绿，却没有解释错误原因。

公开用例不能证明所有输入正确，也不自动判断你是否掌握。全部通过后，关闭旧代码，从空文件重写关键部分，换一个自己构造的输入，再解释输出为何如此。
