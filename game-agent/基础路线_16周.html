Game Agent 讲义

Game Agent 基础路线：16 周建议安排

制定：2026-10-25。用户已确认 Game Agent 主线、每周 8–10 小时、有编程基础，但 Python 和机器学习需要系统补齐。当前暂无本地 GPU 的资源背景沿用前次信息。本路线替代此前六周快速实践节奏；具体研究创新点仍待阅读与实验确定。

学到什么程度

目标是具备进入一个 Game Agent 入门研究项目的基础：读懂关键公式和接口，独立实现小模型与决策算法，能检查对照实验并讲清局限。16 周约 128–160 小时是工作量估计，达标可以提前，知识缺口明显就延长；不以此承诺精通整个机器学习或完成论文。

每个核心知识点都留下三种证据：用自己的话解释；完成一个推导或手算；不照抄教程实现最小例子。看完视频、抄完 notebook、AI 写出的程序运行成功，都不能单独算掌握。

主线依赖：Python 与数学 → 线性模型与评估 → PyTorch 与神经网络 → 序列决策与规划 → 注意力与语言模型 → 代码式游戏智能体。小任务贯穿其中，避免把基础学习变成无限延后的准备期。

每周怎么分配

用途 每周时间 做法
概念与主教材 2 小时 每周只围绕一个主要问题阅读；写下不懂的术语

每周核心为 8 小时，最多加 2 小时。课程忙时减少选做，不用压缩睡眠补进度。每周至少休息两天；首两周的具体时段见 前两周任务单。

第 1–4 周：Python、数学与机器学习入口

周 必学内容 核心练习与产物 本周验收
1 Python 列表/字典、循环、函数、可变对象、文件与异常；解释器和工作目录 从零写教学游戏轨迹统计器：读取小型 JSON，计算成功率、步数和终止原因；保存运行说明 能解释引用与复制；能按 traceback 找到出错行；修改字段后独立修好统计器
2 模块、最小类、虚拟环境概念；NumPy 的 shape、axis、索引、广播、矩阵乘法；向量/内积/范数 用循环和 NumPy 各实现批量线性预测，检查两版结果；画每个张量的形状 对 X 为 N×d、w 为 d，写出 Xw+b；能解释逐元素乘法与矩阵乘法差别
3 导数、偏导、链式法则、梯度、学习率；最小二乘；有限差分 手推线性回归梯度，NumPy 实现梯度下降；用有限差分核对一个参数 从损失推导梯度；解释学习率过大为何可能发散；说清梯度检查的误差来源
4 条件概率、期望、方差、采样；训练/验证/测试；分类与回归、过拟合；逻辑回归概念 在生成数据上做线性回归训练/验证；预处理只拟合训练集；比较多个种子并记录差异 通过 G1；能算条件概率和均值，解释数据泄漏；不能看着测试结果选模型

数学按任务补齐。先掌握矩阵形状、求导、概率和均值方差；特征值、SVD、凸优化证明在相关问题出现时深化。数学课已有内容可以凭闭卷验收压缩，不能仅凭“上过这门课”跳过。

第 5–7 周：PyTorch 与神经网络

周 必学内容 核心练习与产物 本周验收
5 tensor、dtype、autograd、nn.Module、optimizer；梯度累积与清零 将第 3 周线性回归迁到 PyTorch；比较手算、有限差分、自动微分 逐行解释 forward/loss/backward/step；解释为何清零梯度，梯度并非参数更新本身
6 Dataset/DataLoader、小批量 SGD、MLP、ReLU、交叉熵、train/eval、no_grad、保存加载 CPU 训练小型分类模型；先拟合极小训练子集排查实现，再看独立验证；和线性分类器比较 通过 G2；能解释损失和准确率的区别；保存/加载后预测一致；解释过拟合与模型容量
7 卷积/共享参数、CNN、残差连接；RNN 的序列状态；初始化、正则化与优化器直觉 手算一个小卷积并检查形状；写小残差块和 RNN 状态更新演示；MLP 只改变一个训练因素做对照 解释残差为何要匹配形状，RNN 怎样保留历史；能区分结构、损失、优化器的职责

第 7 周达到结构理解和小实现即可，不要求训练 ResNet 或逐一复现经典网络。SVM、树模型、聚类等先形成方法地图，不占用当前核心实现时间，后续课程与研究按需扩展。

第 8–10 周：序列决策、学习与规划

周 必学内容 核心练习与产物 本周验收
8 MDP、状态、动作、转移、奖励、策略、回报、V/Q、Bellman 关系；动态规划 对已知转移的极小网格做价值迭代，手算一轮，再与代码对照 解释即时奖励与长期回报，策略与价值的区别；知道规划为何需要模型
9 多臂老虎机与探索；MC/TD；Q-learning、epsilon-greedy；on/off-policy 概念 小老虎机或表格环境学习；在同一评测种子上比较随机策略与学习策略 独立算一次 TD 更新；能说明训练探索和评测探索设置；不要求深度 RL 训练
10 部分可观察、历史与记忆；BFS/搜索与学习的区别；Gymnasium、MiniGrid；结束与截断 MiniGrid 中记录随机策略轨迹；对已探索信息构建简单地图；完整地图 BFS 只作明确标记的上界演示 通过 G3；检查观察边界；区分任务真正结束和外部截断，解释自举处理

先在表格任务上理解 RL，之后再读策略梯度的直觉。DQN、PPO 训练为后续选做，不是代码式 Agent 的前置条件。规则策略可以帮助调试环境，但必须标明没有模型学习。

第 11–12 周：注意力、大模型与多模态入口

周 必学内容 核心练习与产物 本周验收
11 embedding、Q/K/V、缩放点积注意力、softmax、因果 mask、位置编码、残差与归一化 手算 2–3 token 的单头注意力；用 PyTorch 实现；检查未来 token 被遮蔽 写出 QKᵀ 和输出的形状，解释权重归一化方向及信息泄漏
12 decoder-only 与 encoder-decoder；下一 token 目标、teacher forcing、训练与生成；ViT/VLM/VLA；SFT 与偏好/RL 后训练地图 生成小型动作字符串语料，构建字符级下一 token 数据；跑通极小模型训练与生成；画多模态模块图 通过 G4；解释输入/标签错位、训练/推理差别；说清 SFT、DPO、PPO、GRPO 的数据和信号差异

小语言模型仅用于理解训练机制，学习数据明确标为自建教学数据；不能把重复训练集上的生成效果当作泛化。模型大小和训练步数按本机 CPU 实测调整，不保证固定耗时，也不需要预训练大模型。

ViT/VLM/VLA 在此阶段先建立输入、编码器、表示与输出的关系；视觉编码器、机器人动作预测的深入训练放到进入相应分支后。

第 13–16 周：接入 Game Agent 实践

周 必学内容 核心练习与产物 本周验收
13 Agent 观察—决策—执行循环、工具、Memory、Skill、Harness；Code as Policies 阅读经典论文相应正文，画系统图；写一个只依赖允许观察与动作的策略接口 能说明控制逻辑、技能、环境分别做什么；区分 AI 帮你写代码与被评测 Agent 自主行动
14 MiniGrid DoorKey；动作程序、执行反馈、模型响应与轨迹记录 建立逐步动作和固定技能两类基线；先规则/回放检查，再小规模真实模型试跑 真实模型前固定渠道、模型、提示与预算；规则/回放不能替代真实基线
15 CaP-X、ASPIRE 相关正文；公平对照、消融、配对实验、成本和失败分类 整理近似工作矩阵；比较基线并寻找一个反复出现的问题 区分种子泛化和任务组合迁移；说明抽象层级或额外调用带来的混杂因素
16 研究叙述、统计不确定性、复现记录与局限 汇报背景、代表方法、实验分析和下一步问题；复查至少一个失败轨迹 通过 G5；每个结果对应配置与原始记录，能解释未解决的问题

第 13 周前以基础教学实验为主，不产生付费 API 支出。第 14–16 周真实模型实验是否能执行取决于推理渠道与具体预算授权；如果尚未具备，继续完成接口、规则与回放检查，并如实保留“真实基线未完成”，不强行勾选 G5。

各关都做“闭卷讲 5 分钟＋从空文件写核心部分＋改变一个条件后解释结果”。允许查询 API 签名，不直接照搬完整实现。以下为学习用验收标准，不是导师的入组考核。

关卡 必须独立完成 未通过时怎么补

G3／第 10 周后 小 MDP 价值更新和 Q 更新；解释观察与状态；运行并复查游戏轨迹 先手算极小环境，再检查终止、自举与观察接口

用 AI 学习的具体方法

默认先自己尝试 20–30 分钟，然后请 AI 定位卡点、给一条提示或一组小数字。拿到解答后合上答案，在另一个输入或地图上重做，最后解释“为什么这样写”。AI 可承担资源查找、练习设计、审阅、环境检查和重复实验；核心推导、关键代码和结果解释要亲自练习。这是建议的学习方式，随时可按你的要求提供完整讲解。

每次学习记录：日期、主题、实际时间、资料范围、自己的解释、手算或代码证据、最重要的错误、下一次复测题。模板见 学习记录模板。周末复测本周和上一周；每完成一个关卡，再抽查前一关，防止短期记住后遗忘。
